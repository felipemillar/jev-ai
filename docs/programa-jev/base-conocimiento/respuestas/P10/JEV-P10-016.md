# JEV-P10-016 — Estructuración de Grafos de Conocimiento sin Alucinación de Entidades ni Enlaces

## 1. Respuesta directa y decisión que permite tomar

La construcción de grafos de entidades, hechos y fuentes (Knowledge Graphs) mediante Jev exige restringir la extracción de relaciones a taxonomías y ontologías cerradas. No se permite la generación libre de tipos de relación. Cada arista del grafo `(Sujeto, Relación, Objeto)` debe validarse con una primitiva `Choice` que confirme la relación dentro de un conjunto restringido de opciones documentadas, vinculando de forma obligatoria el identificador del fragmento fuente como propiedad de la arista.

## 4. Explicación técnica

Ontología cerrada: Tipos de relación permitidos: `ES_SUBSIDIARIA_DE`, `ACCIONISTA_MAYORITARIO_DE`, `PROVEEDOR_DE`, `REPRESENTANTE_LEGAL_DE`. La extracción libre sin vocabulario controlado genera aristas sinónimas dispersas y relaciones espurias.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P10_16')

def validar_arista_grafo(texto_noticia: str, entidad_a: str, entidad_b: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        prompt = f'TEXTO: {texto_noticia}\nENTIDAD 1: {entidad_a}\nENTIDAD 2: {entidad_b}'
        relaciones_posibles = ['ES_ACCIONISTA', 'ES_DIRECTOR', 'DEMANDA_A', 'NINGUNA']
        res = client.system_one(state=prompt, questions={'tipo_relacion': Choice(instructions='Relacion entre entidades', criteria={opt: 'Criterio evaluativo para ' + str(opt) for opt in relaciones_posibles})})
        return res.answers['tipo_relacion'].choice
    except Exception as err:
        logger.error(f'Fallo en arista de grafo: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'ERROR'
```

- **Contraejemplo / Caso borde**: Permitir que un modelo invente relaciones como 'parece_que_es_socio_de' contamina el grafo de entidades corporativas impidiendo consultas Cypher estructuradas.

## 8. Validación propuesta

- **Hipótesis Falsable**: La extracción de relaciones sobre vocabulario ontológico cerrado garantiza una fidelidad relacional del 97%.

- **Criterio de Rechazo**: Precisión >= 95% auditada sobre muestra de 150 aristas.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
