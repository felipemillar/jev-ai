# JEV-P10-017 — Detección y Mitigación de Sesgos hacia Fuentes Extensas o Redundantes

## 1. Respuesta directa y decisión que permite tomar

Los sistemas de búsqueda y reranking presentan un sesgo sistemático hacia documentos extensos o párrafos verbosos, los cuales tienden a recibir puntuaciones más altas por mera acumulación de términos afines. Para mitigar este sesgo, el sistema debe normalizar los scores semánticos en función de la longitud del pasaje o estructurar la evaluación comparando exclusivamente fragmentos normalizados de tamaño uniforme (e.g. 300 palabras), penalizando textos redundantes mediante métricas de densidad de información.

## 4. Explicación técnica

Score normalizado: $S_{\text{norm}} = S_{\text{jev}} \cdot \left(\frac{L_{\text{ref}}}{L_{\text{pasaje}}}\right)^\gamma$, donde $\gamma \in [0.1, 0.3]$ modula la penalización por exceso de verbosidad sin castigar injustamente pasajes explicativos.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import math, logging

logger = logging.getLogger("P10_17")

def normalizar_score_por_longitud(score_bruto: float, texto_pasaje: str, longitud_referencia: int = 300) -> float:
    try:
        palabras = len(texto_pasaje.split())
        if palabras <= 0:
            return 0.0
        # Factor de correccion atenuado (gamma = 0.2)
        factor = math.pow(longitud_referencia / max(palabras, 50), 0.2)
        score_normalizado = score_bruto * factor
        return round(score_normalizado, 3)
    except Exception as err:
        logger.error(f"Fallo en normalizacion: {type(err).__name__} (detalles omitidos por seguridad)")
        return score_bruto
```
