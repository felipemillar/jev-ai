# JEV-P08-001 — Separación de Decisiones: Jev vs Código Determinista, Modelos Frontier y Humanos

## 1. Respuesta directa y decisión que permite tomar

Jev 1.13 debe asumir exclusivamente decisiones de clasificación semántica, evaluación ordinal y compuertas booleanas sobre texto no estructurado donde las reglas léxicas fallan por variabilidad lingüística. Todo cómputo aritmético, agregación de métricas financieras, verificación de esquemas y lógica transaccional debe residir en código determinista en Python o C++. Tareas que requieran generación de texto libre, razonamiento multi-paso o síntesis abierta deben delegarse a modelos frontier (Gemini o Claude). Finalmente, acciones irreversibles de alto riesgo (ejecución de órdenes de trading o descarte final de candidatos) exigen supervisión humana obligatoria.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P08_01')

def separar_responsabilidades(texto_gasto: str, monto: float) -> dict:
    try:
        if monto > 50000.0 or monto <= 0:
            return {'status': 'RECHAZO_DETERMINISTA', 'monto': monto}
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_gasto, questions={'tipo': Choice(instructions='Tipo de gasto', criteria={'hardware': 'Criterio para opción hardware', 'software': 'Criterio para opción software', 'viaticos': 'Gasto en viáticos y traslados de personal'})})
        cat = res.answers['tipo'].choice
        return {'status': 'APROBADO_AUTO' if cat == 'software' else 'REVISION', 'categoria': cat}
    except Exception as err:
        logger.error(f'Fallo en modulo 01: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'status': 'ERROR'}
```

### 5.2 Contraejemplo y Caso Límite

Un empleado solicita reembolso por 'almuerzo con cliente para cerrar contrato cloud'. La mezcla de viático y software exige abstención si la diferencia de probabilidades entre ambas opciones es menor a 0.15.
