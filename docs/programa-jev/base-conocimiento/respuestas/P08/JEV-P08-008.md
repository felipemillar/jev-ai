# JEV-P08-008 — Estimación del Error Acumulado en Flujos Multi-Paso sin Suponer Independencia

## 1. Respuesta directa y decisión que permite tomar

En un pipeline con M decisiones semánticas encadenadas, asumir independencia estadística (P(éxito) = prod p_i) es un grave error de diseño, ya que los sesgos de tokenización y distribución se correlacionan positivamente. Para una estimación conservadora y auditable, se debe utilizar la cota de unión de Boole-Fréchet: la probabilidad de fallo total P(error) <= sum (1 - p_i). En flujos de más de tres pasos, los errores se multiplican, haciendo indispensable intercalar filtros deterministas purificadores.

## 4. Explicación técnica verificable

Aplicación de desigualdades de Fréchet para acotar la fiabilidad conjunta: P(exito_total) >= max(0, 1 - sum(1 - p_k)). Si la cota garantizada cae por debajo de 0.80, la arquitectura exige desacoplar el flujo.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P08_08")

def calcular_frechet(probabilidades: list[float]) -> dict:
    try:
        sum_errores = sum(1.0 - p for p in probabilidades)
        cota_minima = max(0.0, 1.0 - sum_errores)
        prod_indep = 1.0
        for p in probabilidades:
            prod_indep *= p
        return {"cota_frechet": round(cota_minima, 3), "cálculo_ingenuo": round(prod_indep, 3)}
    except Exception as err:
        logger.error(f"Fallo frechet: {type(err).__name__} (detalles omitidos por seguridad)")
        return {}
```

### 5.2 Contraejemplo y Caso Límite

Conectar 5 clasificadores encadenados con 90% de exactitud cada uno: el cálculo ingenuo estima 59% de éxito, pero la cota Fréchet advierte que el fallo acumulado puede alcanzar el 50% de las transacciones.
