# JEV-P08-014 — Diseño de Colas de Revisión Humana con Contexto Suficiente y Feedback Ingerible

## 1. Respuesta directa y decisión que permite tomar

El diseño de la cola de revisión humana debe estructurarse para facilitar el análisis inmediato y registrar retroalimentación auditable. Cada registro debe desplegar: el texto original analizado, la predicción del modelo con su distribución de probabilidades, la regla o umbral que disparó la derivación y selectores atómicos para que el revisor clasifique el caso y justifique su corrección.

## 8. Validación propuesta

- **Hipótesis Falsable**: Desplegar el motivo de escalado reduce el tiempo de resolución humana en al menos un 40%.

- **Criterio de Rechazo**: Tiempo medio <= 35 segundos por ítem revisado.
