# JEV-P15-014 — Evaluación de Señales Textuales con Particiones Temporales Rigurosas

## 1. Respuesta directa y decisión que permite tomar

En finanzas cuantitativas, la validación de cualquier modelo o señal derivada de texto exige particiones temporales estrictas (Time-Series Split / Purged Walk-Forward). Queda terminantemente prohibido utilizar validación cruzada con barajado aleatorio (K-Fold cross-validation con shuffle), ya que mezcla datos del futuro con datos del pasado, generando resultados artificialmente optimistas que colapsan en tiempo real. Los conjuntos de entrenamiento, validación y prueba deben ser cronológicamente contiguos y purgando períodos de solapamiento.

def validar_particion_temporal_continua(anios_entrenamiento: list, anios_prueba: list) -> bool:

## 8. Validación propuesta

- **Hipótesis Falsable**: La validación Walk-Forward refleja fielmente el rendimiento real de las señales textuales en producción.
- **Métricas**: Correlación entre el Sharpe de validación Walk-Forward y el Sharpe en producción.
- **Criterio de Rechazo**: Correlación >= 0.70 en pruebas con datos no vistos.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
