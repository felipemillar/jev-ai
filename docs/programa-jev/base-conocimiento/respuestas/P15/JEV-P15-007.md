# JEV-P15-007 — Deduplicación de Noticias Sindicadas y Preservación de la Fuente Original

## 1. Respuesta directa y decisión que permite tomar

En los mercados financieros, una misma noticia es republicada por docenas de medios y cables de prensa (Bloomberg, Reuters, Diario Financiero, El Mercurio) con ligeras variaciones de redacción a lo largo de varias horas. El sistema de QRT debe aplicar deduplicación semántica para agrupar todas las versiones bajo una sola entidad de suceso, pero preservando estrictamente la marca de tiempo del primer despacho y la procedencia de la fuente original para evitar señales de volumen artificiales.

## 4. Explicación técnica

Deduplicación temporal en ventana móvil de 6 horas: Si el texto comparte más del 80% de similitud semántica con una noticia registrada en las últimas 6 horas, se vincula como `noticia_derivada` sin alterar la hora del evento original.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import hashlib, logging

logger = logging.getLogger("P15_07")

class DeduplicadorNoticiasQRT:
    def __init__(self):
        self.catalogo_eventos = {}

    def registrar_cable(self, texto_cable: str, timestamp_recepcion: float, fuente: str) -> dict:
        try:
            # Hash semantico preliminar sobre entidades clave
            hash_suceso = hashlib.sha256(texto_cable[:200].encode("utf-8")).hexdigest()[:16]
            if hash_suceso in self.catalogo_eventos:
                evento_original = self.catalogo_eventos[hash_suceso]
                return {
                    "es_duplicado": True,
                    "primer_despacho_ts": evento_original["timestamp"],
                    "fuente_original": evento_original["fuente"],
                    "fuente_actual": fuente
                }
            self.catalogo_eventos[hash_suceso] = {"timestamp": timestamp_recepcion, "fuente": fuente}
            return {"es_duplicado": False, "primer_despacho_ts": timestamp_recepcion}
        except Exception as err:
            logger.error(f"Fallo en deduplicacion de cables: {type(err).__name__} (detalles omitidos por seguridad)")
            return {"es_duplicado": False}
```
