En el marco del Piloto QRT-02, Jev debe evaluar la literatura científica de finanzas cuantitativas (SSRN, arXiv) basándose en criterios estrictos de rigor metodológico y reproducibilidad, penalizando de forma deliberada los papers que reportan ratios de Sharpe astronómicos (>3.0) sin documentar costos de transacción o pruebas fuera de muestra. ## 4. Explicación técnica

Evaluación con rúbrica cerrada: Evaluar con `Score(1, 5)` el detalle de costos de transacción y con `Choice` la presencia de validación fuera de muestra. Un paper que omita costos de transacción recibe automáticamente una penalización en su ranking.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice, Score
logger = logging.getLogger('P15_08')

def auditar_paper_metodologia(texto_metodologia: str) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_metodologia, questions={'costos_transaccion': Choice(instructions='Detalla costos de transaccion y slippage', criteria={'detallados_realisticos': 'Modela explícitamente comisiones, spread y slippage', 'mencionados_superficial': 'Menciona fricciones de forma superficial sin modelo numérico', 'omitidos_completamente': 'Omite fricciones asumiendo ejecución perfecta a mid-price'}), 'reproducibilidad': Score(instructions='Grado de reproducibilidad de datos', criteria=['Nivel 1: Muy deficiente / Sin alineación', 'Nivel 2: Deficiente / Baja alineación', 'Nivel 3: Aceptable / Alineación moderada', 'Nivel 4: Bueno / Alta alineación', 'Nivel 5: Excelente / Rigurosamente alineado'])})
        return {'costos': res.answers['costos_transaccion'].choice, 'score_reproducibilidad': res.answers['reproducibilidad'].score}
    except Exception as err:
        logger.error(f'Fallo en evaluacion de paper QRT-02: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'costos': 'omitidos_completamente', 'score_reproducibilidad': 1}
```
