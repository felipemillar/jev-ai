# JEV-P15-020 — Criterios Formales para Aprobar, Reformular o Archivar Pilotos de QRT

## 1. Respuesta directa y decisión que permite tomar

Al término del período de evaluación de 60 días de los pilotos QRT-01 y QRT-02, el Director Quant y el comité de tecnología deben aplicar una regla tripartita de dictamen: 1) Aprobar: Si el piloto redujo en más de un 40% el tiempo manual de triaje manteniendo 95% de precisión sin violar Point-in-Time; 2) Reformular: Si la precisión es adecuada pero el costo o la tasa de abstención son excesivos; y 3) Archivar definitivamente: Si los clasificadores no superan la línea base de reglas deterministas o si introducen riesgos de estabilidad.

logger = logging.getLogger("P15_20")

def emitir_dictamen_piloto_qrt(ahorro_tiempo_pct: float, precision: float, incidentes_seguridad: int) -> dict:
    try:
        if incidentes_seguridad > 0 or precision < 0.88:
            return {"dictamen": "ARCHIVAR_DEFINITIVAMENTE", "motivo": "Fallo en seguridad o precision insuficiente"}
        if ahorro_tiempo_pct >= 40.0 and precision >= 0.94:
            return {"dictamen": "APROBAR_PARA_PRODUCCION", "motivo": "Cumple todos los objetivos tecnicos y de valor"}
        return {"dictamen": "REFORMULAR_PILOTO", "motivo": "Precisión aceptable pero ahorro de tiempo sub-óptimo"}
    except Exception as err:
        logger.error(f"Fallo en dictamen de piloto: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"dictamen": "ERROR"}
