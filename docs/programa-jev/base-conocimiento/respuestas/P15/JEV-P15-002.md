## 4. Explicación técnica

Canal de enriquecimiento asíncrono: Entrada: Hecho esencial en PDF extraído de la CMF. Jev devuelve `Choice` con el tipo de evento corporativo (`Aumento_Capital`, `Cambio_Directorio`, `Dividendo`). El resultado se indexa en una base de datos relacional para consulta histórica.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P15_02')

def clasificar_evento_cmf(texto_hecho_esencial: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_hecho_esencial, questions={'tipo_evento': Choice(instructions='Clasificar evento corporativo segun normativa CMF', criteria={'aumento_capital': 'Hecho esencial de aumento de capital o emisión', 'cambio_directorio': 'Modificación en composición del directorio o administración', 'dividendo': 'Acuerdo de distribución de dividendos o utilidades', 'hecho_menor': 'Comunicación de hecho de interés no calificado como esencial'})})
        return res.answers['tipo_evento'].choice
    except Exception as err:
        logger.error(f'Fallo en clasificador CMF: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'hecho_menor'
```

- **Contraejemplo / Caso borde**: Intentar que Jev 'prediga si la acción subirá o bajará' basándose en el hecho esencial en lugar de solo clasificar el tipo de evento corporativo.
