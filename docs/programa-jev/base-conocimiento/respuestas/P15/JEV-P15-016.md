# JEV-P15-016 — Protocolo contra el Sobreajuste Iterativo en el Conjunto Fuera de Muestra (OOD)

## 1. Respuesta directa y decisión que permite tomar

Para evitar el fenómeno destructivo de sobreajuste acumulativo (Data Snooping / P-Hacking), el conjunto de prueba fuera de muestra (OOD) debe mantenerse bajo un protocolo formal de acceso restringido. Queda prohibido consultar iterativamente el conjunto OOD para ajustar los prompts o cambiar los parámetros de Jev hasta obtener un buen resultado. El conjunto OOD solo se evalúa una única vez cuando el modelo ha sido completamente congelado y aprobado.

## 4. Explicación técnica

Cierre criptográfico del conjunto de prueba: El archivo de datos OOD se almacena cifrado. Solo el responsable de control de riesgos posee la clave para desencriptarlo y ejecutar la evaluación definitiva una vez por trimestre.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P15_16")

class ControlAccesoConjuntoPrueba:
    def __init__(self, evaluaciones_maximas: int = 2):
        self.evaluaciones_realizadas = 0
        self.limite = evaluaciones_maximas

    def solicitar_acceso_ood(self, modelo_congelado: bool) -> bool:
        try:
            if not modelo_congelado:
                logger.critical("ACCESO DENEGADO: El modelo no ha sido congelado formalmente")
                return False
            if self.evaluaciones_realizadas >= self.limite:
                logger.critical("ACCESO DENEGADO: Limite de consultas al conjunto OOD agotado")
                return False
            self.evaluaciones_realizadas += 1
            return True
        except Exception as err:
            logger.error(f"Fallo en control OOD: {type(err).__name__} (detalles omitidos por seguridad)")
            return False
```

## 8. Validación propuesta

- **Hipótesis Falsable**: La restricción de consultas al conjunto OOD garantiza que la degradación en producción no supere los 3 puntos porcentuales.
- **Métricas**: Caída de rendimiento entre el test OOD y la operación en vivo.
- **Criterio de Rechazo**: Delta de exactitud OOD vs Live <= 3.0%.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
