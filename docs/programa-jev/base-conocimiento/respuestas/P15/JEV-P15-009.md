# JEV-P15-009 — Detección de Afirmaciones sin Soporte en Reportes Internos de Research

## 1. Respuesta directa y decisión que permite tomar

Jev 1.13 debe actuar como un verificador de consistencia lógica sobre los memorandos internos de investigación generados por los analistas cuantitativos. El sistema debe comprobar que cada afirmación o conclusión sobre el rendimiento de una estrategia esté respaldada directamente por las tablas de métricas o gráficos incluidos en el reporte, alertando ante discrepancias o interpretaciones no justificadas por los datos numéricos brutos.

## 4. Explicación técnica

Verificación de soporte textual-numérico: El texto del reporte se pasa en `state`. Jev evalúa mediante `Choice` si la conclusión 'la estrategia es robusta ante caídas de mercado' tiene respaldo en los datos de drawdown de la tabla adjunta.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P15_09')

def auditar_consistencia_reporte(texto_memorando: str) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_memorando, questions={'consistencia_afirmaciones': Choice(instructions='Determinar si las conclusiones estan sustentadas por los datos del texto', criteria={'plenamente_sustentadas': 'Conclusiones respaldadas rigurosamente por los datos presentados', 'afirmaciones_exageradas': 'Conclusiones que extrapolan o exageran el alcance de los datos', 'inconsistencias_detectadas': 'Inconsistencias directas o contradicciones entre datos y tesis'})})
        ans = res.answers['consistencia_afirmaciones']
        return {'dictamen': ans.choice, 'confianza': ans.confidence}
    except Exception as err:
        logger.error(f'Fallo en auditoria de reporte: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'dictamen': 'inconsistencias_detectadas', 'confianza': 0.0}
```

- **Contraejemplo / Caso borde**: Aprobar una estrategia cuantitativa para producción porque el analista escribió en la introducción que 'es inmune a la volatilidad' aunque la tabla mostraba pérdidas del 20% en 2022.
