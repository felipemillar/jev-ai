# JEV-P05-014: Pertinencia y Límites de la Predicción Conforme (Conformal Prediction) en Jev

## 1. Respuesta directa y decisión que permite tomar

La **Predicción Conforme (*Conformal Prediction*)** es un marco matemático riguroso que transforma las salidas puntuales o probabilidades de Jev 1.13 en **conjuntos de predicción con garantía estadística de cobertura finita libre de distribución (*Distribution-Free Finite-Sample Guarantee*)**. En lugar de forzar al modelo a predecir una única opción en `Choice` (e.g., *"es Fraude Documental"*), la predicción conforme emite un conjunto de alternativas $\mathcal{C}(x) \subseteq \mathcal{Y}$ garantizando que:
$$\mathbb{P}(Y \in \mathcal{C}(x)) \ge 1 - \alpha$$
Donde $1 - \alpha$ es el nivel de cobertura fijado por el negocio (e.g., $95\%$ o $99\%$).

**Cuándo es altamente pertinente en nuestros desarrollos**:
1. **Enrutamiento Inteligente por Cardinalidad del Conjunto**:
   - Si $|\mathcal{C}(x)| = 1$ (conjunto unitario, e.g., `{"APROBADO"}`): Alta certeza del modelo $\implies$ **Automatizar al 100%**.
   - Si $|\mathcal{C}(x)| > 1$ (conjunto multi-etiqueta, e.g., `{"FRAUDE_DOCUMENTAL", "DISPUTA_COMERCIAL"}`): Ambigüedad identificada $\implies$ **Escalar a analista humano**.
   - Si $|\mathcal{C}(x)| = \emptyset$ (conjunto vacío): Anomalía severa o caso fuera de distribución (OOD) $\implies$ **Rechazo preventivo en CPU**.
2. **Taxonomías Complejas en `Choice`**: En clasificación de incidentes, tipificación legal o clasificación de contratos donde las categorías tienen solapamiento semántico.

**Supuestos críticos que impiden tratar sus garantías como universales en producción**:
La garantía matemática de cobertura del $(1 - \alpha)$ depende estrictamente de un supuesto fundamental: **la Intercambiabilidad (*Exchangeability*)** entre el conjunto de calibración y los datos futuros de producción. En la operativa real de Wheelwork y QRT, este supuesto **se rompe sistemáticamente** debido a:
1. **Dependencia Temporal y Autocorrelación**: En series financieras (QRT), los eventos no son intercambiables; presentan memoria larga y clustering de volatilidad.
2. **Desplazamiento de Dominio y Deriva (*Concept & Covariate Drift*)**: Cambios regulatorios o económicos invalidan la calibración previa.
3. **Cobertura Marginal vs Condicional**: La garantía estándar es *marginal* (promediada en toda la población); puede satisfacer el $95\%$ global teniendo un $0\%$ de cobertura en una minoría vulnerable (JEV-P05-008).

**Decisión que permite tomar**: Habilitar la Predicción Conforme como motor de enrutamiento y detección de anomalías en tareas multiclase no temporales en Wheelwork. Prohibir su uso como garantía estricta en series temporales financieras de QRT a menos que se utilicen variantes adaptativas de tiempo (*Adaptive Conformal Inference*).

## 4. Explicación técnica verificable

### 4.1. Algoritmo de Predicción Conforme Split (Inductive Conformal Prediction)

Dado un conjunto de calibración independiente $D_{\text{cal}} = \{(x_i, y_i)\}_{i=1}^{N_{\text{cal}}}$ y un nivel de significancia deseado $\alpha \in (0, 1)$ (e.g., $\alpha = 0.05$ para $95\%$ de cobertura):

1. **Puntuación de No Conformidad (*Non-Conformity Score*)**:
   Para cada caso de calibración $i$, se evalúa la probabilidad asignada por Jev a la clase verdadera:
   $$s_i = 1 - p(y_i \mid x_i)$$
   Un valor alto de $s_i$ indica que el modelo consideró "improbable" la clase real.
2. **Cálculo del Cuantil Conformal Crítico ($\hat{q}$)**:
   Se calcula el cuantil corregido por muestra finita:
   $$\hat{q} = \text{Quantile}\left( \{s_1, \dots, s_{N_{\text{cal}}}\}, \frac{\lceil (N_{\text{cal}} + 1)(1 - \alpha) \rceil}{N_{\text{cal}}} \right)$$
3. **Construcción del Conjunto de Predicción para una Nueva Instancia $x_{\text{test}}$**:
   El conjunto conformal incluye todas las opciones cuya probabilidad predicha sea suficientemente alta:
   $$\mathbf{\mathcal{C}(x_{\text{test}}) = \{ y \in \mathcal{Y} \mid 1 - p(y \mid x_{\text{test}}) \le \hat{q} \} = \{ y \in \mathcal{Y} \mid p(y \mid x_{\text{test}}) \ge 1 - \hat{q} \}}$$

### 5.1. Código en Python: Motor de Predicción Conforme para Jev en CPU

```python
# Ejemplo ilustrativo no ejecutado
"""
Motor de Predicción Conforme (Conformal Prediction) en CPU para Jev 1.13.
"""
import numpy as np
from typing import Dict, Any, List, Set

class ConformalPredictionEngine:
    def __init__(self, alpha: float = 0.05):
        self.alpha = alpha
        self.q_hat = 1.0
        self.calibrated = False

    def calibrate(self, probs_matrix: np.ndarray, true_labels: np.ndarray):
        """
        Calcula el cuantil crítico q_hat sobre D_cal.
        probs_matrix: Matriz (N, K) con las probabilidades devueltas por Jev.
        true_labels: Array (N,) con los índices de la clase verdadera (0 a K-1).
        """
        n = len(true_labels)
        # Extraer la probabilidad asignada a la clase real
        true_class_probs = probs_matrix[np.arange(n), true_labels]
        # Puntuaciones de no conformidad: s_i = 1 - p(y_real)
        scores = 1.0 - true_class_probs

        # Cuantil ajustado por muestra finita: ceil((n + 1) * (1 - alpha)) / n
        quantile_level = np.clip(np.ceil((n + 1) * (1.0 - self.alpha)) / n, 0.0, 1.0)
        self.q_hat = float(np.quantile(scores, quantile_level, method="higher"))
        self.calibrated = True
        print(f"Calibrador Conformal Ajustado: N={n}, 1-alpha={1-self.alpha:.2f}, q_hat={self.q_hat:.4f}")

    def predict_set(self, prob_dict: Dict[str, float]) -> Dict[str, Any]:
        """Construye el conjunto de predicción para un caso nuevo."""
        if not self.calibrated:
            raise RuntimeError("El motor conformal debe calibrarse antes de predecir.")

        threshold = 1.0 - self.q_hat
        prediction_set = [choice for choice, p in prob_dict.items() if p >= threshold]

        cardinality = len(prediction_set)
        if cardinality == 1:
            decision = "AUTOMATIZAR_ALTA_CONFIANZA"
        elif cardinality > 1:
            decision = "ESCALAR_A_HUMANO_AMBIGUO"
        else:
            decision = "RECHAZO_PREVENTIVO_OOD_ANOMALIA"

        return {
            "conjunto_conformal": prediction_set,
            "cardinalidad": cardinality,
            "umbral_corte_p": round(threshold, 4),
            "accion_operacional": decision
        }

# Simulación de calibración y ejecución en producción
if __name__ == "__main__":
    np.random.seed(42)
    N_cal = 500
    K = 3 # Clases: ["APROBADO", "RECHAZADO", "CONDICIONAL"]
    clases = ["APROBADO", "RECHAZADO", "CONDICIONAL"]

    # Simular probabilidades de Jev sobre D_cal
    raw_logits = np.random.randn(N_cal, K)
    # Exponencial y normalizar para tener softmax
    exp_logits = np.exp(raw_logits)
    cal_probs = exp_logits / np.sum(exp_logits, axis=1, keepdims=True)
    cal_labels = np.random.choice(K, size=N_cal)

    engine = ConformalPredictionEngine(alpha=0.05) # 95% cobertura garantizada
    engine.calibrate(cal_probs, cal_labels)

    # Evaluar 3 casos nuevos representativos
    caso_facil = {"APROBADO": 0.94, "RECHAZADO": 0.04, "CONDICIONAL": 0.02}

    caso_ood_plano = {"APROBADO": 0.34, "RECHAZADO": 0.33, "CONDICIONAL": 0.33}

    print("\n=== CASO 1: Documento Limpio y Decisivo ===")
    print(engine.predict_set(caso_facil))
```

### 5.2. Contraejemplo y Caso Límite: Colapso de Garantía Conformal por Desplazamiento Temporal en QRT

En una mesa de dinero en QRT, se calibra un conjunto conformal al $99\%$ de cobertura ($\alpha = 0.01$) para predecir si una orden de compra sufrirá deslizamiento de precio (*slippage*):
- El modelo se calibra usando $1,000$ órdenes ejecutadas durante un mes de calma cambiaria (baja volatilidad).
- Se obtiene un cuantil crítico que genera conjuntos compactos de tamaño $1$ o $2$.
- **Ruptura de Intercambiabilidad**: A la semana siguiente, el Banco Central sube sorpresivamente las tasas de interés, desatando una ola de volatilidad macroeconómica.
- El supuesto de intercambiabilidad se quiebra radicalmente: la distribución $P_{\text{nuevo}}(X, Y) \neq P_{\text{cal}}(X, Y)$.
- En lugar de mantener la cobertura garantizada del $99\%$, la cobertura empírica real se derrumba al **$72\%$**, y la orden sufre pérdidas por deslizamiento masivo no anticipado.
- **Lección**: La garantía formal de la predicción conforme es estática; en series temporales con cambio de régimen, la garantía matemática se extingue a menos que se re-calibre continuamente con algoritmos adaptativos (Gibbs & Candès, 2021).

## 6. Aplicación a nuestros desarrollos

### 6.1. Hechos verificables en proyectos existentes

1. **Wheelwork (Tipificación de Incidentes de Flota)**:
   - Los partes policiales y reportes de choque involucran múltiples causas posibles (falla mecánica, imprudencia, estado del camino).
   - *Hecho*: Forzar a Jev a elegir una sola causa genera disputas legales; el conjunto conformal permite emitir `{"IMPRUDENCIA_TERCERO", "ESTADO_CAMINO"}`, derivando el caso a un perito solo cuando el conjunto no es unitario.

2. **QRT (Clasificación de Comunicados de Quiebra)**:
   - Los comunicados de insolvencia de la SEC o CMF combinan múltiples tipologías normativas.
   - *Hecho*: En regímenes estables, la predicción conforme aísla hechos esenciales atípicos emitiendo conjuntos vacíos ($\mathcal{C}(x) = \emptyset$), alertando a compliance sobre anomalías documentales.

### 6.2. Hipótesis de diseño para Jev

- **Hipótesis 1**: El uso de conjuntos conformales en Wheelwork permitirá automatizar el 75% de las tipificaciones documentales con una tasa de cobertura empírica auditada superior al $95\%$.
- **Hipótesis 2**: El filtrado por cardinalidad conformal ($|\mathcal{C}(x)| > 1$) reducirá el tiempo de análisis de los operadores humanos en un 40% al preseleccionar las 2 opciones plausibles y descartar las demás.

## 7. Fallos, límites, controles y condiciones de no uso

### 7.1. Modos de falla y mitigaciones

| Modo de Falla | Causa Raíz | Detección | Mitigación Arquitectónica |
|---|---|---|---|
| **Violación de Intercambiabilidad** | Aplicar conformal en series de tiempo con autocorrelación en QRT. | Monitoreo continuo de la tasa de cobertura real; caída por debajo de $1 - \alpha$. | Implementar *Adaptive Conformal Inference (ACI)* que ajusta $\alpha_t$ dinámicamente. |
| **Conjuntos Demasiado Grandes ($|\mathcal{C}(x)| = K$)** | El modelo es muy inseguro y el algoritmo conformal incluye todas las opciones para cumplir la garantía. | Cardinalidad media del conjunto $\ge 0.8 \cdot K$. | El sistema no tiene utilidad; requiere mejorar el prompt o cambiar a abstención dura. |
| **Sub-cobertura en Clases Minoritarias** | Cumplir 95% global a costa de fallar en el 100% de los casos de una clase rara. | Auditoría desagregada de cobertura por clase (Class-Conditional Conformal). | Adoptar *Mondrian Conformal Prediction* que calibra un cuantil $\hat{q}_k$ por cada clase. |

### 7.2. Condiciones de NO uso

- **NO utilizar predicción conforme estándar en series temporales financieras de alta frecuencia sin corrección adaptativa**: Las garantías teóricas quedan formalmente invalidadas por la autocorrelación.
- **NO interpretar el conjunto conformal como una distribución de probabilidad**: Es una región de confianza discreta de pertenencia, no un estimador de densidad.
