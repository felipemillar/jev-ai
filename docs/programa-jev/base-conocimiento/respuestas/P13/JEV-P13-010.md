# JEV-P13-010 — Amortización de la Inversión Inicial de Integración en Pilotos Pequeños

## 1. Respuesta directa y decisión que permite tomar

El costo de ingeniería requerido para integrar, probar y auditar Jev (estimado en 40 a 80 horas de desarrollador, equivalentes a $2.000 a $4.000 USD) no se amortiza fácilmente en pilotos con volúmenes reducidos si solo se mide el ahorro de llamadas. Para que un piloto sea financieramente viable, debe resolver un cuello de botella de alto valor añadido (e.g. evitar multas laborales, acelerar en días el cierre de contratos o filtrar cables financieros críticos) y no limitarse a automatizar tareas triviales.

## 4. Explicación técnica

Fórmula de amortización: $\text{Meses para Payback} = \frac{\text{Costo Desarrollo (\$3.000)}}{\text{Valor Mensual Generado} - \text{Costo Operativo}}$. Si el valor generado es inferior a $500 USD/mes, el piloto tardará más de 6 meses en amortizarse.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_10")

def meses_payback_piloto(costo_desarrollo_usd: float, valor_mensual_usd: float, costo_operativo_mes: float) -> float:
    try:
        beneficio_neto = valor_mensual_usd - costo_operativo_mes
        if beneficio_neto <= 0:
            return float("inf")
        return round(costo_desarrollo_usd / beneficio_neto, 1)
    except Exception as err:
        logger.error(f"Fallo en calculo de payback: {type(err).__name__} (detalles omitidos por seguridad)")
        return float("inf")
```

- **Contraejemplo / Caso borde**: Gastar $5.000 USD de ingeniería para automatizar un proceso que solo ahorra $20 USD al mes en un flujo de uso esporádico.

## 8. Validación propuesta

- **Hipótesis Falsable**: Los pilotos enfocados en mitigación de riesgos de alto costo alcanzan el punto de amortización en menos de 90 días.
- **Métricas**: Tiempo transcurrido hasta recuperar el costo de desarrollo del piloto.
- **Criterio de Rechazo**: Payback <= 3 meses post-lanzamiento.
