# JEV-P13-012 — Evaluación de Equivalencia de Interfaz y Calidad entre Jev y Alternativas Abiertas (Jeff)

## 1. Respuesta directa y decisión que permite tomar

La alternativa comunitaria de código abierto conocida como Jeff busca emular la interfaz discriminativa de Jev, pero la compatibilidad a nivel de interfaz no implica equivalencia de calidad ni calibración probabilística. ## 4. Explicación técnica

Evaluación de paridad: Comparar ECE entre Jev ($ECE \approx 0.04$) y Jeff ($ECE \approx 0.14$). Una mayor descalibración en Jeff obliga a ensanchar los márgenes de abstención, reduciendo su rendimiento neto.

import logging

logger = logging.getLogger("P13_12")

def evaluar_paridad_modelos(ece_jev: float, ece_jeff: float, f1_jev: float, f1_jeff: float) -> dict:
    try:
        delta_f1 = f1_jeff - f1_jev
        delta_ece = ece_jeff - ece_jev
        es_sustituible = delta_f1 >= -0.02 and delta_ece <= 0.03
        return {
            "delta_f1": round(delta_f1, 4),
            "delta_ece": round(delta_ece, 4),
            "dictamen": "APROBADO_COMO_ALTERNATIVA" if es_sustituible else "NO_EQUIVALENTE_CALIBRACION_POBRE"
        }
    except Exception as err:
        logger.error(f"Fallo en comparativa de modelos: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"dictamen": "ERROR_EVALUACION"}
