# JEV-P13-001 — Modelo de Cobro Documentado de Jev: Unidades Facturables, Tarifas y Condiciones

## 1. Respuesta directa y decisión que permite tomar

El modelo de cobro oficial documentado de Jev 1.13 por TypeSafe se estructura bajo facturación por volumen de tokens procesados en el endpoint `/v1/systemone` a una tarifa base de $0.042 USD por millón de tokens procesados (aproximadamente $0.000042 por 1K tokens), calculados sumando el tamaño del `state` y la longitud de las preguntas. No existen cobros por tokens de salida generativos autoregresivos ya que la respuesta es un payload estructurado atómico de tamaño despreciable.

## 4. Explicación técnica

Cálculo de costo de inferencia: $\text{Costo} = (\text{Tokens}_{\text{state}} + \text{Tokens}_{\text{questions}}) \times \frac{0.042}{10^6}$. Un payload promedio de 2.000 tokens cuesta $0.000084 USD, haciéndolo dos órdenes de magnitud más económico que modelos frontier como Claude 3.5 Sonnet ($3.00/Mtok input).

def calcular_costo_llamada_jev(longitud_texto_chars: int, tarifa_m_tok: float = 0.042) -> float:
    try:
        # Estimacion conservadora: 4 caracteres por token
        tokens_estimados = max(1, int(longitud_texto_chars / 4))
        costo_usd = (tokens_estimados / 1000000.0) * tarifa_m_tok
        return round(costo_usd, 6)
    except Exception as err:
        logger.error(f"Fallo en calculo de costo: {type(err).__name__} (detalles omitidos por seguridad)")
        return 0.0
