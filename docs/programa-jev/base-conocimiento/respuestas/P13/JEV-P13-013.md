# JEV-P13-013 — Costos Ocultos del Auto-Hosting de Modelos Locales frente a Soluciones Gestionadas

## 1. Respuesta directa y decisión que permite tomar

Alojar modelos de clasificación en servidores propios (vLLM, Triton Inference Server o BentoML) introduce costos ocultos sustanciales que frecuentemente se omiten en comparaciones simplistas: 1) Costo de transferencia de datos de salida (Data Egress); 2) Horas de ingeniería SRE para parches de seguridad, balanceo de carga y autoscaling de GPUs; 3) Pérdidas por infrautilización durante valles nocturnos; y 4) Costo de mantenimiento de drivers NVIDIA CUDA y contenedores.

## 2. Alcance, términos y supuestos

## 4. Explicación técnica

Cálculo de costo oculto: El costo nominal de la instancia de GPU ($0.526 USD/hora en AWS g4dn.xlarge = ~$380 USD/mes) debe incrementarse en un factor de 1.8x a 2.5x para reflejar horas de administración, monitoreo, storage EBS y redundancia multizona, alcanzando ~$800 USD/mes reales.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_13")

def calcular_costo_real_self_hosting(costo_instancia_gpu_mes: float, horas_sre_mes: float = 10.0, costo_hora_sre: float = 45.0) -> float:
    try:
        costo_sre = horas_sre_mes * costo_hora_sre
        costo_red_storage = costo_instancia_gpu_mes * 0.20  # 20% en EBS y transferencia
        costo_total_real = costo_instancia_gpu_mes + costo_sre + costo_red_storage
        return round(costo_total_real, 2)
    except Exception as err:
        logger.error(f"Fallo en calculo de costos ocultos: {type(err).__name__} (detalles omitidos por seguridad)")
        return costo_instancia_gpu_mes * 2.0
```

- **Contraejemplo / Caso borde**: Decidir 'montar un servidor propio porque la GPU cuesta $300' y luego tener que contratar un consultor de $2.000 para configurar Kubernetes y drivers de GPU.
