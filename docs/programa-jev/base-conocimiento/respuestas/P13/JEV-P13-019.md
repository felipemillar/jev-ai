# JEV-P13-019 — Tablero Mínimo de FinOps y Control de Costos en Tiempo Real

## 1. Respuesta directa y decisión que permite tomar

Todo proyecto que opere con Jev debe disponer de un Tablero de FinOps en tiempo real que consolide cuatro métricas fundamentales: 1) Gasto diario acumulado vs presupuesto mensual asignado; 2) Costo medio por decisión unitaria; 3) Tasa de crecimiento de consumo de tokens (análisis de tendencias); y 4) Alerta temprana de anomalías de facturación (e.g. si el gasto diario supera el promedio histórico en más de un 100%). Los incrementos anómalos activan una alerta automática para investigar posibles bucles infinitos de reintento.

## 4. Explicación técnica

Detección de anomalías de gasto: Comparar el gasto de las últimas 24 horas frente a la media móvil de 7 días. Si $G_{\text{hoy}} > 2.0 \cdot \mu_{7d}$, disparar alerta de severidad alta a Slack y correo de FinOps.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_19")

def auditar_anomalia_gasto_finops(gasto_hoy: float, media_7_dias: float) -> dict:
    try:
        if media_7_dias <= 0:
            return {"anomalia": False, "ratio": 1.0}
        ratio = gasto_hoy / media_7_dias
        es_anomalo = ratio >= 2.0 and gasto_hoy > 10.0
        if es_anomalo:
            logger.critical(f"ANOMALIA FINOPS: Gasto actual ({gasto_hoy} USD) duplica la media semanal ({media_7_dias} USD)")
        return {"anomalia": es_anomalo, "ratio": round(ratio, 2)}
    except Exception as err:
        logger.error(f"Fallo en auditoria finops: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"anomalia": False}
```

- **Contraejemplo / Caso borde**: Tener un error en un script que llama a la API en un bucle cerrado infinito durante un fin de semana y enterarse a fin de mes con una factura de miles de dólares.
