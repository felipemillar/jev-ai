# JEV-P13-003 — Costo por Decisión Correcta Aceptada: Más Allá del Precio por Token

## 1. Respuesta directa y decisión que permite tomar

La métrica definitiva de eficiencia económica no es el costo por token ni el costo por llamada, sino el Costo por Decisión Correcta Aceptada (Cost per Correct Accepted Decision, CPCAD). Un modelo extremadamente barato que cometa un 15% de errores o requiera re-clasificación humana constante resulta mucho más costoso por decisión efectiva que un modelo ligeramente más caro con alta precisión y adecuada compuerta de abstención.

## 4. Explicación técnica

Fórmula de CPCAD: $\text{CPCAD} = \frac{C_{\text{Llamada}} + P(\text{Abstención}) \cdot C_{\text{Humano}} + P(\text{Error}) \cdot C_{\text{Fallo}}}{P(\text{Acierto})}$. Si $C_{\text{Fallo}}$ es alto, cualquier mejora en precisión reduce drásticamente el CPCAD.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_03")

def calcular_cpcad(costo_llamada: float, exactitud: float, tasa_abstencion: float, costo_humano: float = 1.5, costo_error: float = 25.0) -> float:
    try:
        tasa_error = max(0.0, 1.0 - exactitud - tasa_abstencion)
        costo_esperado = costo_llamada + (tasa_abstencion * costo_humano) + (tasa_error * costo_error)
        tasa_acierto = max(exactitud, 0.001)
        return round(costo_esperado / tasa_acierto, 4)
    except Exception as err:
        logger.error(f"Fallo en calculo de CPCAD: {type(err).__name__} (detalles omitidos por seguridad)")
        return float("inf")
```

- **Contraejemplo / Caso borde**: Elegir una API gratuita que tiene 75% de exactitud en vez de Jev provocará miles de dólares en costos de remediación por decisiones erróneas.
