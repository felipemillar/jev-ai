# JEV-P13-007 — Sensibilidad de Rentabilidad ante Crecimiento de la Tasa de Escalamiento Humano

## 1. Respuesta directa y decisión que permite tomar

La rentabilidad de un flujo automatizado con Jev es extremadamente sensible a la tasa de escalamiento humano ($P_{\text{escalado}}$). Dado que el costo de la inferencia automática es de ~$0.000084 USD y el costo de una revisión humana manual es de ~$1.00 USD, cada punto porcentual adicional de casos derivados a humanos incrementa el costo medio del flujo en $0.01 USD (un aumento de más del 10.000% sobre el costo de la API). Si la tasa de escalamiento supera el 12%, el flujo pierde su justificación económica frente a la revisión manual pura por lotes.

## 4. Explicación técnica

Derivada de sensibilidad: $\frac{\partial C}{\partial P_{\text{esc}}} = C_{\text{humano}} - C_{\text{api}} \approx C_{\text{humano}}$. El costo unitario es una función lineal con pendiente empinada dominada por el salario de los analistas.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_07")

def evaluar_sensibilidad_escalamiento(tasa_escalado_pct: float, costo_humano: float = 1.0, costo_api: float = 0.0001) -> float:
    try:
        tasa = tasa_escalado_pct / 100.0
        costo_medio_operacion = ((1.0 - tasa) * costo_api) + (tasa * costo_humano)
        return round(costo_medio_operacion, 4)
    except Exception as err:
        logger.error(f"Fallo en analisis de sensibilidad: {type(err).__name__} (detalles omitidos por seguridad)")
        return 0.0
```
