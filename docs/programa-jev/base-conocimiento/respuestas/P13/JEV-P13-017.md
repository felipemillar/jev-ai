# JEV-P13-017 — Presupuesto de Evaluación Previa y Reducción de Incertidumbre Tecnológica

## 1. Respuesta directa y decisión que permite tomar

Antes de comprometer meses de desarrollo en una integración profunda con Jev, los proyectos deben asignar un presupuesto de evaluación previa (PoC Budget) acotado a un máximo de $500 USD de consumo de API y 40 horas de ingeniería. Este presupuesto se destina exclusivamente a ejecutar benchmarks rigurosos sobre datos reales, medir la tasa de exactitud, comprobar la latencia y determinar la tasa de abstención efectiva, reduciendo la incertidumbre tecnológica antes de inversiones mayores.

logger = logging.getLogger("P13_17")

def control_gasto_poc(gasto_acumulado: float, limite_poc_usd: float = 500.0) -> dict:
    try:
        presupuesto_restante = limite_poc_usd - gasto_acumulado
        alcanzo_limite = gasto_acumulado >= limite_poc_usd
        if alcanzo_limite:
            logger.critical("LIMITE DE PRESUPUESTO DE EVALUACION ALCANZADO: Congelar llamadas")
        return {
            "gasto_actual": round(gasto_acumulado, 2),
            "restante": round(max(0.0, presupuesto_restante), 2),
            "puede_continuar": not alcanzo_limite
        }
    except Exception as err:
        logger.error(f"Fallo en control de gasto PoC: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"puede_continuar": False}
