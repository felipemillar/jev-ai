# JEV-P13-020 — Regla Corporativa de Decisión: Construir, Comprar o Descartar (Build vs Buy vs Discard)

## 1. Respuesta directa y decisión que permite tomar

Toda iniciativa del Programa Jev debe someterse a la Regla Corporativa de Decisión tripartita: 1) Construir en local (Build): Solo si el volumen supera 4.5M llamadas/mes, los datos no pueden salir de la red bajo ninguna circunstancia, y el equipo cuenta con ingenieros SRE dedicados; 2) Comprar en SaaS con Jev (Buy): Si el volumen es bajo o medio (<4M llamadas/mes), la tarea exige calibración discriminativa rápida (Sistema 1) y no hay infraestructura propia de GPU; y 3) Descartar (Discard): Si la tarea puede resolverse mediante expresiones regulares en CPU o si el valor generado no compensa el TCO integral.
