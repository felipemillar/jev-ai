# JEV-P12-015 — Gobernanza de Registros de Auditoría: Minimización, Cifrado y Retención Diferenciada

## 1. Respuesta directa y decisión que permite tomar

Los registros de auditoría que documentan decisiones tomadas por Jev deben regirse por una política estricta de ciclo de vida: 1) Los identificadores, hashes y decisiones estructuradas se conservan cifrados en reposo durante 5 años para responder a auditorías financieras y laborales; 2) Los textos completos del campo `state` se purgan o anonimizan irrevocablemente a los 60 días de la transacción para minimizar la exposición de datos personales.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import datetime, logging

logger = logging.getLogger("P12_15")

def determinar_politica_retencion(tipo_dato: str, fecha_registro: datetime.date) -> dict:
    try:
        hoy = datetime.date.today()
        antiguedad_dias = (hoy - fecha_registro).days
        if tipo_dato == "texto_crudo_state":
            debe_purgarse = antiguedad_dias > 60
            return {"accion": "PURGAR" if debe_purgarse else "CONSERVAR", "limite_dias": 60}
        elif tipo_dato == "metadatos_decision":
            debe_purgarse = antiguedad_dias > 1825  # 5 anos
            return {"accion": "PURGAR" if debe_purgarse else "CONSERVAR_GLACIER", "limite_dias": 1825}
        return {"accion": "DESCONOCIDO"}
    except Exception as err:
        logger.error(f"Fallo en evaluacion de retencion: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"accion": "ERROR"}
```

## 8. Validación propuesta

- **Hipótesis Falsable**: La purga automatizada a 60 días reduce el volumen de datos personales almacenados en un 70%.
- **Métricas**: Registros de texto no estructurado con más de 60 días en la base.
- **Criterio de Rechazo**: 0 registros de texto crudo fuera de la ventana de retención.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
