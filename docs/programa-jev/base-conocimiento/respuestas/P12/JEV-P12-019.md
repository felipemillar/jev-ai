# JEV-P12-019 — Runbook Operativo, Procedimientos de Turno y Tiempos de Respuesta del Equipo

## 1. Respuesta directa y decisión que permite tomar

Todo piloto y servicio en producción debe contar con un Runbook Operativo validado que detalle: 1) Matriz de escalamiento con roles claros (Ingeniero de Guardia SRE, Líder Técnico de Dominio, Oficial de Seguridad); 2) Tiempos máximos de respuesta (MTTD < 3 minutos, MTTA < 5 minutos, MTTR < 15 minutos); 3) Comandos exactos de diagnóstico y conmutación manual a fallback; y 4) Plantillas de comunicación de incidentes a clientes.
