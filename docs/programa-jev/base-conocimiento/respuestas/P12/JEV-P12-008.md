# JEV-P12-008 — Fijación Inmutable de Versiones de Modelo, SDK y Taxonomías en Cada Decisión

## 1. Respuesta directa y decisión que permite tomar

Toda decisión emitida en producción debe registrar inmutablemente los metadatos completos de su generación: modelo exacto (`jev-1.13.0`), versión de SDK (`typesafe_sdk 0.7.0`), hash criptográfico de las instrucciones del prompt, versión de la taxonomía de opciones (`Choice`), fecha y hora ISO-8601 con milisegundos, y hash SHA-256 del texto de entrada (`state`). Queda prohibido registrar decisiones huérfanas sin trazabilidad de versión.

import hashlib, time, logging

logger = logging.getLogger("P12_08")

def construir_registro_decision_inmutable(decision_id: str, texto_estado: str, respuesta_dict: dict) -> dict:
    try:
        hash_input = hashlib.sha256(texto_estado.encode("utf-8")).hexdigest()
        return {
            "decision_id": decision_id,
            "version_modelo": "jev-1.13.0",
            "version_sdk": "typesafe_sdk 0.7.0",
            "state_hash_sha256": hash_input,
            "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
            "resultado": respuesta_dict
        }
    except Exception as err:
        logger.error(f"Fallo en registro de auditoria: {type(err).__name__} (detalles omitidos por seguridad)")
        return {}
