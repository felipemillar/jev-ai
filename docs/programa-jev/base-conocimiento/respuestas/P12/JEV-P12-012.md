# JEV-P12-012 — Detección Temprana de Deriva de Entradas (Data Drift) sin Disponibilidad de Etiquetas

## 1. Respuesta directa y decisión que permite tomar

En producción, las etiquetas reales sobre la corrección de una decisión tardan días o semanas en conocerse. Para detectar degradaciones tempranas, el sistema debe monitorear la deriva de datos de entrada (Data Drift) y la deriva de predicciones (Prediction Drift) en tiempo real mediante métodos no supervisados: prueba de Kolmogorov-Smirnov sobre la longitud y vocabulario de los textos en `state`, y divergencia de Kullback-Leibler o Wasserstein sobre las distribuciones de probabilidades predichas.

## 4. Explicación técnica

Métrica Population Stability Index (PSI): $PSI = \sum (P_i - Q_i) \ln(P_i / Q_i)$. Si $PSI > 0.20$ entre la distribución de clases de la semana actual frente a la línea base de entrenamiento, se dispara una alerta preventiva de deriva.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import math, logging

logger = logging.getLogger("P12_12")

def calcular_psi(dist_esperada: list, dist_observada: list) -> float:
    try:
        psi = 0.0
        for p, q in zip(dist_esperada, dist_observada):
            p = max(p, 0.0001)
            q = max(q, 0.0001)
            psi += (q - p) * math.log(q / p)
        return round(psi, 4)
    except Exception as err:
        logger.error(f"Fallo en calculo de PSI: {type(err).__name__} (detalles omitidos por seguridad)")
        return 0.0
```

- **Contraejemplo / Caso borde**: Esperar a que los clientes reclamen por malas recomendaciones para descubrir que el formato de los correos entrantes cambió hace tres semanas.
