# JEV-P06-008: Comparación Pareada sobre Mismas Instancias y Estimación de Incertidumbre de las Diferencias

## 1. Respuesta directa y decisión que permite tomar

Comparar dos sistemas de inteligencia artificial (e.g., Jev 1.13 vs. una línea base de reglas o un LLM estructurado) evaluándolos sobre conjuntos de datos distintos o utilizando pruebas estadísticas para muestras independientes (como el test t de Student no pareado) es un error metodológico que **destruye la potencia estadística y enmascara la covarianza de las predicciones**. Al evaluar ambos sistemas sobre **exactamente las mismas instancias de prueba**, la variabilidad intrínseca del corpus se neutraliza, permitiendo aislar matemáticamente el verdadero aporte de la arquitectura.

Para certificar la superioridad o equivalencia de Jev frente a cualquier comparador, la ingeniería de evaluación debe aplicar el **Protocolo Pareado Tripartito de Significancia e Incertidumbre (PPTSI)**:

1. **Test de McNemar con Corrección por Continuidad (Para Decisiones Binarias/Discretas)**:
   - Se construye la tabla de contingencia de pares discordantes: casos donde Jev acierta y la línea base falla ($b$), frente a casos donde Jev falla y la línea base acierta ($c$):
     $$\chi^2 = \frac{(|b - c| - 1)^2}{b + c} \sim \chi_1^2$$
   - Si $\chi^2 \ge 6.635 \implies p < 0.01$, confirmando que la diferencia observada no es atribuible al azar.
2. **Prueba de Rangos con Signo de Wilcoxon (Para Utilidad y Pérdidas Asimétricas)**:
   - Evaluación pareada sobre el delta de utilidad neta por instancia: $\Delta U_i = U_i(\text{Jev}) - U_i(\text{Baseline})$. No asume normalidad en las ganancias financieras.
3. **Remuestreo Bootstrap Pareado ($B \ge 2,000$ iteraciones)**:
   - Estimación no paramétrica del **Intervalo de Confianza al 95% de la Diferencia ($\Delta_{\text{F1}}$ o $\Delta_{\text{Acc}}$)** mediante percentiles de remuestreo con reemplazo de instancias indexadas.
   - Si el límite inferior del intervalo al $95\%$ es estrictamente mayor a cero ($\text{CI}_{95\%}[\Delta] > 0$), la ventaja de Jev queda formalmente certificada.

**Decisión que permite tomar**: Prohibir la adopción de Jev si el intervalo de confianza bootstrap de la diferencia incluye el cero ($0 \in \text{CI}_{95\%}$) o si el test de McNemar arroja $p \ge 0.01$, manteniendo la línea base actual sin incurrir en costes innecesarios de migración.

## 4. Explicación técnica verificable

### 4.1. La Tabla de Contingencia de McNemar

Para $N$ decisiones evaluadas simultáneamente:

| | Línea Base Acierta | Línea Base Falla | Total |
|---|---|---|---|
| **Jev Acierta** | $a$ (Concordancia positiva) | **$b$ (Gana Jev)** | $a + b$ |
| **Jev Falla** | **$c$ (Gana Línea Base)** | $d$ (Concordancia negativa) | $c + d$ |
| **Total** | $a + c$ | $b + d$ | $N$ |

- La diferencia neta de aciertos es $b - c$.
- El estadístico de prueba con corrección de continuidad de Edwards:
  $$\chi^2 = \frac{(|b - c| - 1)^2}{b + c}$$
- Si $b + c < 25$, se aplica la **Prueba Binomial Exacta** de dos colas bajo la hipótesis nula de que $b \sim \text{Binomial}(b + c, 0.5)$.

### 4.2. Algoritmo de Intervalo de Confianza Bootstrap Pareado

```
DADO: Tuplas pareadas (y_true, pred_jev, pred_base) de longitud N
INICIALIZAR: array de deltas = []
PARA b = 1 HASTA 2,000:
    1. Muestrear N índices con reemplazo: idx ~ Uniforme(0, N-1)
    2. Subconjunto: (y_true[idx], pred_jev[idx], pred_base[idx])
    3. Calcular Métrica_Jev y Métrica_Base sobre la muestra bootstrap
    4. Guardar delta_b = Métrica_Jev - Métrica_Base
ORDENAR array de deltas
INTERVALO_95 = [delta ordenado en percentil 2.5%, delta ordenado en percentil 97.5%]
¿Contiene el 0.0? ──► SÍ: No hay ventaja significativa | NO: Ventaja probada
```

### 5.1. Implementación en Python: Suite de Comparación Pareada y Bootstrap

```python
# Ejemplo ilustrativo no ejecutado
"""
Módulo de Comparación Pareada de Clasificadores (Test de McNemar y Bootstrap CI).
Evalúa la superioridad estadística de Jev frente a líneas base sobre las mismas instancias.
"""

from typing import List, Dict, Any, Tuple
import numpy as np
from scipy import stats
from sklearn.metrics import f1_score
import logging

logger = logging.getLogger("PairedComparator")

class PairedModelEvaluator:
    @staticmethod
    def run_mcnemar_test(
        y_true: np.ndarray, y_pred_jev: np.ndarray, y_pred_base: np.ndarray
    ) -> Dict[str, Any]:
        """
        Calcula el test de McNemar sobre la tabla de pares discordantes.
        """
        try:
            correct_jev = (y_pred_jev == y_true)
            correct_base = (y_pred_base == y_true)

            # b: Jev acierta y Base falla
            b = int(np.sum(correct_jev & ~correct_base))
            # c: Jev falla y Base acierta
            c = int(np.sum(~correct_jev & correct_base))
            # a: Ambos aciertan; d: Ambos fallan
            a = int(np.sum(correct_jev & correct_base))
            d = int(np.sum(~correct_jev & ~correct_base))

            n_discordant = b + c
            if n_discordant == 0:
                return {
                    "mcnemar_statistic": 0.0,
                    "p_value": 1.0,
                    "table": {"a": a, "b": b, "c": c, "d": d},
                    "significant": False,
                    "verdict": "MODELOS_IDENTICOS_EN_DISCORDANCIAS"
                }

            # Si hay pocas discordancias, usar test binomial exacto
            if n_discordant < 25:
                # Test binomial de dos colas con p=0.5
                res_binom = stats.binomtest(b, n_discordant, 0.5, alternative="two-sided")
                p_val = res_binom.pvalue
                stat = float(b)
            else:
                # McNemar chi-cuadrado con corrección de continuidad
                stat = ((abs(b - c) - 1.0) ** 2) / float(n_discordant)
                p_val = stats.chi2.sf(stat, df=1)

            is_sig = p_val < 0.01

            return {
                "mcnemar_statistic": round(float(stat), 4),
                "p_value": float(p_val),
                "table_discordant": {"jev_wins_b": b, "base_wins_c": c},
                "net_difference": b - c,
                "significant_at_1_percent": is_sig,
                "verdict": (
                    "DIFERENCIA_ESTADISTICAMENTE_SIGNIFICATIVA"
                    if is_sig
                    else "NO_HAY_DIFERENCIA_SIGNIFICATIVA"
                )
            }

        except Exception as err:
            logger.error(f"Error en Test de McNemar: {type(err).__name__} (detalles omitidos por seguridad)")
            return {"error": f"Fallo de cálculo: {type(err).__name__}"}

    @staticmethod
    def run_paired_bootstrap_f1(
        y_true: np.ndarray,
        y_pred_jev: np.ndarray,
        y_pred_base: np.ndarray,
        n_bootstraps: int = 2000,
        alpha: float = 0.05
    ) -> Dict[str, Any]:
        """
        Estima el intervalo de confianza de la diferencia de Macro-F1 mediante Bootstrap Pareado.
        """
        try:
            n = len(y_true)
            delta_f1_samples = []

            for _ in range(n_bootstraps):
                indices = np.random.randint(0, n, size=n)
                f1_j = f1_score(y_true[indices], y_pred_jev[indices], average="macro", zero_division=0)
                f1_b = f1_score(y_true[indices], y_pred_base[indices], average="macro", zero_division=0)
                delta_f1_samples.append(f1_j - f1_b)

            delta_f1_samples = np.sort(delta_f1_samples)
            lower_idx = int((alpha / 2.0) * n_bootstraps)
            upper_idx = int((1.0 - alpha / 2.0) * n_bootstraps)

            ci_lower = delta_f1_samples[lower_idx]
            ci_upper = delta_f1_samples[upper_idx]
            mean_delta = np.mean(delta_f1_samples)

            # Si el límite inferior es > 0, Jev es superior con (1 - alpha)% de confianza
            is_strictly_positive = ci_lower > 0.0

            return {
                "mean_delta_f1": round(float(mean_delta), 4),
                "confidence_interval_95": [round(float(ci_lower), 4), round(float(ci_upper), 4)],
                "zero_excluded": is_strictly_positive,
                "verdict": (
                    "JEV_SUPERIOR_CON_CERTEZA_ESTADISTICA"
                    if is_strictly_positive
                    else "EQUIVALENCIA_O_VENTAJA_NO_CONCLUYENTE"
                )
            }

        except Exception as err:
            logger.error(f"Error en Bootstrap Pareado: {type(err).__name__} (detalles omitidos por seguridad)")
            return {"error": f"Fallo de cálculo: {type(err).__name__}"}


if __name__ == "__main__":
    np.random.seed(42)
    N = 1000
    y_true_sim = np.random.choice([0, 1], size=N, p=[0.70, 0.30])

    # Jev tiene una ligera ventaja: acierta el 92% vs 87% de la línea base
    pred_jev = np.array([y if np.random.rand() < 0.92 else 1 - y for y in y_true_sim])
    pred_base = np.array([y if np.random.rand() < 0.87 else 1 - y for y in y_true_sim])

    evaluator = PairedModelEvaluator()

    # 1. McNemar
    res_mcnemar = evaluator.run_mcnemar_test(y_true_sim, pred_jev, pred_base)
    print("--- Resultado Test de McNemar Pareado ---")
    print(f"Estadístico: {res_mcnemar['mcnemar_statistic']} | p-value: {res_mcnemar['p_value']:.6f}")
    print("Veredicto:", res_mcnemar["verdict"])
    print("Tabla Discordante:", res_mcnemar["table_discordant"])

    # 2. Bootstrap Pareado
    res_boot = evaluator.run_paired_bootstrap_f1(y_true_sim, pred_jev, pred_base, n_bootstraps=1000)
    print("\n--- Resultado Bootstrap Pareado (Macro-F1) ---")
    print(f"Delta Medio F1: {res_boot['mean_delta_f1']}")
    print(f"IC 95%: {res_boot['confidence_interval_95']}")
    print("Veredicto:", res_boot["verdict"])
```

### 5.2. Caso Límite / Contraejemplo

Un equipo evaluó a Jev contra un modelo de reglas en un conjunto de 500 correos de soporte.
- Reportaron: *"Jev obtuvo 91.2% de exactitud y las reglas 89.6% (+1.6% a favor de Jev)"*.
- Al realizar la prueba de McNemar sobre los mismos 500 correos:
  - En 420 casos ambos acertaron.
  - En 30 casos ambos fallaron.
  - En **26 casos Jev acertó y las reglas fallaron ($b=26$)**.
  - En **24 casos las reglas acertaron y Jev falló ($c=24$)**.
- Estadístico $\chi^2 = \frac{(|26 - 24| - 1)^2}{26 + 24} = \frac{1}{50} = 0.02 \implies p = 0.887$.
- El intervalo de confianza al 95% de la diferencia abarcaba desde **$-2.4\%$ hasta $+5.6\%$**.
- **La realidad**: No existía ninguna superioridad estadística; el $+1.6\%$ era puro ruido aleatorio. Si el equipo hubiera desplegado Jev, hubiera incurrido en costes de API y latencia sin ninguna ganancia real de precisión.
- **Lección**: La diferencia aparente de porcentajes sin prueba pareada es una ilusión estadística.

- **Hipótesis de desarrollo**: QRT debe forzar la evaluación **Tick-by-Tick Pareada**: evaluar la señal con filtro Jev vs. la señal sin filtro sobre exactamente los mismos timestamps de mercado. Se exigirá que el **Paired Bootstrap de la diferencia de Sharpe Ratio** excluya el cero en el percentil 2.5% antes de comprometer capital en paper trading.

## 7. Fallos, límites, controles y condiciones de no uso

### 7.1. Modos de Fallo
1. **Pares Artificiales por Promedios**: Intentar emparejar métricas agregadas por día en lugar de emparejar las decisiones individuales caso por caso a nivel de fila.
2. **Ignorar el Coste de Error de los Pares Discordantes**: Celebrar que Jev gana $b=30$ veces y pierde $c=10$ veces, sin verificar si los 10 casos donde Jev falló implicaron pérdidas financieras que superaron el valor de los 30 aciertos.

### 7.2. Controles Mandatorios
- **Log de Contingencia Discordante**: Todo reporte comparativo debe incluir la matriz $2 \times 2$ de aciertos y fallos cruzados ($a, b, c, d$).
- **Mínimo de 2,000 Réplicas Bootstrap**: Para que el intervalo de confianza sea numéricamente estable.

### 7.3. Condiciones de No Uso
- Prohibido afirmar que Jev es "superior" si el test de McNemar arroja $p \ge 0.01$ o si el intervalo de confianza bootstrap de la diferencia incluye el cero.
