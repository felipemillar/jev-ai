# JEV-P09-001 — Interfaz Oficial de Jev: Endpoints, Contrato POST /v1/systemone y Verificabilidad

## 1. Respuesta directa y decisión que permite tomar

La interfaz oficial verificada de Jev 1.13 es exclusivamente el endpoint HTTP `POST /v1/systemone`. No existen endpoints de streaming de tokens, WebSockets ni interfaces gRPC públicas en la especificación del proveedor. El contrato exige un payload JSON con dos campos obligatorios: `state` (cadena de texto no estructurada de hasta 32 KB) y `questions` (diccionario donde cada clave mapea a una primitiva `Choice`, `Score` o `Noul`). La respuesta devuelve un objeto JSON con las decisiones estructuradas en el diccionario `answers`.

## 2. Alcance, términos y supuestos

- **Ámbito de JEV-P09-001**: Bajo las directrices de P09, JEV-P09-001 circunscribe la inferencia requerida en «¿Cuál es la interfaz oficial disponible de Jev para la versión estudiada y qué partes del contrato pueden verificarse en documentación original».
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk==0.7.0` / `POST /v1/systemone`).
- **Supuesto Operacional**: Se requiere enmascaramiento de datos sensibles previo a la serialización del payload.

## 4. Explicación técnica

Protocolo: HTTP/1.1 o HTTP/2 sobre TLS 1.3. Cabeceras obligatorias: `Authorization: Bearer <API_KEY>`, `Content-Type: application/json`. Códigos de retorno documentados: 200 OK, 400 Bad Request (payload > 32KB o JSON malformado), 401 Unauthorized, 422 Unprocessable Entity (violación de esquema de pregunta) y 429 Too Many Requests.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("P09_01")

def consultar_api_oficial(texto_entrada: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(
            state=texto_entrada,
            questions={"tipo": Choice(instructions="Tipo de documento", criteria={"factura": "Documento tributario de factura mercantil", "boleta": "Boleta de compraventa o servicios", "guia": "Guía de despacho o traslado"})}
        )
        ans = res.answers["tipo"]
        return {"decision": ans.choice, "confianza": ans.confidence}
    except Exception as err:
        logger.error(f"Fallo en consulta oficial: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"status": "error"}
```

- **Contraejemplo / Caso borde**: Intentar abrir una conexión WebSocket o pasar un parámetro `stream=True` producirá un error HTTP 400 o será ignorado por el backend, ya que Jev no es un LLM generativo autoregresivo.
