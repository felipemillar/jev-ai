# JEV-P09-014 — Pruebas de Contrato y Respuestas Simuladas (Mocking) sin Consumo de Cuota

## 1. Respuesta directa y decisión que permite tomar

El desarrollo y las pruebas continuas (CI/CD) deben realizarse utilizando pruebas de contrato y servidores simulados (mocks) que emulen fielmente el payload JSON de `Choice`, `Score` y `Noul`. Queda prohibido ejecutar suites de pruebas automatizadas contra la API real de TypeSafe en pipelines de CI para evitar costos innecesarios, agotamiento de cuota y falsos negativos por fluctuaciones de red. Se recomienda el uso de librerías como `respx` o `unittest.mock`.

## 4. Explicación técnica

Mocking hermético: Interceptar llamadas HTTP salientes a `api.typesafe.ai` y devolver estructuras conformes: `{'answers': {'q1': {'type': 'choice', 'choice': 'A', 'probabilities': {'A': 0.9, 'B': 0.1}, 'confidence': 0.9}}}`.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import unittest
from unittest.mock import MagicMock
from typesafe_sdk import Choice

class TestContratosJev(unittest.TestCase):

    def test_mock_respuesta_choice(self):
        cliente_mock = MagicMock()
        respuesta_falsa = MagicMock()
        respuesta_falsa.answers = {'clasificacion': MagicMock(choice='categoria_a', confidence=0.95)}
        cliente_mock.system_one.return_value = respuesta_falsa
        res = cliente_mock.system_one(state='Texto de prueba', questions={'clasificacion': Choice(instructions='Tipo', criteria={'categoria_a': 'Categoría operacional tipo A', 'categoria_b': 'Categoría operacional tipo B'})})
        self.assertEqual(res.answers['clasificacion'].choice, 'categoria_a')
        self.assertGreater(res.answers['clasificacion'].confidence, 0.9)
```

- **Contraejemplo / Caso borde**: Ejecutar 500 pruebas unitarias en GitHub Actions contra la API real provocará un bloqueo temporal por rate limiting (HTTP 429) y costos no presupuestados.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Pruebas unitarias atadas a red real | Falsos fallos de CI por red o cuota | Mocking obligatorio en pre-commit | Aislar suite unitaria con unittest.mock |
| Corte total de conectividad saliente | Caída del servicio dependiente | Monitoreo sintético cada 60s | Conmutación automática a clasificador determinista local |
| Variación no notificada en contrato | Errores 422 en llamadas de API | Pruebas de contrato diarias en CI | Fijar versión y alertar ante discrepancias |
