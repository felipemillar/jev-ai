# JEV-P16-009 — Exclusión de Atributos Sensibles y Variables Proxy en Criterios de Evaluación

## 1. Respuesta directa y decisión que permite tomar

No basta con eliminar las variables protegidas directas (género, edad, RUT); el sistema debe erradicar activamente las variables proxy que correlacionan indirectamente con clases protegidas (e.g. nombre de instituciones educativas de élite, códigos postales, actividades extracurriculares socialmente estratificadas). Las instrucciones de Jev deben formularse centrándose exclusivamente en habilidades funcionales verificables, auditando periódicamente la distribución de resultados por subgrupos demográficos.

## 4. Explicación técnica

Prueba estadística de Disparate Impact: $\text{AIR} = \frac{\text{Tasa Selección Grupo Protegido}}{\text{Tasa Selección Grupo Control}}$. Si $\text{AIR} < 0.80$, el modelo presenta impacto adverso indirecto y el proceso de filtrado debe detenerse para reentrenamiento.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P16_09")

def auditar_disparate_impact(seleccionados_grupo_a: int, total_a: int, seleccionados_grupo_b: int, total_b: int) -> dict:
    try:
        tasa_a = seleccionados_grupo_a / max(total_a, 1)
        tasa_b = seleccionados_grupo_b / max(total_b, 1)
        if max(tasa_a, tasa_b) <= 0:
            return {"air": 1.0, "conforme": True}
        air = min(tasa_a, tasa_b) / max(tasa_a, tasa_b)
        es_conforme = air >= 0.80
        return {"air": round(air, 3), "conforme_regla_4_5": es_conforme}
    except Exception as err:
        logger.error(f"Fallo en calculo de disparate impact: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"conforme_regla_4_5": False}
```
