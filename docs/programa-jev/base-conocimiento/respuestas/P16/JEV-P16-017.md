# JEV-P16-017 — Requisitos de Privacidad, Consentimiento y Retención Legal en Selección de Personal

## 1. Respuesta directa y decisión que permite tomar

Antes de utilizar datos curriculares reales en cualquier sistema asistido por IA, la consultora debe comprobar formalmente: 1) Consentimiento informado explícito del postulante para el tratamiento de su información mediante herramientas tecnológicas; 2) Política de retención que elimine automáticamente los CVs de candidatos no seleccionados tras 12 meses; y 3) Canal abierto para ejercer los derechos ARCO (Acceso, Rectificación, Cancelación y Oposición) conforme a la Ley 19.628.

## 4. Explicación técnica

Pila de cumplimiento legal: Verificación en base de datos del flag `consentimiento_ia_firmado == true` antes de enviar el texto al microservicio de Jev. Si el flag es falso, el CV se deriva exclusivamente al proceso manual tradicional.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P16_17")

def verificar_consentimiento_candidato(metadata_postulante: dict) -> bool:
    try:
        consentimiento = metadata_postulante.get("consentimiento_ia_firmado", False)
        if not consentimiento:
            logger.info("Candidato no autorizo procesamiento automatizado; derivando a flujo 100% manual")
            return False
        return True
    except Exception as err:
        logger.error(f"Fallo en verificador de consentimiento: {type(err).__name__} (detalles omitidos por seguridad)")
        return False
```

- **Contraejemplo / Caso borde**: Procesar currículums extraídos de redes sociales o recibidos por correo sin consentimiento informado para alimentar la base de datos de IA.
