# JEV-P16-013 — Detección de Información Faltante y Propuesta de Preguntas de Aclaración

## 1. Respuesta directa y decisión que permite tomar

Cuando un currículum, contrato o solicitud comercial carece de datos indispensables para emitir una decisión fundada (e.g. un CV que no indica nivel de inglés en un cargo bilingüe, o un contrato que omite la jornada laboral), Jev no debe asumir ni adivinar los datos faltantes mediante inferencias probabilísticas. El sistema debe clasificar el expediente como `informacion_incompleta` y generar una lista de preguntas de aclaración objetivas para formular al solicitante.

## 4. Explicación técnica

Compuerta de completitud con `Choice(instructions='Verificar completitud del perfil profesional', criteria={'perfil_completo': 'Perfil con datos curriculares completos', 'falta_idioma': 'Omisión de acreditación de idioma requerido', 'falta_certificacion': 'Omisión de certificaciones técnicas clave', 'incompleto_general': 'Antecedentes insuficientes para evaluación'})`. Si la salida es incompleta, el flujo propone un correo de consulta breve y neutral.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P16_13')

def detectar_omisiones_en_perfil(cv_resumen: str) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=cv_resumen, questions={'estado_completitud': Choice(instructions='Verificar si se especifican anos de experiencia y titulacion', criteria={'completo_para_evaluar': 'Perfil contiene años de ejercicio profesional y acreditación de título', 'falta_anos_experiencia': 'Perfil omite detalle cronológico de años de experiencia', 'falta_titulo_formal': 'Perfil omite acreditación de titulación o certificación requerida'})})
        ans = res.answers['estado_completitud']
        requiere_pregunta = ans.choice != 'completo_para_evaluar'
        return {'estado': ans.choice, 'requiere_aclaracion': requiere_pregunta}
    except Exception as err:
        logger.error(f'Fallo en detector de omisiones: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'estado': 'completo_para_evaluar', 'requiere_aclaracion': False}
```

- **Contraejemplo / Caso borde**: Suponer que un candidato habla inglés fluido porque estudió una carrera técnica en informática, descartándolo más tarde en la entrevista.
