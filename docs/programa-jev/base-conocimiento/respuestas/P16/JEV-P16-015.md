# JEV-P16-015 — Evaluación de Consistencia Inter-Evaluador antes de Atribuir Errores a Jev

## 1. Respuesta directa y decisión que permite tomar

Antes de culpar a Jev por discrepancias en la evaluación de perfiles de talento, la consultora debe medir el coeficiente de acuerdo inter-evaluador humano (Kappa de Cohen o Fleiss) entre sus propios consultores de selección. En reclutamiento, el desacuerdo humano entre entrevistadores sobre un mismo candidato suele superar el 30%. Si dos consultores humanos no coinciden entre sí en sus evaluaciones, el modelo de IA no puede alcanzar una precisión artificialmente superior a la concordancia humana base.

## 4. Explicación técnica

Medición previa de concordancia humana: Calcular $\kappa$ sobre 50 perfiles evaluados a ciegas por tres consultores de Wheelwork. Solo las categorías donde $\kappa \ge 0.70$ se consideran válidas como ground truth para calibrar a Jev.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P16_15")

def calcular_concordancia_kappa_dos_jueces(acuerdos_totales: int, evaluados_totales: int, acuerdo_azar_esperado: float = 0.5) -> dict:
    try:
        if evaluados_totales <= 0:
            return {"kappa": 0.0, "calidad": "INSUFICIENTE"}
        p_observada = acuerdos_totales / evaluados_totales
        kappa = (p_observada - acuerdo_azar_esperado) / (1.0 - acuerdo_azar_esperado)
        calidad = "CONCORDANCIA_ALTA" if kappa >= 0.70 else "DESACUERDO_HUMANO_ELEVADO"
        return {"kappa": round(kappa, 3), "calidad": calidad}
    except Exception as err:
        logger.error(f"Fallo en calculo de Kappa: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"kappa": 0.0, "calidad": "ERROR"}
```
