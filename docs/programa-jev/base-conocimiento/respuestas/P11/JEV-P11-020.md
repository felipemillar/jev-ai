# JEV-P11-020 — Procedimiento Formal de Respuesta a Incidentes de Seguridad y Auditoría Forense

## 1. Respuesta directa y decisión que permite tomar

Ante la confirmación de un incidente de seguridad (e.g. evasión exitosa de guardrail o fuga de datos), debe ejecutarse un protocolo estandarizado de respuesta a incidentes en cuatro fases: 1) Contención inmediata (activación de Kill Switch y conmutación a fallback local); 2) Preservación de evidencia forense (aislamiento de logs y volcados criptográficos sin divulgar información sensible); 3) Erradicación y parcheo (actualización de reglas regex y re-entrenamiento o afinamiento de instrucciones); y 4) Análisis post-mortem y notificación a partes interesadas.

## 4. Explicación técnica

Preservación forense segura: Copiar los logs de la sesión afectada a un bucket de almacenamiento inmutable con Object Lock (WORM: Write Once, Read Many) para evitar que el atacante o el equipo alteren los registros durante la investigación.

```python
# Ejemplo ilustrativo no ejecutado
import time, logging

logger = logging.getLogger("P11_20")

def iniciar_protocolo_incidente(incidente_id: str, tipo_evento: str) -> dict:
    try:
        timestamp_inicio = time.time()
        logger.critical(f"INCIDENTE DECLARADO [{incidente_id}]: {tipo_evento}")
        
        # Paso 1: Contencion
        paso_contencion = "KILL_SWITCH_DISPARADO"
        # Paso 2: Preservacion forense
        paso_forense = "LOGS_BLOQUEADOS_EN_BUCKET_WORM"
        
        return {
            "incidente": incidente_id,
            "estado": "EN_CONTENCION",
            "timestamp": timestamp_inicio,
            "acciones": [paso_contencion, paso_forense]
        }
    except Exception as err:
        logger.error(f"Fallo en protocolo de incidente: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"estado": "FALLO_CRITICO"}
```

## 8. Validación propuesta

- **Hipótesis Falsable**: La aplicación del protocolo formal reduce el tiempo de contención de incidentes a menos de 5 minutos.

- **Criterio de Rechazo**: Contención en < 5 minutos y 100% de evidencia preservada.
