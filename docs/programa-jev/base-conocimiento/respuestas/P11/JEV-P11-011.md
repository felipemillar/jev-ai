# JEV-P11-011 — Limitación Determinista de Herramientas y Parámetros Permitidos (Least Privilege)

## 1. Respuesta directa y decisión que permite tomar

El principio de mínimo privilegio exige restringir el conjunto de herramientas expuestas al modelo exclusivamente a aquellas estrictamente indispensables para la tarea en curso. Queda terminantemente prohibido confiar en que el modelo 'obedecerá' una instrucción textual como 'no uses la herramienta de eliminación de base de datos'. La restricción debe ser técnica y determinista: la herramienta no debe existir en la lista retornada por `tools/list` para ese contexto específico.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P11_11")

class ControlHerramientasMCP:
    def __init__(self, rol_usuario: str):
        self.rol = rol_usuario
        self.permisos = {
            "auditor": ["leer_fuente", "consultar_resumen"],
            "admin": ["leer_fuente", "consultar_resumen", "actualizar_indice"]
        }

    def filtrar_herramientas_para_sesion(self, catalogo_completo: list) -> list:
        try:
            permitidas = set(self.permisos.get(self.rol, ["leer_fuente"]))
            return [h for h in catalogo_completo if h.get("name") in permitidas]
        except Exception as err:
            logger.error(f"Fallo en filtrado de herramientas: {type(err).__name__} (detalles omitidos por seguridad)")
            return []
```

## 8. Validación propuesta

- **Hipótesis Falsable**: El filtrado determinista de herramientas en el handshake reduce la superficie de ataque en un 70%.
- **Métricas**: Número de herramientas críticas accesibles por agentes de lectura.
- **Criterio de Rechazo**: 0 herramientas de escritura expuestas en perfiles de consulta.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
