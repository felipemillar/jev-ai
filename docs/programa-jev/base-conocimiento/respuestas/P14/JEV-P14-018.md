# JEV-P14-018 — Indicadores de Dependencia Excesiva y Aumento del Trabajo de Supervisión

## 1. Respuesta directa y decisión que permite tomar

El sistema debe registrar telemetría sobre el propio comportamiento del usuario para detectar dos patologías opuestas: 1) Complacencia acrítica (aprobar el 100% de las sugerencias del modelo en menos de 200 ms sin leer, lo que indica pérdida de control humano); y 2) Fatiga de supervisión (pasar más de 30 minutos diarios corrigiendo propuestas del modelo, lo que indica que el clasificador está descalibrado y destruyendo tiempo). Ambos indicadores activan una recomendación de pausa del flujo.
