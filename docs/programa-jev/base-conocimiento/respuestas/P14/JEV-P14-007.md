# JEV-P14-007 — Detección de Solicitudes y Compromisos en Mensajes: Tareas Firmes vs Sugerencias

## 1. Respuesta directa y decisión que permite tomar

El análisis semántico de mensajes recibidos (correos, notas de chat) debe diferenciar con alta precisión entre tres categorías pragmáticas: 1) Tarea Firme con compromiso vinculante (e.g. 'me comprometo a enviar el informe el viernes'); 2) Sugerencia o idea abierta sin obligación (e.g. 'podríamos revisar esto más adelante'); y 3) Condición pendiente subordinada a terceros (e.g. 'si Juan aprueba el presupuesto, avanzamos'). Jev debe categorizar la fuerza ilocucionaria del texto mediante `Choice` cerrada.

## 4. Explicación técnica

Clasificación pragmática cerrada: Instruir a Jev para que identifique verbos modales, condicionantes ('si', 'en caso de') y marcas temporales explícitas antes de clasificar un texto como tarea firme.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P14_07')

def clasificar_compromiso_mensaje(extracto_mensaje: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=extracto_mensaje, questions={'tipo_compromiso': Choice(instructions='Determinar fuerza del compromiso expresado', criteria={'tarea_firme_vinculante': 'Compromiso formal firme y vinculante con fecha', 'sugerencia_abierta': 'Sugerencia o propuesta abierta sin obligación', 'condicion_pendiente': 'Compromiso sujeto a condición precedente', 'sin_compromiso': 'Expresión informativa sin asunción de compromiso'})})
        return res.answers['tipo_compromiso'].choice
    except Exception as err:
        logger.error(f'Fallo en extraccion de compromiso: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'sin_compromiso'
```

- **Contraejemplo / Caso borde**: Crear automáticamente una tarea urgente en el gestor de proyectos porque alguien escribió 'quizás deberíamos tomar un café algún día' satura la agenda de ruido.
