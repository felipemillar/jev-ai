## 1. Respuesta directa y decisión que permite tomar

El asistente personal no debe intentar resolver todas las dudas mediante un único modelo de lenguaje. def enrutar_consulta_asistente(consulta_texto: str) -> str:
    try:
        # Deteccion rapida de calculo determinista
        if any(char in "+-*/=" for char in consulta_texto) and any(c.isdigit() for c in consulta_texto):
            return "MOTOR_CALCULO_PYTHON"
