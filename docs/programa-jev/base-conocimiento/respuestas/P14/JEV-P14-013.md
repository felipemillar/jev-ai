# JEV-P14-013 — Clasificación de Gastos Sintéticos sin Delegación de Cálculos ni Pagos

## 1. Respuesta directa y decisión que permite tomar

En flujos personales de control de presupuesto, Jev debe utilizarse exclusivamente para inferir la categoría cualitativa del gasto (e.g. 'alimentación', 'hardware', 'transporte') a partir del texto no estructurado de la descripción de la transacción. Queda terminantemente prohibido delegar en Jev: la suma de montos, el cálculo de impuestos, la verificación de saldos o la autorización de pagos. Toda la aritmética y persistencia contable debe residir en código determinista en Python o base relacional.

## 4. Explicación técnica

Contrato de pre-clasificación: Entrada: descripción textual (`state = 'Compra de cables HDMI en tienda local'`). Jev devuelve `Choice` con la categoría. El monto monetario se extrae mediante regex y se suma en variables `Decimal` de Python.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
from decimal import Decimal
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P14_13')

def categorizar_gasto_personal(descripcion: str, monto_str: str) -> dict:
    try:
        monto = Decimal(monto_str)
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=descripcion, questions={'categoria': Choice(instructions='Tipo de gasto', criteria={'tecnologia': 'Gasto en infraestructura tecnológica y software', 'alimentacion': 'Gasto en alimentación o catering corporativo', 'viaticos': 'Gasto en viáticos y traslados de personal'})})
        return {'monto_contabilizado': float(monto), 'categoria_asignada': res.answers['categoria'].choice, 'estado': 'PENDIENTE_CONFIRMACION_USUARIO'}
    except Exception as err:
        logger.error(f'Fallo en clasificador de gastos: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'estado': 'ERROR'}
```

- **Contraejemplo / Caso borde**: Pedirle a un modelo que 'calcule el total de las facturas sumando los textos' terminará en inconsistencias contables por redondeos o sumas fantasma.
