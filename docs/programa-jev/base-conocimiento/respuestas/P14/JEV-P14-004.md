# JEV-P14-004 — Cálculo Riguroso del Tiempo Neto Ahorrado (Net Time Saved)

## 1. Respuesta directa y decisión que permite tomar

El éxito de un flujo personal automatizado no se mide por la cantidad de tareas procesadas por el modelo, sino por el Tiempo Neto Ahorrado ($T_{\text{neto}}$). El cálculo debe restar explícitamente del tiempo manual previo: el tiempo invertido en preparar los datos, el tiempo de supervisión o revisión de las propuestas del modelo, el tiempo de corrección de falsos positivos y las horas dedicadas a reparar scripts o adaptar librerías. Si $T_{\text{neto}} \le 0$, el flujo debe desmantelarse inmediatamente.

## 4. Explicación técnica

Fórmula de Tiempo Neto: $T_{\text{neto}} = T_{\text{manual}} - (T_{\text{preparación}} + T_{\text{revisión}} + T_{\text{corrección}} + T_{\text{mantenimiento}})$. Si una tarea manual toma 2 horas al mes y mantener el script toma 3 horas, la automatización destruye productividad.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P14_04")

def calcular_tiempo_neto_ahorrado_horas(t_manual: float, t_prep: float, t_rev: float, t_corr: float, t_mant: float) -> dict:
    try:
        costo_automatizacion = t_prep + t_rev + t_corr + t_mant
        t_neto = t_manual - costo_automatizacion
        return {
            "tiempo_neto_horas": round(t_neto, 2),
            "aporta_valor": t_neto > 0.0,
            "eficiencia_pct": round((t_neto / max(t_manual, 0.1)) * 100.0, 1)
        }
    except Exception as err:
        logger.error(f"Fallo en calculo de tiempo neto: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"tiempo_neto_horas": 0.0, "aporta_valor": False}
```
