# JEV-P14-010 — Detección de Duplicados en Documentos Personales con Preservación de Versiones

## 1. Respuesta directa y decisión que permite tomar

El organizador de archivos personales debe detectar duplicados y documentos estrechamente relacionados mediante comparación semántica de resúmenes y hashes SHA-256 de contenido, pero prohibiendo proponer el borrado automático de archivos. El sistema debe limitarse a agrupar los archivos como 'versiones de una misma entidad' o 'documentos redundantes', sugiriendo el archivado de borradores viejos pero manteniendo intacto el sistema de archivos hasta que el usuario decida manualmente.

## 4. Explicación técnica

Detección de similitud en 2 niveles: Nivel 1 (Hash SHA-256 idéntico -> duplicado exacto, sugerir descarte de copia); Nivel 2 (Jev evalúa si el borrador B sustituye conceptualmente al borrador A mediante `Noul` de equivalencia semántica).

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Noul

logger = logging.getLogger("P14_10")

def evaluar_equivalencia_borradores(texto_v1: str, texto_v2: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        prompt = f"DOCUMENTO A:\n{texto_v1[:4000]}\nDOCUMENTO B:\n{texto_v2[:4000]}"
        res = client.system_one(
            state=prompt,
            questions={"equivalente": Noul(instructions="Determinar si B es una revision identica en contenido a A")}
        )
        p_equiv = res.answers["equivalente"].noul
        return {
            "son_equivalentes": p_equiv >= 0.85,
            "certeza": abs(2 * p_equiv - 1),
            "recomendacion": "ARCHIVAR_V1_EN_HISTORICO" if p_equiv >= 0.85 else "CONSERVAR_AMBOS"
        }
    except Exception as err:
        logger.error(f"Fallo en comparativa de borradores: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"recomendacion": "CONSERVAR_AMBOS"}
```

## 8. Validación propuesta

- **Hipótesis Falsable**: La agrupación semántica de versiones reduce el desorden visual del disco en un 60% con 0 pérdidas de borradores.
- **Métricas**: Archivos duplicados consolidados sin incidentes de pérdida.
- **Criterio de Rechazo**: 100% de borradores históricos accesibles en carpeta de archivo.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
