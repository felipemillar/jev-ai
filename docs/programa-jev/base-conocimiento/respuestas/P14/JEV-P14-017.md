# JEV-P14-017 — Diseño de Interfaz Minimalista: Decisión, Evidencia Breve y Opción de Corregir

## 1. Respuesta directa y decisión que permite tomar

La interfaz de usuario para flujos personales no debe saturar al usuario con párrafos explicativos extensos que obliguen a perder tiempo leyendo la justificación del modelo. La pantalla debe presentar exclusivamente tres elementos concisos: 1) La decisión o etiqueta propuesta (e.g. `URGENTE`); 2) La evidencia mínima directa (una frase de hasta 15 palabras extraída del texto original); y 3) Un botón de un solo clic para corregir la categoría si el modelo falló.

Estructura de la tarjeta visual (UI Card): Encabezado con etiqueta + Píldora de extracto textual + Menú desplegable o botones rápidos de reasignación. El clic de corrección actualiza inmediatamente la base local de reglas.
