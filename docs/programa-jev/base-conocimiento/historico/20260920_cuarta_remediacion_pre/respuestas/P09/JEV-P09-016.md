# JEV-P09-016 — Detección de Respuestas Truncadas y Resultados Parciales en Conectores

## 1. Respuesta directa y decisión que permite tomar

Los conectores MCP y los clientes de investigación deben inspeccionar activamente indicadores de truncamiento, longitudes de payload y banderas de finalización (`finish_reason`, `is_truncated`) en las respuestas recibidas. Asumir que una respuesta devuelta por NotebookLM o por un conector MCP representa la totalidad del texto o evidencia disponible sin validar estos metadatos induce a conclusiones incompletas y sesgos de confirmación.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Integridad de datos en la recuperación de respuestas extensas y auditoría de completitud.
- **Supuesto clave**: Conectividad saliente HTTPS habilitada hacia los endpoints oficiales de TypeSafe.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Protocolo de integración de Antigravity: los archivos `transcript.jsonl` marcan explícitamente `is_truncated: true` cuando el contenido excede límites de buffer.
- **Contraste de hipótesis**: Se descartan integraciones basadas en suposiciones de APIs genéricas de OpenAI o protocolos no oficiales.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Verificación de completitud: Si la respuesta contiene la clave `is_truncated: true` o si la longitud de la cadena coincide exactamente con la potencia de dos del buffer (e.g. 4096, 8192 bytes), el conector debe solicitar paginación adicional o marcar la evidencia como `parcial_truncada`.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P09_16")

def evaluar_integridad_respuesta(datos_respuesta: dict) -> dict:
    try:
        texto = datos_respuesta.get("content", "")
        truncado = datos_respuesta.get("is_truncated", False)
        if truncado or len(texto) >= 65536:
            logger.warning("Respuesta identificada como truncada o al limite de buffer")
            return {"estado": "incompleto", "contenido": texto, "requiere_paginacion": True}
        return {"estado": "completo", "contenido": texto, "requiere_paginacion": False}
    except Exception as err:
        logger.error(f"Fallo al auditar respuesta: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"estado": "error"}
```
