# JEV-P08-010 — El Patrón Sandwich: Recuperación Previa, Juicio Tipado y Síntesis Posterior

## 1. Respuesta directa y decisión que permite tomar

El patrón arquitectónico Sandwich estructura el flujo en tres fases rigurosas: (1) Recuperación determinista de evidencia verificada (vía BM25 o embeddings en CPU); (2) Juicio semántico rápido mediante Jev 1.13 para certificar pertinencia o veracidad sin alucinaciones; (3) Generación explicativa opcional con un modelo frontier condicionada estrictamente a que Jev haya otorgado un dictamen aprobatorio previo.

## 2. Alcance, términos, versiones y supuestos

- **Alcance Operacional**: Arquitectura híbrida de generación fundamentada (RAG) con compuertas semánticas de validación.
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk 0.7.0` / `POST /v1/systemone`).
- **Supuestos Críticos**: Las decisiones semánticas son puramente consultivas; la ejecución y mutación de estado residen exclusivamente en componentes deterministas en CPU.

## 4. Explicación técnica verificable

Desacoplamiento: El recuperador aporta hechos; Jev valida con Noul si los hechos sustentan la hipótesis; el LLM generativo redacta la narrativa citando las fuentes certificadas por Jev.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
import logging
from typesafe_sdk import TypeSafeClient, Noul
logger = logging.getLogger('P08_10')

def compuerta_sandwich(evidencia: str, postulado: str) -> bool:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=f'Evidencia: {evidencia}\nPostulado: {postulado}', questions={'sustenta': Noul(instructions='Evaluar si la evidencia respalda el postulado de forma fidedigna')})
        return res.answers['sustenta'].noul >= 0.75
    except Exception as err:
        logger.error(f'Fallo sandwich: {type(err).__name__} (detalles omitidos por seguridad)')
        return False
```

### 5.2 Contraejemplo y Caso Límite

Permitir que el modelo generativo redacte cuando Jev evaluó una probabilidad de respaldo de solo 0.25 provocará alucinaciones graves en el informe final.

## 8. Validación propuesta

- **Hipótesis Falsable**: El patrón Sandwich elimina en un 99% las citas falsas en reportes técnicos automatizados.
- **Métricas**: Tasa de alucinación de citas documentales.
- **Criterio de Rechazo**: < 0.5% de citas no respaldadas en 500 reportes.
- **Estado**: Protocolo propuesto no ejecutado en producción.
