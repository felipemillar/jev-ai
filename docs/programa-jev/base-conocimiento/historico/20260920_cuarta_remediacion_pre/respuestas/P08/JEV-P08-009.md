# JEV-P08-009 — Retención de Estado en el Orquestador para Trazabilidad sin Memoria en el Modelo

## 1. Respuesta directa y decisión que permite tomar

Dado que Jev 1.13 es estrictamente apátrida (stateless) y no conserva memoria de conversación entre llamadas HTTP, el orquestador anfitrión debe implementar el patrón Event Sourcing. Para cada interacción se debe registrar de forma inmutable: identificador de correlación UUIDv4, marca de tiempo UTC de entrada, hash SHA-256 del payload state, diccionario de preguntas evaluadas, versión exacta del modelo (jev-1.13.0), latencia de red y la respuesta JSON bruta devuelta por la API.

## 2. Alcance, términos, versiones y supuestos

- **Alcance Operacional**: Persistencia de eventos inmutables para reproducibilidad forense y cumplimiento de auditoría.
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk 0.7.0` / `POST /v1/systemone`).
- **Supuestos Críticos**: Las decisiones semánticas son puramente consultivas; la ejecución y mutación de estado residen exclusivamente en componentes deterministas en CPU.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
import hashlib, time, logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P08_09')

def auditar_peticion(texto: str) -> dict:
    try:
        t0 = time.time()
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto, questions={'c': Choice(instructions='Tipo', criteria={'a': 'Clasificación bajo esquema tipo A', 'b': 'Clasificación bajo esquema tipo B'})})
        dur = int((time.time() - t0) * 1000)
        h = hashlib.sha256(texto.encode()).hexdigest()
        return {'hash_state': h, 'veredicto': res.answers['c'].choice, 'latencia_ms': dur}
    except Exception as err:
        logger.error(f'Fallo auditoria: {type(err).__name__} (detalles omitidos por seguridad)')
        return {}
```

### 5.2 Contraejemplo y Caso Límite

Confiar en que el modelo 'recuerda' lo que se le preguntó hace dos llamadas genera respuestas inconsistentes y rompe la reproducibilidad de auditoría.
