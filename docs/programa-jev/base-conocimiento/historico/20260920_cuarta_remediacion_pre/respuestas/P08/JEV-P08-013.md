# JEV-P08-013 — Implementación de Rutas de Respaldo (Fallback) sin Degradar Silenciosamente la Calidad

## 1. Respuesta directa y decisión que permite tomar

Implementar una ruta de respaldo sin degradar silenciosamente la calidad exige que todo fallback emita de forma explícita la cabecera 'X-Degraded-Mode: true' y active un circuit breaker tras 5 fallos consecutivos. De este modo, los consumidores de la API saben que la decisión fue tomada por reglas heurísticas de emergencia y no por el modelo semántico calibrado.

## 2. Alcance, términos, versiones y supuestos

- **Alcance Operacional**: Resiliencia operacional transparente con señalización de estado de servicio degradado.
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk 0.7.0` / `POST /v1/systemone`).
- **Supuestos Críticos**: Las decisiones semánticas son puramente consultivas; la ejecución y mutación de estado residen exclusivamente en componentes deterministas en CPU.
