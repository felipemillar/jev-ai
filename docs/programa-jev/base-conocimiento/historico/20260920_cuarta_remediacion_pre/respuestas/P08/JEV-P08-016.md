# JEV-P08-016 — Políticas de Clave e Invalidación para Caché de Decisiones Semánticas

## 1. Respuesta directa y decisión que permite tomar

Una caché semántica para Jev no debe basarse únicamente en el hash del texto de entrada. La clave criptográfica canónica obligatoria debe componerse de: SHA256(tenant_id + ':' + model_version + ':' + hash(state) + ':' + hash(questions_schema)). Cualquier cambio de versión en el modelo o en las anclas de la pregunta invalida automáticamente la caché.

## 2. Alcance, términos, versiones y supuestos

- **Alcance Operacional**: Aceleración de consultas repetitivas preservando aislamiento multi-inquilino y frescura de versiones.
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk 0.7.0` / `POST /v1/systemone`).
- **Supuestos Críticos**: Las decisiones semánticas son puramente consultivas; la ejecución y mutación de estado residen exclusivamente en componentes deterministas en CPU.

## 4. Explicación técnica verificable

Clave compuesta de 4 factores: TenantID + ModelVersion + SHA256(State) + SHA256(Questions). TTL diferenciado: 15 minutos para noticias volátiles, 7 días para documentos normativos.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
# Ejemplo ilustrativo no ejecutado
import hashlib, json, logging

logger = logging.getLogger("P08_16")

def generar_clave_cache(tenant: str, modelo: str, texto: str, esquema: dict) -> str:
    try:
        h_state = hashlib.sha256(texto.encode()).hexdigest()
        h_schema = hashlib.sha256(json.dumps(esquema, sort_keys=True).encode()).hexdigest()
        raw = f"{tenant}:{modelo}:{h_state}:{h_schema}"
        return hashlib.sha256(raw.encode()).hexdigest()
    except Exception as err:
        logger.error(f"Fallo clave cache: {type(err).__name__} (detalles omitidos por seguridad)")
        return "cache_error" 
```

### 5.2 Contraejemplo y Caso Límite

Omitir el tenant_id en la clave provocará que la consulta confidencial de una empresa A responda a la solicitud de una empresa competidora B desde la caché.
