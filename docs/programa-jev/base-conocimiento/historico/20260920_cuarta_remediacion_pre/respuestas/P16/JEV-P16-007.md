# JEV-P16-007 — Mapeo de Competencias con Respaldo de Fragmentos Textuales Literales

## 1. Respuesta directa y decisión que permite tomar

Cuando Jev determina que un candidato posee una competencia requerida por una vacante (e.g. 'Gestión de proyectos en metodologías ágiles'), el sistema debe vincular obligatoriamente el fragmento textual literal del CV que respalda dicha conclusión. Queda terminantemente prohibido que el modelo asuma o infiera habilidades no respaldadas por el texto. Si no existe evidencia textual directa, la competencia debe registrarse como `no_acreditada_en_perfil`.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Auditoría de correspondencia de habilidades (Skill Matching) y trazabilidad documental de talento.
- **Supuesto clave**: Pruebas sobre perfiles sintéticos y cumplimiento estricto del Código del Trabajo chileno y Ley 19.628.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia laboral/B2B**: Estándares de evaluación por competencias en psicología organizacional y auditoría de decisiones automatizadas.
- **Contraste ético-jurídico**: Se prohíben descartes automáticos no supervisados y el tratamiento de atributos sensibles protegidos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Estructura de match estructurado: `{'competencia': 'SQL Avanzado', 'estado': 'acreditado', 'evidencia': 'Diseño y optimización de consultas complejas en PostgreSQL durante 3 años en Empresa X'}`.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P16_07')

def verificar_evidencia_competencia(extracto_cv: str, competencia_buscada: str) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        prompt = f'EXTRACTO CV:\n{extracto_cv}\nCOMPETENCIA BUSCADA: {competencia_buscada}'
        res = client.system_one(state=prompt, questions={'acreditacion': Choice(instructions='Verificar si el extracto demuestra la competencia directamente', criteria={'acreditada_literalmente': 'Competencia demostrada con evidencias fácticas explícitas', 'inferencia_no_sustentada': 'Mención tangencial que no acredita dominio efectivo', 'no_mencionada': 'Ausencia de referencia a la competencia requerida'})})
        ans = res.answers['acreditacion']
        return {'estado': ans.choice, 'fragmento_respaldo': extracto_cv[:150]}
    except Exception as err:
        logger.error(f'Fallo en mapeo de competencias: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'estado': 'no_mencionada', 'fragmento_respaldo': ''}
```

- **Contraejemplo / Caso borde**: Asumir que un postulante sabe administrar bases de datos Oracle solo porque mencionó que 'utilizó una computadora con Windows'.

- **Criterio de Rechazo**: Menos del 5% de competencias observadas en entrevistas técnicas.
