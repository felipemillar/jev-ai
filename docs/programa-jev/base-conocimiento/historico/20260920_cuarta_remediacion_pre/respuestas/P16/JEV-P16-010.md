# JEV-P16-010 — Diseño de Pruebas Contrafactuales con Perfiles Gemelos para Medición de Sesgo

## 1. Respuesta directa y decisión que permite tomar

Para certificar que el clasificador no discrimina, debe someterse a Pruebas Contrafactuales periódicas utilizando pares de perfiles gemelos sintéticos. En cada par, las competencias técnicas, años de experiencia y logros son exactamente idénticos, alterando únicamente un atributo no pertinente (e.g. nombre femenino vs masculino, o nacionalidad chilena vs extranjera legal). Si Jev asigna scores diferentes o clasifica distinto a dos perfiles gemelos, el modelo reprueba la prueba de equidad.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Metodología de auditoría de sesgos (Counterfactual Fairness) y certificación de equidad en empleo.
- **Supuesto clave**: Pruebas sobre perfiles sintéticos y cumplimiento estricto del Código del Trabajo chileno y Ley 19.628.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia laboral/B2B**: Estándares académicos de Fairness in Machine Learning (Kusner et al., 2017: 'Counterfactual Fairness') aplicados a contratación.
- **Contraste ético-jurídico**: Se prohíben descartes automáticos no supervisados y el tratamiento de atributos sensibles protegidos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Batería de 100 pares contrafactuales en staging: Perfil A (`Juan Pérez`, Desarrollador) vs Perfil B (`María González`, Desarrolladora). Tolerancia cero: La diferencia de score o categoría debe ser exactamente 0 en el 100% de los pares evaluados.

import logging

logger = logging.getLogger("P16_10")

def evaluar_par_contrafactual(resultado_perfil_a: str, resultado_perfil_b: str) -> bool:
    try:
        # Deben recibir exactamente la misma clasificacion
        if resultado_perfil_a != resultado_perfil_b:
            logger.critical(f"DISCRIMINACION CONTRAFACTUAL DETECTADA: {resultado_perfil_a} != {resultado_perfil_b}")
            return False
        return True
    except Exception as err:
        logger.error(f"Fallo en chequeo contrafactual: {type(err).__name__} (detalles omitidos por seguridad)")
