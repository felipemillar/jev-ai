# JEV-P16-012 — Priorización de Solicitudes Comerciales B2B por Ajuste Técnico sin Compromisos Automáticos

## 1. Respuesta directa y decisión que permite tomar

En el área comercial de Wheelwork, Jev puede clasificar las solicitudes de cotización entrantes según su nivel de ajuste con los servicios especializados de la consultora (e.g. consultoría de clima laboral, reclutamiento ejecutivo o compliance con la Ley Karin). El modelo debe evaluar el encaje funcional sin utilizar información personal de los ejecutivos solicitantes y sin enviar respuestas automáticas ni comprometer plazos o tarifas sin validación de un socio comercial.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Automatización comercial B2B, triaje de leads calificados y prevención de compromisos no autorizados.
- **Supuesto clave**: Pruebas sobre perfiles sintéticos y cumplimiento estricto del Código del Trabajo chileno y Ley 19.628.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia laboral/B2B**: Políticas de contratación mercantil y estándares comerciales de consultoría de gestión de personas.
- **Contraste ético-jurídico**: Se prohíben descartes automáticos no supervisados y el tratamiento de atributos sensibles protegidos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Clasificador de encaje de servicios: Entrada: Formulario web de contacto corporativo. Jev devuelve `Choice` con la línea de negocio pertinente y `Score(1, 5)` de ajuste preliminar para ordenar la cola de prospección.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P16_12')

def triaje_solicitud_comercial(texto_solicitud: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_solicitud, questions={'linea_servicio': Choice(instructions='Asignar solicitud a linea de servicio Wheelwork', criteria={'seleccion_ejecutiva': 'Servicio de búsqueda y selección de perfiles ejecutivos', 'compliance_ley_karin': 'Investigación y protocolos conforme a Ley Karin', 'consultoria_clima': 'Diagnóstico y consultoría de clima y cultura organizacional', 'fuera_de_alcance': 'Solicitud no comprendida en las líneas de servicio de Wheelwork'})})
        return res.answers['linea_servicio'].choice
    except Exception as err:
        logger.error(f'Fallo en triaje comercial: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'fuera_de_alcance'
```

- **Contraejemplo / Caso borde**: Permitir que un bot comercial confirme automáticamente a un cliente que Wheelwork asumirá un proyecto internacional para el cual no tiene personal habilitado.

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Compromiso comercial vinculante automático | Demandas por incumplimiento o cotizaciones erróneas | Notificación interna en Slack sin respuesta a cliente | El socio comercial firma siempre las propuestas |

## 8. Validación propuesta

- **Hipótesis Falsable**: El triaje de solicitudes comerciales reduce el tiempo de respuesta a clientes potenciales en un 50%.
- **Métricas**: Horas transcurridas hasta el primer contacto de un consultor con el cliente.
- **Criterio de Rechazo**: Primer contacto en < 4 horas laborables para leads calificados.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
