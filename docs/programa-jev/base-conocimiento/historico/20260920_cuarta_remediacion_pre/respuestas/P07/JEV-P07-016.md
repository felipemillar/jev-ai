# JEV-P07-016: Preparación y Gobernanza del Conjunto Exploratorio de 30 Casos Sintéticos en Español

## 1. Respuesta directa y decisión que permite tomar

La preparación de una batería exploratoria de 30 casos de prueba sintéticos representa una herramienta fundamental de **detección temprana de modos de fallo y verificación cualitativa de capacidades** en modelos de Sistema 1 como TypeSafe Jev. Sin embargo, el error más común en la industria consiste en confundir este banco de pruebas con una validación estadística concluyente: un conjunto de $N = 30$ carece de potencia muestral para estimar intervalos de confianza estrechos (con $N=30$ y $95\%$ de confianza, el margen de error supera el $\pm 18\%$).

El estándar canónico de Jev, formalizado en el documento `P07_EXPERIMENT_PROTOCOL`, establece la **Batería de Humo Exploratoria Cualitativa (BHEC-30)** estructurada en 7 bloques fenomenológicos (negaciones complejas, cortesía indirecta, ironía/sarcasmo, siglas chilenas, modismos, términos técnicos y alternancia de código Spanglish). Cada caso se diseña mediante **pares mínimos de contraste** (entrada dialectal vs. versión neutra equivalente), con preguntas tipadas (`Noul` o `Choice`), *Ground Truth* verificado por hablantes nativos y justificación teórica explícita. Para evitar la complacencia, una directriz de gobernanza prohíbe formalmente utilizar el porcentaje de acierto de este conjunto como métrica de SLA de producción.

## 4. Explicación técnica verificable

### 2.1 Desacople entre Verificación de Capacidades y Validación Estadística

En la ingeniería de software y machine learning, la validación de un componente cognitivo opera en dos niveles ortogonales:

1. **Verificación Conductual Cualitativa ($N = 30$, Pruebas de Unidad Semánticas):**
   - *Propósito:* Detectar si el modelo es ciego a un fenómeno específico (ej. si la palabra *"joyita"* invariablemente activa la clase positiva, o si *"al tiro"* genera máxima entropía).
   - *Diseño:* Muestreo intencional dirigido a los límites de la distribución (*stress testing* en casos esquina o *edge cases*).
   - *Regla de Decisión:* **Falsación binaria**. Un solo fallo sistemático en una capacidad crítica basta para vetar el despliegue directo y exigir un preprocesador.
2. **Validación Estadística de Producción ($N \ge 1.000$, Inferencia Paramétrica):**
   - *Propósito:* Estimar la precisión poblacional esperada, el *Macro-F1* y el error de calibración esperado (ECE) en la distribución real de producción.
   - *Diseño:* Muestreo probabilístico estratificado sin sesgo de selección.
   - *Regla de Decisión:* Superación de umbrales estadísticos con significancia ($p < 0.01$).

```
Límites Estadísticos del Tamaño Muestral N=30 (Margen de Error al 95% de Confianza)
─────────────────────────────────────────────────────────────────────────────
Aciertos Observados    Exactitud Aparente    Intervalo de Confianza Wilson (95%)
─────────────────────────────────────────────────────────────────────────────
27 / 30                90.0%                 [74.4%  ───  96.5%]   <── ¡Margen de ±11%!
24 / 30                80.0%                 [62.7%  ───  90.5%]   <── ¡Margen de ±14%!
20 / 30                66.7%                 [48.8%  ───  80.8%]   <── ¡Margen de ±16%!
─────────────────────────────────────────────────────────────────────────────
Conclusión: Con N=30 es estadísticamente imposible certificar un SLA de 95% en producción.
```

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1. Implementación de Referencia en Python

El siguiente módulo implementa la estructura de datos para registrar los 30 casos sintéticos y ejecuta una auditoría que previene activamente el reporte de falsas certezas estadísticas.

```python
# Ejemplo ilustrativo no ejecutado
"""
Módulo de Gestión y Ejecución de la Batería Exploratoria de 30 Casos (BHEC-30) para Jev AI.
Incluye advertencias estadísticas explícitas y cálculo de intervalos de confianza de Wilson.
"""

from dataclasses import dataclass
from typing import List, Dict, Any, Tuple
import math
import logging

logger = logging.getLogger("ExploratoryBenchmarkManager")


@dataclass(frozen=True)
class SyntheticTestCase:
    case_id: str
    block: str  # "A_NEGATION", "B_POLITENESS", "C_SARCASM", "D_ACRONYMS", "E_SLANG", "F_TECHNICAL", "G_SPANGLISH"
    raw_text: str
    neutral_pair_text: str
    question: str
    primitive: str
    ground_truth: Any
    failure_risk_description: str


@dataclass
class ExploratoryReport:
    total_cases: int
    passed_cases: int
    sample_accuracy: float
    wilson_ci_low: float
    wilson_ci_high: float
    block_breakdown: Dict[str, Dict[str, int]]
    statistical_warning: str


class ExploratoryBenchmarkSuite:
    """
    Ejecutor de la batería cualitativa de 30 casos con salvaguardas de gobernanza estadística.
    """

    def __init__(self):
        self.suite_cases: List[SyntheticTestCase] = []

    def add_case(self, case: SyntheticTestCase):
        self.suite_cases.append(case)

    def run_exploratory_evaluation(self) -> ExploratoryReport:
        try:
            total = len(self.suite_cases)
            if total != 30:
                logger.warning(f"La suite contiene {total} casos. La BHEC estándar está calibrada en exactamente 30 casos.")

            passed = 0
            breakdown = {}

            for case in self.suite_cases:
                block_stats = breakdown.setdefault(case.block, {"total": 0, "passed": 0})
                block_stats["total"] += 1

                # Simulación de inferencia
                predicted = self._mock_infer(case.raw_text, case.question)
                if predicted == case.ground_truth:
                    passed += 1
                    block_stats["passed"] += 1

            sample_acc = passed / total if total > 0 else 0.0
            ci_low, ci_high = self._calculate_wilson_interval(passed, total, 0.95)

            warning_msg = (
                "ADVERTENCIA DE GOBERNANZA: Este conjunto de 30 casos es de carácter CUALITATIVO Y EXPLORATORIO. "
                f"El margen de error estadístico es de ±{(ci_high - ci_low) / 2 * 100:.1f}%. "
                "ESTÁ ESTRICTAMENTE PROHIBIDO utilizar este resultado para certificar acuerdos de nivel de servicio (SLA) "
                "o afirmar precisión de producción. Se requiere una validación estadística con N >= 1,000 instancias."
            )

            return ExploratoryReport(
                total_cases=total,
                passed_cases=passed,
                sample_accuracy=sample_acc,
                wilson_ci_low=ci_low,
                wilson_ci_high=ci_high,
                block_breakdown=breakdown,
                statistical_warning=warning_msg
            )

        except Exception as err:
            logger.error(f"Error en ejecución exploratoria: {type(err).__name__} (detalles omitidos por seguridad)")
            raise RuntimeError(f"Fallo en suite exploratoria: {type(err).__name__}")

    def _calculate_wilson_interval(self, successes: int, total: int, confidence: float = 0.95) -> Tuple[float, float]:
        """Calcula el intervalo de confianza binomial de Wilson para muestras pequeñas."""
        if total == 0:
            return 0.0, 0.0
        z = 1.95996  # Para 95% de confianza
        p = successes / total
        denominator = 1 + z**2 / total
        centre = (p + z**2 / (2 * total)) / denominator
        spread = z * math.sqrt((p * (1 - p) + z**2 / (4 * total)) / total) / denominator
        return max(0.0, centre - spread), min(1.0, centre + spread)

    def _mock_infer(self, text: str, question: str) -> Any:
        lower = text.lower()
        if "no es que no quiera" in lower:
            return False
        if "al tiro" in lower:
            return True
        if "joyita" in lower or "maravilla" in lower:
            return "Insatisfecho"
        return True
```

## 7. Fallos, límites, controles y condiciones de no uso

### 7.1. Modos de Falla y Controles de Mitigación
1. **Descalibración por modismos chilenos no composicionales**: Activación de umbrales dinámicos y compuerta de abstención ante entropía alta.
2. **Fragmentación sub-léxica en tokenización**: Preprocesamiento determinista de acrónimos territoriales y siglas institucionales (CMF, SII, DTE, UF) en memoria en CPU.
3. **Falsos positivos por sarcasmo o ironía**: Desacoplamiento de juicios de satisfacción mediante preguntas fácticas concurrentes en primitivas `Noul`.

### 7.2. Gobernanza, Privacidad y Condiciones de No Uso
1. **Gobernanza de Datos Sintéticos:**
   - Al ser 100% sintéticos, los 30 casos de la BHEC-30 no contienen PII de usuarios reales, lo que permite su versionado abierto en repositorios de código Git corporativos sin riesgo de vulneración de la Ley 19.628 de protección de datos.
2. **Prevención del Síndrome de "Prueba Superada":**
   - Para evitar que los desarrolladores adapten las reglas deterministas para pasar únicamente estos 30 casos fijos (*test-set contamination*), la suite debe rotar un 20% de sus variantes léxicas en cada ciclo de auditoría mediante generadores paramétricos.

---

### 7.3. Condiciones Taxativas de NO Uso
- **NO delegar la normalización de identificadores legales (RUT, patentes) al espacio latente de Jev**; debe validarse con Módulo 11 en CPU.
- **NO canalizar datos confidenciales o bancarios a servicios de traducción externa (NMT no autorizados)** para intentar "traducir" antes de Jev.
- **NO ejecutar acciones operativas irreversibles sin verificación de umbral calibrado localmente**.

## 8. Validación propuesta

> **Nota**: Plan de validación propuesto, no ejecutado en producción. Estado: `pendiente_de_validacion`.

### 7.1 Hipótesis Falsable
$$H_0: \text{Wilson\_Margin}(\text{BHEC-30}) \le 0.05$$
*La hipótesis nula plantea que una muestra de $N = 30$ permite estimar la precisión en español con un margen de error estadístico inferior o igual al $\pm 5\%$.*

### 7.2 Demostración Matemática Falsable
Para una proporción observada $p = 0.90$ y $N = 30$, aplicando el intervalo de Wilson:
$$\text{Margen de Error} \approx z \cdot \sqrt{\frac{p(1-p)}{N}} = 1.96 \cdot \sqrt{\frac{0.90 \times 0.10}{30}} = 1.96 \cdot 0.0547 = 0.1073 \quad (\pm 10.7\%)$$
Dado que $0.1073 > 0.05$, la hipótesis nula $H_0$ queda **falsada matemáticamente a priori**. Queda demostrado formalmente que ninguna muestra de $N=30$ puede proporcionar certeza estadística de producción, sustentando su estatus exclusivamente cualitativo.
