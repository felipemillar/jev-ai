# JEV-P14-020 — Rutina Semanal de Revisión de Errores y Criterio de Retiro de Automatizaciones Inútiles

## 1. Respuesta directa y decisión que permite tomar

El mantenimiento de la higiene operativa del investigador exige una rutina fija semanal de 15 minutos (ejecutada cada viernes) para auditar el desempeño de los flujos personales. En esta sesión se analizan los errores clasificados en la semana, se ajustan las reglas locales y se evalúa el valor neto aportado. Si una automatización requirió más de 20 minutos de mantenimiento en la semana o si su tiempo neto ahorrado fue negativo durante dos semanas consecutivas, se ejecuta su desinstalación definitiva sin contemplaciones.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Cultura de mantenimiento ágil personal, desmantelamiento de deuda técnica y mejora continua.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Buenas prácticas de productividad personal (Weekly Review de Getting Things Done) adaptadas al uso de agentes de IA.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Checklist semanal de auditoría: 1. Contar discrepancias corregidas; 2. Medir tiempo de mantenimiento; 3. Comprobar que no hay procesos zombis en background; 4. Ejecutar script de retiro `uninstall_flow.py` si el valor neto es nulo.
