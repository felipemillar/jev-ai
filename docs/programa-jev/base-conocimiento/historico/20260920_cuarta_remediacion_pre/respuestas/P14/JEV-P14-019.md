# JEV-P14-019 — Protocolo de Traslado Gradual: De Casos Sintéticos a Datos Personales Autorizados

## 1. Respuesta directa y decisión que permite tomar

El traspaso de un flujo personal desde el banco de pruebas sintético hacia la operación con datos propios debe realizarse mediante un protocolo formal en tres etapas: 1) Etapa de Aislamiento Sintético (200 documentos ficticios probados en staging); 2) Etapa de Acompañamiento en Sombra (el modelo clasifica correos reales en un buzón de prueba secundario sin permisos de modificación durante 7 días); y 3) Etapa de Activación Supervisada (clasificación en buzón principal con confirmación obligatoria en pantalla).

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Metodología de puesta en marcha segura de automatizaciones personales y transición controlada.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Mandato de gobernanza y protección de datos del Programa Jev para la adopción de pilotos.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Gate de Autorización: Cada transición de etapa exige la verificación de un informe técnico donde conste que la tasa de acierto es >= 92% y que no se ha registrado ninguna excepción no controlada.

# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P14_19")

class ProtocoloTransicionPiloto:
    def __init__(self):
        self.etapa_actual = "FASE_1_SINTETICA"

    def promover_a_siguiente_fase(self, dias_sin_incidentes: int, exactitud_comprobada: float) -> str:
        try:
            if self.etapa_actual == "FASE_1_SINTETICA" and exactitud_comprobada >= 0.92:
                self.etapa_actual = "FASE_2_SOMBRA_REAL"
            elif self.etapa_actual == "FASE_2_SOMBRA_REAL" and dias_sin_incidentes >= 7:
                self.etapa_actual = "FASE_3_ACTIVACION_SUPERVISADA"
            return self.etapa_actual
        except Exception as err:
            logger.error(f"Fallo en transicion de fase: {type(err).__name__} (detalles omitidos por seguridad)")
            return self.etapa_actual
