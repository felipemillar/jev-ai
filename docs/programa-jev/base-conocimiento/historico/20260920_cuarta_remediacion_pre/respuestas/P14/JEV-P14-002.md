# JEV-P14-002 — Tres Flujos Personales Óptimos: Frecuencia, Reversibilidad y Facilidad de Evaluación

## 1. Respuesta directa y decisión que permite tomar

Los tres flujos personales que presentan la combinación óptima de alta frecuencia, reversibilidad absoluta y facilidad de evaluación en el marco del Piloto FP-01 son: 1) Triaje y etiquetado de lecturas técnicas y papers de investigación (alta frecuencia, impacto nulo ante falsos positivos); 2) Pre-clasificación de correos entrantes en carpetas lógicas sin acciones de respuesta automática; y 3) Asignación de categorías funcionales a recibos y comprobantes de gasto sobre datos sintéticos.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Selección de flujos semilla, control de riesgos y diseño de experimentos personales.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

## 4. Explicación técnica

Matriz de reversibilidad: Flujo 1 (Lecturas: Reversibilidad 100%, reordenar lista); Flujo 2 (Emails: Reversibilidad 100%, mover mensaje); Flujo 3 (Recibos: Reversibilidad 100%, modificar etiqueta en hoja de cálculo antes de contabilizar).

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P14_02')

def triaje_lectura_personal(titulo_resumen: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=titulo_resumen, questions={'categoria': Choice(instructions='Clasificar pertinencia para investigacion', criteria={'lectura_inmediata': 'Documento de alta prioridad para lectura inmediata', 'archivo_referencia': 'Documento secundario para archivo de referencia', 'descartar': 'Documento no pertinente que debe ser descartado'})})
        return res.answers['categoria'].choice
    except Exception as err:
        logger.error(f'Fallo en triaje de lectura: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'archivo_referencia'
```

- **Contraejemplo / Caso borde**: Automatizar el envío de respuestas de correo sin confirmación humana puede provocar malentendidos graves con colegas o clientes.
