# JEV-P11-005 — Prevención de Inclusión de Secretos en Solicitudes, Notebooks y Repositorios

## 1. Respuesta directa y decisión que permite tomar

Las llaves de API (`TYPESAFE_API_KEY`, tokens de NotebookLM, credenciales de brokers MT5) jamás deben quemarse en scripts, celdas de Jupyter Notebooks, archivos Markdown de la base de conocimiento ni repositorios Git. Debe aplicarse un hook de pre-commit con herramientas de detección estática (Gitleaks, TruffleHog) y una regla estricta de regex en runtime. Toda excepción de Python debe usar `type(err).__name__` con el sufijo `(detalles omitidos por seguridad)`.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Gestión de secretos, higiene en control de versiones y auditoría continua de código fuente.
- **Supuesto clave**: Defensa en profundidad activa combinando controles en CPU y evaluación semántica.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Incidentes históricos de ciberseguridad donde llaves de API expuestas en repositorios públicos causaron pérdidas millonarias en minutos.
- **Contraste de seguridad**: Se descartan posturas que asumen invulnerabilidad intrínseca o delegan controles de acceso a modelos probabilísticos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Regex obligatoria de escaneo en runtime y pre-commit: `r'(?:api[_-]?key|secret|token|bearer)\s*[:=]\s*['"]?([A-Za-z0-9_\-\.]{16,})['"]?'`. Bloqueo inmediato del proceso si se detecta coincidencia en variables exportadas o payloads salientes.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import os, re, logging

logger = logging.getLogger("P11_05")
REGEX_SECRETOS_ESTRICTA = re.compile(
    r'''(?:api[_-]?key|secret|token|bearer)\s*[:=]\s*['"]?([A-Za-z0-9_\-\.]{16,})['"]?''',
    re.IGNORECASE
)

def verificar_ausencia_de_secretos(payload_json_str: str) -> bool:
    try:
        match = REGEX_SECRETOS_ESTRICTA.search(payload_json_str)
        if match:
            logger.critical("INTENTO DE FUGA DE CREDENCIALES DETECTADO EN PAYLOAD")
            return False
        return True
    except Exception as err:
        logger.error(f"Fallo en auditoria de secretos: {type(err).__name__} (detalles omitidos por seguridad)")
        return False
```

- **Contraejemplo / Caso borde**: Copiar el contenido de un archivo `.env` dentro de una celda de un cuaderno compartido para 'hacer una prueba rápida' expone la llave a todo el equipo.
