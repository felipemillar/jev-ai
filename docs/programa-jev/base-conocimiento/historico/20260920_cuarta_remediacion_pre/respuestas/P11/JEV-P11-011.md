# JEV-P11-011 — Limitación Determinista de Herramientas y Parámetros Permitidos (Least Privilege)

## 1. Respuesta directa y decisión que permite tomar

El principio de mínimo privilegio exige restringir el conjunto de herramientas expuestas al modelo exclusivamente a aquellas estrictamente indispensables para la tarea en curso. Queda terminantemente prohibido confiar en que el modelo 'obedecerá' una instrucción textual como 'no uses la herramienta de eliminación de base de datos'. La restricción debe ser técnica y determinista: la herramienta no debe existir en la lista retornada por `tools/list` para ese contexto específico.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Control de acceso basado en capacidades, diseño de herramientas seguras y aislamiento de permisos.
- **Supuesto clave**: Defensa en profundidad activa combinando controles en CPU y evaluación semántica.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Principio de menor privilegio de Saltzer y Schroeder (1975) y recomendaciones de seguridad de agentes de Anthropic y OpenAI.
- **Contraste de seguridad**: Se descartan posturas que asumen invulnerabilidad intrínseca o delegan controles de acceso a modelos probabilísticos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Filtrado de capacidades por perfil: Perfil Investigador = solo herramientas de lectura (`tools/read`, `notebook_query`); Perfil Operador = herramientas de lectura y simulación; Perfil Producción = requiere doble firma humana para escrituras.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P11_11")

class ControlHerramientasMCP:
    def __init__(self, rol_usuario: str):
        self.rol = rol_usuario
        self.permisos = {
            "auditor": ["leer_fuente", "consultar_resumen"],
            "admin": ["leer_fuente", "consultar_resumen", "actualizar_indice"]
        }

    def filtrar_herramientas_para_sesion(self, catalogo_completo: list) -> list:
        try:
            permitidas = set(self.permisos.get(self.rol, ["leer_fuente"]))
            return [h for h in catalogo_completo if h.get("name") in permitidas]
        except Exception as err:
            logger.error(f"Fallo en filtrado de herramientas: {type(err).__name__} (detalles omitidos por seguridad)")
            return []
```

- **Contraejemplo / Caso borde**: Exponer una herramienta de ejecución de comandos de terminal (bash) a un agente que solo necesita resumir textos expone todo el servidor a toma de control.
