# JEV-P11-015 — Protocolo de Auditoría Previa para Conectores y Librerías Comunitarias

## 1. Respuesta directa y decisión que permite tomar

Antes de autorizar la integración de cualquier conector o paquete comunitario (e.g. extensiones no oficiales de GitHub para TypeSafe o MCP), el equipo de ciberseguridad debe ejecutar un protocolo formal de homologación: 1) Inspección de código fuente y dependencias transitivas; 2) Verificación de llamadas de red salientes no documentadas; 3) Análisis estático de vulnerabilidades (SAST); y 4) Pruebas en sandbox hermético sin acceso a producción.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Gestión de riesgos en software de terceros y homologación técnica de dependencias abiertas.
- **Supuesto clave**: Defensa en profundidad activa combinando controles en CPU y evaluación semántica.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Marcos de seguridad de la cadena de suministro OpenSSF Scorecard y recomendaciones de la auditoría de Codex.
- **Contraste de seguridad**: Se descartan posturas que asumen invulnerabilidad intrínseca o delegan controles de acceso a modelos probabilísticos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Checklist de auditoría de conector: Sin llamadas a `eval()` o `exec()`; sin conexiones socket raw fuera de la URL configurada; licencias permisivas aprobadas (MIT/Apache 2.0); y pin estricto de commit con firma GPG.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import ast, logging

logger = logging.getLogger("P11_15")

def auditar_peligros_en_codigo_fuente(codigo: str) -> bool:
    try:
        arbol = ast.parse(codigo)
        for nodo in ast.walk(arbol):
            if isinstance(nodo, ast.Call):
                if isinstance(nodo.func, ast.Name) and nodo.func.id in ("eval", "exec", "__import__"):
                    logger.critical(f"Llamada peligrosa detectada en conector: {nodo.func.id}")
                    return False
        return True
    except Exception as err:
        logger.error(f"Fallo en analisis estatico: {type(err).__name__} (detalles omitidos por seguridad)")
        return False
```

- **Contraejemplo / Caso borde**: Instalar un paquete de PyPI llamado `typesafe-mcp-connector` subido por un usuario desconocido sin auditar su código puede introducir un troyano en el clúster.

- **Hipótesis Falsable**: El protocolo de homologación previa detiene el 100% de las dependencias con código ofuscado o llamadas peligrosas.

- **Criterio de Rechazo**: 0 dependencias no homologadas autorizadas en producción.
