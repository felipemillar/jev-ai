# JEV-P11-012 — Controles contra la Contaminación del Corpus (Data Poisoning) y Fuentes Hostiles

## 1. Respuesta directa y decisión que permite tomar

La integridad de la base de conocimiento exige proteger el corpus contra ataques de contaminación de datos (Data Poisoning), donde fuentes aparentemente benignas introducen desinformación o sesgos deliberados. Cada documento ingresado al corpus debe contar con una firma criptográfica de procedencia, un hash SHA-256 verificado y una validación de reputación de dominio. Se prohíbe la auto-ingestión desatendida de páginas web abiertas sin curaduría humana.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Seguridad de la cadena de suministro de conocimiento e integridad de datasets de referencia.
- **Supuesto clave**: Defensa en profundidad activa combinando controles en CPU y evaluación semántica.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Estándares de envenenamiento de modelos (OWASP LLM03: Training Data Poisoning) aplicados a conocimiento contextual en RAG.
- **Contraste de seguridad**: Se descartan posturas que asumen invulnerabilidad intrínseca o delegan controles de acceso a modelos probabilísticos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Cadena de custodia documental: Cada archivo en `docs/programa-jev/` registra su SHA-256 en un manifiesto centralizado (`manifest-sha256.txt`). Una rutina diaria de integridad verifica que ningún archivo haya sido modificado sin registro en la bitácora.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import hashlib, logging

logger = logging.getLogger("P11_12")

def validar_integridad_fuente(contenido_archivo: bytes, sha256_esperado: str) -> bool:
    try:
        sha_calculado = hashlib.sha256(contenido_archivo).hexdigest()
        if sha_calculado != sha256_esperado:
            logger.critical("ALERTA DE CONTAMINACION: Hash de documento no coincide con el manifiesto")
            return False
        return True
    except Exception as err:
        logger.error(f"Fallo en chequeo de integridad: {type(err).__name__} (detalles omitidos por seguridad)")
        return False
```

- **Métricas**: Tasa de discrepancias de hash no autorizadas detectadas.
- **Criterio de Rechazo**: 0 documentos modificados sin trazabilidad en manifiesto.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
