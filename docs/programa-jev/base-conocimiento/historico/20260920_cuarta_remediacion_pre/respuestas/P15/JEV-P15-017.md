# JEV-P15-017 — Medición de Comportamiento ante Cambios de Régimen de Mercado sin Inferencias Causales

## 1. Respuesta directa y decisión que permite tomar

El sistema debe evaluar cómo se comporta el clasificador de texto durante períodos de turbulencia macroeconómica o cambios bruscos de régimen de mercado (e.g. crisis de liquidez, estallido social, pandemia). En tales regímenes, el vocabulario de las noticias cambia drásticamente y la tasa de abstención de Jev tiende a incrementarse. Se prohíbe atribuir al modelo una comprensión causal de la economía; Jev solo mide la correlación estadística entre términos y etiquetas previamente entrenadas.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Análisis de robustez en estrés de mercado, regímenes no estacionarios y humildad epistémica en finanzas.
- **Supuesto clave**: Entorno de investigación documental hermético y aislado del motor de trading algorítmico.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia cuantitativa**: Comportamiento empírico de modelos de NLP en períodos de shock financiero: la distribución de entradas se desplaza fuera de la distribución base de entrenamiento.
- **Contraste econométrico**: Se prohíbe deducir rentabilidad o predicción financiera a partir de exactitud de clasificación de texto.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Monitoreo estratificado por régimen de volatilidad: Segmentar el dataset histórico en períodos de 'Baja Volatilidad' ($VIX < 15$) y 'Alta Volatilidad' ($VIX > 30$). Evaluar si el F1-Score de clasificación se mantiene dentro de rangos tolerables.

def auditar_comportamiento_por_regimen(f1_baja_vol: float, f1_alta_vol: float) -> dict:
    try:
        degradacion = (f1_baja_vol - f1_alta_vol) / max(f1_baja_vol, 0.001)
        es_estable = degradacion <= 0.15
        return {
            "degradacion_pct": round(degradacion * 100.0, 1),
            "es_robusto_en_crisis": es_estable,
            "dictamen": "APROBADO_MULTI_REGIMEN" if es_estable else "REQUERIR_ABSTENCION_EN_ALTA_VOLATILIDAD"
        }
    except Exception as err:
        logger.error(f"Fallo en auditoria por regimen: {type(err).__name__} (detalles omitidos por seguridad)")
