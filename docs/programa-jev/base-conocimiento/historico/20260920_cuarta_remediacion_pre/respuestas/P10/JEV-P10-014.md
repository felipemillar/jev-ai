# JEV-P10-014 — Mecanismos de Abstención Rigurosa ante Ausencia de Evidencia en el Corpus

## 1. Respuesta directa y decisión que permite tomar

El sistema debe abstenerse categóricamente de responder cuando el corpus carece de evidencia suficiente para sustentar una afirmación, incluso si existen pasajes superficialmente relacionados por coincidencia léxica. La compuerta de abstención de Jev debe operar mediante umbrales duros de confianza: si en una primitiva `Choice` la probabilidad de la opción ganadora es menor a 0.60, o si en `Noul` la certeza $|2p - 1| < 0.30$, el sistema emite el dictamen formal de 'información no concluyente'.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Calibración probabilística, compuertas nulas y erradicación de alucinaciones en escenarios Out-Of-Distribution (OOD).
- **Supuesto clave**: Existencia de un motor de recuperación primaria de primera fase configurado y poblado.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Principios de diseño del Pilar P05 (Probabilidad y calibración): Jev 1.13 no genera texto libre, pero puede emitir clasificaciones forzadas si el prompt no ofrece una opción de escape.
- **Contraste metodológico**: Se descartan arquitecturas que confunden búsqueda masiva no estructurada con inferencia semántica puntual.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Diseño de preguntas con opción nula obligatoria: En `Choice`, incluir siempre la opción `'informacion_insuficiente'`. En `Noul`, computar en CPU del cliente $|2p - 1| < \tau$ para conmutar a estado de abstención.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Noul

logger = logging.getLogger("P10_14")

def evaluar_con_compuerta_abstencion(pasaje: str, consulta: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        prompt = f"PASAJE: {pasaje}\nCONSULTA: {consulta}"
        res = client.system_one(
            state=prompt,
            questions={"suficiente": Noul(instructions="Determinar si el pasaje contiene la respuesta exacta")}
        )
        p = res.answers["suficiente"].noul
        certeza = abs(2 * p - 1)
        if certeza < 0.35:
            return {"decision": "ABSTENCION", "motivo": "Certeza insuficiente en corpus"}
        return {"decision": "RESPUESTA_VALIDA" if p >= 0.5 else "SIN_EVIDENCIA", "certeza": certeza}
    except Exception as err:
        logger.error(f"Fallo en compuerta de abstencion: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"decision": "ERROR_ABSTENCION"}
```

- **Contraejemplo / Caso borde**: Forzar una respuesta binaria 'Si/No' cuando el texto no menciona el asunto analizado obliga al modelo a responder al azar.
