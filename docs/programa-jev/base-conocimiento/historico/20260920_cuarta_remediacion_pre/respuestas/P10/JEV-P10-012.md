# JEV-P10-012 — Estrategia para Consultas Multi-Fuente y Atribución 분산ada de Hechos Sintetizados

## 1. Respuesta directa y decisión que permite tomar

Cuando una consulta compleja exige sintetizar información dispersa en múltiples fuentes, queda prohibido atribuir la conclusión total a una única fuente individual. La arquitectura debe: 1) Descomponer la consulta en proposiciones atómicas; 2) Evaluar cada proposición contra su fuente primaria correspondiente mediante Jev; y 3) Componer la síntesis final mapeando explícitamente cada hecho derivado a su fuente canónica mediante una tabla de trazabilidad documental.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Trazabilidad de conocimiento compuesto, desmitificación de fuentes únicas y arquitectura de síntesis rigurosa.
- **Supuesto clave**: Existencia de un motor de recuperación primaria de primera fase configurado y poblado.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Mandato expreso de la auditoría de Codex (Deficiencia B05): las respuestas anteriores atribuían síntesis elaboradas a cuadernos únicos sin citar las fuentes primarias subyacentes.
- **Contraste metodológico**: Se descartan arquitecturas que confunden búsqueda masiva no estructurada con inferencia semántica puntual.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Grafo de procedencia: Cada afirmación $f_i$ se almacena como una tupla $(f_i, \text{fuente}_i, \text{confianza}_i)$. La síntesis $S = \{f_1, f_2, \dots, f_n\}$ solo es válida si todos sus nodos componentes cuentan con respaldo trazable verificado.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

import logging

logger = logging.getLogger("P10_12")

def registrar_sintesis_multi_fuente(afirmaciones_con_fuente: list) -> dict:
    try:
        tabla_trazabilidad = []
        for hecho, fuente in afirmaciones_con_fuente:
            tabla_trazabilidad.append({"proposicion": hecho, "fuente_canonica": fuente})
        return {"estado": "sintesis_trazable", "trazabilidad": tabla_trazabilidad}
    except Exception as err:
        logger.error(f"Fallo en composicion multi-fuente: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"estado": "error"}
