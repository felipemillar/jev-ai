# JEV-P13-002 — Costo Total de Propiedad (TCO): Infraestructura, Mantenimiento, Errores y Supervisión

## 1. Respuesta directa y decisión que permite tomar

El costo de la API de TypeSafe representa típicamente menos del 20% del Costo Total de Propiedad (Total Cost of Ownership, TCO). El TCO completo comprende: 1) Costo directo de API; 2) Cómputo auxiliar de pre y posprocesamiento en clúster; 3) Desarrollo, testing y despliegue de integraciones; 4) Supervisión humana de casos ambiguos o escalados; y 5) Costo financiero o reputacional de los errores cometidos. Evaluar solo la factura de la API oculta el 80% del impacto financiero real.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: FinOps, análisis de costo total de ciclo de vida y presupuestación empresarial integral.
- **Supuesto clave**: Evaluación financiera a precios plenos documentados ($0.042/Mtok) sin subsidios temporales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia económica**: Marcos de análisis de TCO de Gartner para proyectos de inteligencia artificial y automatización de procesos.
- **Contraste de modelos**: Se comparan escenarios de SaaS gestionado frente a auto-hosting de GPU y LLMs frontier generativos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Ecuación formal de TCO: $\text{TCO} = C_{\text{API}} + C_{\text{Cloud}} + C_{\text{DevOps}} + C_{\text{Revision}} + C_{\text{Errores}}$. En un flujo de 100.000 operaciones mensuales, la revisión humana de 5.000 casos ($0.50 USD/caso = $2.500 USD) domina totalmente sobre la API ($8.40 USD).

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_02")

def calcular_tco_mensual(costo_api: float, costo_cloud: float, casos_escalados: int, costo_hora_humana: float = 20.0) -> dict:
    try:
        # Asumiendo 2 minutos por caso revisado por analista
        costo_humano = (casos_escalados * (2.0 / 60.0)) * costo_hora_humana
        tco_total = costo_api + costo_cloud + costo_humano
        pct_humano = (costo_humano / max(tco_total, 1.0)) * 100.0
        return {
            "tco_total_usd": round(tco_total, 2),
            "costo_humano_usd": round(costo_humano, 2),
            "porcentaje_humano_tco": round(pct_humano, 1)
        }
    except Exception as err:
        logger.error(f"Fallo en calculo de TCO: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"tco_total_usd": 0.0}
```

- **Contraejemplo / Caso borde**: Celebrar una reducción del 50% en el precio de la API mientras la tasa de abstención sube un 5% aumentará el costo total del proyecto por sobrecarga del personal.
