# JEV-P13-010 — Amortización de la Inversión Inicial de Integración en Pilotos Pequeños

## 1. Respuesta directa y decisión que permite tomar

El costo de ingeniería requerido para integrar, probar y auditar Jev (estimado en 40 a 80 horas de desarrollador, equivalentes a $2.000 a $4.000 USD) no se amortiza fácilmente en pilotos con volúmenes reducidos si solo se mide el ahorro de llamadas. Para que un piloto sea financieramente viable, debe resolver un cuello de botella de alto valor añadido (e.g. evitar multas laborales, acelerar en días el cierre de contratos o filtrar cables financieros críticos) y no limitarse a automatizar tareas triviales.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Evaluación de retorno de inversión en proyectos piloto (ROI de I+D) y justificación de capex de software.
- **Supuesto clave**: Evaluación financiera a precios plenos documentados ($0.042/Mtok) sin subsidios temporales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia económica**: Directrices de gestión de innovación y proyectos tecnológicos de McKinsey sobre la tasa de fracaso de pilotos de IA aislados.
- **Contraste de modelos**: Se comparan escenarios de SaaS gestionado frente a auto-hosting de GPU y LLMs frontier generativos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Fórmula de amortización: $\text{Meses para Payback} = \frac{\text{Costo Desarrollo (\$3.000)}}{\text{Valor Mensual Generado} - \text{Costo Operativo}}$. Si el valor generado es inferior a $500 USD/mes, el piloto tardará más de 6 meses en amortizarse.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_10")

def meses_payback_piloto(costo_desarrollo_usd: float, valor_mensual_usd: float, costo_operativo_mes: float) -> float:
    try:
        beneficio_neto = valor_mensual_usd - costo_operativo_mes
        if beneficio_neto <= 0:
            return float("inf")
        return round(costo_desarrollo_usd / beneficio_neto, 1)
    except Exception as err:
        logger.error(f"Fallo en calculo de payback: {type(err).__name__} (detalles omitidos por seguridad)")
        return float("inf")
```

- **Contraejemplo / Caso borde**: Gastar $5.000 USD de ingeniería para automatizar un proceso que solo ahorra $20 USD al mes en un flujo de uso esporádico.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Piloto en tarea de escaso impacto económico | Incapacidad de recuperar la inversión | Filtro previo de viabilidad con Payback < 6 meses | Priorizar flujos con impacto directo en ingresos o riesgo |
| Aumento sorpresivo de tarifas del proveedor | Incremento del costo operativo | Monitoreo semanal de facturación | Patrón Adapter para conmutar a alternativas locales |
