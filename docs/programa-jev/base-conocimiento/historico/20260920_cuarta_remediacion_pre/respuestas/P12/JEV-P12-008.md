# JEV-P12-008 — Fijación Inmutable de Versiones de Modelo, SDK y Taxonomías en Cada Decisión

## 1. Respuesta directa y decisión que permite tomar

Toda decisión emitida en producción debe registrar inmutablemente los metadatos completos de su generación: modelo exacto (`jev-1.13.0`), versión de SDK (`typesafe_sdk 0.7.0`), hash criptográfico de las instrucciones del prompt, versión de la taxonomía de opciones (`Choice`), fecha y hora ISO-8601 con milisegundos, y hash SHA-256 del texto de entrada (`state`). Queda prohibido registrar decisiones huérfanas sin trazabilidad de versión.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Auditoría forense, reproducibilidad científica y cumplimiento regulatorio en decisiones automatizadas.
- **Supuesto clave**: Plataforma de monitoreo y telemetría distribuida activa en el entorno de despliegue.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia operativa**: Estándares de gobernanza de modelos de Machine Learning (MLOps) y requisitos de trazabilidad legal del AI Act.
- **Contraste de confiabilidad**: Se descartan suposiciones de estabilidad perfecta en servicios cloud de terceros sin mecanismos de fallback.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Esquema de auditoría inmutable en PostgreSQL/BigQuery: `decision_id UUID PRIMARY KEY`, `model_version VARCHAR(32)`, `sdk_version VARCHAR(32)`, `prompt_hash CHAR(64)`, `state_hash CHAR(64)`, `output_json JSONB`, `created_at TIMESTAMPTZ`.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import hashlib, time, logging

logger = logging.getLogger("P12_08")

def construir_registro_decision_inmutable(decision_id: str, texto_estado: str, respuesta_dict: dict) -> dict:
    try:
        hash_input = hashlib.sha256(texto_estado.encode("utf-8")).hexdigest()
        return {
            "decision_id": decision_id,
            "version_modelo": "jev-1.13.0",
            "version_sdk": "typesafe_sdk 0.7.0",
            "state_hash_sha256": hash_input,
            "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
            "resultado": respuesta_dict
        }
    except Exception as err:
        logger.error(f"Fallo en registro de auditoria: {type(err).__name__} (detalles omitidos por seguridad)")
        return {}
```

- **Contraejemplo / Caso borde**: Intentar auditar un error en una transacción de hace 3 meses sin saber si se usó Jev 1.12 o 1.13 ni qué opciones se le pasaron hace imposible el análisis de causa raíz.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |

| Desbordamiento de colas de memoria ante picos | Out of Memory (OOM) en contenedor | Métricas de memoria en Prometheus | Colas acotadas con descarte ordenado (backpressure) |
