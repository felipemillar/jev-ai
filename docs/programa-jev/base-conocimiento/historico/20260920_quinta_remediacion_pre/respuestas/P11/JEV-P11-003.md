# JEV-P11-003 — Sanitización Determinista Previa y Erradicación de Fuga de PII en Solicitudes

## 1. Respuesta directa y decisión que permite tomar

Toda información personal identificable (PII) —incluyendo RUTs chilenos, números de pasaporte, correos electrónicos, números de teléfono y números de tarjetas de crédito— debe redactarse u ofuscarse de forma determinista en CPU antes de que el texto sea enviado a la API de TypeSafe. Aunque TypeSafe ofrezca acuerdos de confidencialidad, la responsabilidad penal y regulatoria (Ley 19.628 y RGPD) exige que los datos sensibles nunca abandonen el perímetro corporativo.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Cumplimiento de privacidad de datos, anonimización algorítmica y prevención de filtraciones.
- **Supuesto clave**: Defensa en profundidad activa combinando controles en CPU y evaluación semántica.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Directrices de la Agencia de Protección de Datos y normativa de ciberseguridad financiera sobre datos en tránsito hacia nubes de terceros.
- **Contraste de seguridad**: Se descartan posturas que asumen invulnerabilidad intrínseca o delegan controles de acceso a modelos probabilísticos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Canal de ofuscación por expresiones regulares y algoritmos deterministas: Reemplazo por tokens sintéticos consistentes `[RUT_HASH_XXXX]`, preservando la entidad para análisis semántico sin revelar el dato real.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import re, hashlib, logging

logger = logging.getLogger("P11_03")

REGEX_RUT = re.compile(r"(\d{1,2}\.?\d{3}\.?\d{3}-[\dkK])")
REGEX_EMAIL = re.compile(r"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}")

def anonimizar_pii(texto_original: str) -> str:
    try:
        def hash_rut(m):
            h = hashlib.sha256(m.group(1).encode()).hexdigest()[:8]
            return f"[RUT_PSEUDO_{h}]"

        texto_limpio = REGEX_RUT.sub(hash_rut, texto_original)
        texto_limpio = REGEX_EMAIL.sub("[CORREO_OFUSCADO]", texto_limpio)
        return texto_limpio
    except Exception as err:
        logger.error(f"Fallo en anonimizacion: {type(err).__name__} (detalles omitidos por seguridad)")
        return "" 
```

- **Criterio de Rechazo**: 0 registros de RUTs o correos reales en 5.000 peticiones.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
