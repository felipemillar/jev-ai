## 4. Explicación técnica verificable

Clave compuesta de 4 factores: TenantID + ModelVersion + SHA256(State) + SHA256(Questions). TTL diferenciado: 15 minutos para noticias volátiles, 7 días para documentos normativos.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
# Ejemplo ilustrativo no ejecutado
import hashlib, json, logging

logger = logging.getLogger("P08_16")

def generar_clave_cache(tenant: str, modelo: str, texto: str, esquema: dict) -> str:
    try:
        h_state = hashlib.sha256(texto.encode()).hexdigest()
        h_schema = hashlib.sha256(json.dumps(esquema, sort_keys=True).encode()).hexdigest()
        raw = f"{tenant}:{modelo}:{h_state}:{h_schema}"
        return hashlib.sha256(raw.encode()).hexdigest()
    except Exception as err:
        logger.error(f"Fallo clave cache: {type(err).__name__} (detalles omitidos por seguridad)")
        return "cache_error" 
```
