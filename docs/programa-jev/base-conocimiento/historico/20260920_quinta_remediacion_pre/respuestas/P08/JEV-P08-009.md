### 5.1 Implementación en Python (SDK 0.7.0)

```python
import hashlib, time, logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P08_09')

def auditar_peticion(texto: str) -> dict:
    try:
        t0 = time.time()
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto, questions={'c': Choice(instructions='Tipo', criteria={'a': 'Clasificación bajo esquema tipo A', 'b': 'Clasificación bajo esquema tipo B'})})
        dur = int((time.time() - t0) * 1000)
        h = hashlib.sha256(texto.encode()).hexdigest()
        return {'hash_state': h, 'veredicto': res.answers['c'].choice, 'latencia_ms': dur}
    except Exception as err:
        logger.error(f'Fallo auditoria: {type(err).__name__} (detalles omitidos por seguridad)')
        return {}
```

### 5.2 Contraejemplo y Caso Límite

Confiar en que el modelo 'recuerda' lo que se le preguntó hace dos llamadas genera respuestas inconsistentes y rompe la reproducibilidad de auditoría.
