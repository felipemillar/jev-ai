## 4. Explicación técnica verificable

Evaluación de corte por Entropía Normalizada de Shannon H_N(p) y margen de probabilidad delta_p = p_top1 - p_top2. Escalamiento a frontier cuando H_N > 0.40 o delta_p < 0.25.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
import math, logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P08_03')

def cascada_tco(texto: str) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto, questions={'c': Choice(instructions='Area', criteria={'soporte': 'Área de soporte técnico y resolución de incidencias', 'ventas': 'Área comercial y de ventas', 'duda': 'Consulta general o duda operativa'})})
        ans = res.answers['c']
        p = list(ans.probabilities.values())
        h = -sum((x * math.log(x + 1e-09) for x in p)) / math.log(len(p))
        if ans.confidence >= 0.82 and h <= 0.4:
            return {'origen': 'JEV_1.13', 'area': ans.choice, 'coste': 2e-05}
        return {'origen': 'FRONTIER_MODEL', 'area': 'escalado', 'coste': 0.003}
    except Exception as err:
        logger.error(f'Fallo cascada: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'origen': 'FALLBACK_MANUAL', 'coste': 0.0}
```
