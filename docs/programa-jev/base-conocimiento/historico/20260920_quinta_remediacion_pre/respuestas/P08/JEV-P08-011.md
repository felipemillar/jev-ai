## 4. Explicación técnica verificable

Presupuesto de iteración finito k in [1, 3] con decaimiento de gradiente de temperatura en el generador y evaluación de delta de score delta S >= 0.30 para continuar.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
import logging
from typesafe_sdk import TypeSafeClient, Score
logger = logging.getLogger('P08_11')

def bucle_refinamiento(texto: str, max_rondas: int=3) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        score_ant = 0.0
        for r in range(max_rondas):
            res = client.system_one(state=texto, questions={'calidad': Score(instructions='Calidad 1-4', criteria=['Nivel 1: Nivel inicial con fiabilidad baja', 'Nivel 2: Nivel regular con reservas', 'Nivel 3: Nivel aceptable conforme', 'Nivel 4: Nivel óptimo con fiabilidad alta'])})
            sc = res.answers['calidad'].score
            if sc >= 3.2 or (r > 0 and sc - score_ant < 0.25):
                return {'rondas': r + 1, 'score': sc, 'exito': sc >= 3.2}
            score_ant = sc
            texto += ' [corregido]'
        return {'rondas': max_rondas, 'score': sc, 'exito': False}
    except Exception as err:
        logger.error(f'Fallo bucle: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'error': 'Excepcion'}
```

### 5.2 Contraejemplo y Caso Límite

Un generador obstinado que insiste en usar una palabra prohibida entrará en bucle de 100 llamadas contra Jev, consumiendo cuotas de API inútilmente sin una condición de parada dura.
