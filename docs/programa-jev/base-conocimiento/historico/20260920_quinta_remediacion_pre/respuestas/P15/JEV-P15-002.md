# JEV-P15-002 — Decisiones Semánticas de Soporte a la Investigación sin Impacto en Trading Directo

## 1. Respuesta directa y decisión que permite tomar

El valor probado de Jev 1.13 en QRT reside en tareas de soporte cognitivo a los analistas cuantitativos: 1) Clasificación y extracción de metadatos de hechos esenciales reportados a la CMF; 2) Triaje de literatura científica para priorizar papers reproducibles; y 3) Monitoreo de coherencia entre afirmaciones y datos en reportes internos. Estas tareas ahorran horas de lectura manual sin intervenir en el cálculo de señales alfa ni en el enrutamiento de órdenes.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Automatización de back-office de investigación, enriquecimiento de datos textuales y productividad del analista.
- **Supuesto clave**: Entorno de investigación documental hermético y aislado del motor de trading algorítmico.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia cuantitativa**: Evaluación del diagnóstico de QRT: el cuello de botella del equipo radica en el tiempo invertido en leer memorandos y catalogar fuentes macroeconómicas.
- **Contraste econométrico**: Se prohíbe deducir rentabilidad o predicción financiera a partir de exactitud de clasificación de texto.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Canal de enriquecimiento asíncrono: Entrada: Hecho esencial en PDF extraído de la CMF. Jev devuelve `Choice` con el tipo de evento corporativo (`Aumento_Capital`, `Cambio_Directorio`, `Dividendo`). El resultado se indexa en una base de datos relacional para consulta histórica.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P15_02')

def clasificar_evento_cmf(texto_hecho_esencial: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_hecho_esencial, questions={'tipo_evento': Choice(instructions='Clasificar evento corporativo segun normativa CMF', criteria={'aumento_capital': 'Hecho esencial de aumento de capital o emisión', 'cambio_directorio': 'Modificación en composición del directorio o administración', 'dividendo': 'Acuerdo de distribución de dividendos o utilidades', 'hecho_menor': 'Comunicación de hecho de interés no calificado como esencial'})})
        return res.answers['tipo_evento'].choice
    except Exception as err:
        logger.error(f'Fallo en clasificador CMF: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'hecho_menor'
```

- **Contraejemplo / Caso borde**: Intentar que Jev 'prediga si la acción subirá o bajará' basándose en el hecho esencial en lugar de solo clasificar el tipo de evento corporativo.
