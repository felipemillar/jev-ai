# JEV-P15-018 — Aislamiento Hermético entre Entorno de Investigación y Ejecución Algorítmica

## 1. Respuesta directa y decisión que permite tomar

Existe una frontera de red infranqueable entre el entorno de investigación documental (donde operan Antigravity, NotebookLM y las pruebas con la API de TypeSafe) y el entorno productivo de ejecución algorítmica de QRT. Los servidores de trading de MetaTrader 5 residen en una VPC aislada sin acceso a internet público y sin conexión con las APIs de IA. Los resultados de investigación solo se transfieren como datasets estáticos auditados mediante un canal unidireccional seguro.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Ciberseguridad de infraestructura financiera, segmentación de redes y prevención de intrusiones.
- **Supuesto clave**: Entorno de investigación documental hermético y aislado del motor de trading algorítmico.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia cuantitativa**: Normativa de seguridad de infraestructuras críticas financieras y directrices del comité de ciberseguridad de QRT.
- **Contraste econométrico**: Se prohíbe deducir rentabilidad o predicción financiera a partir de exactitud de clasificación de texto.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Air-Gap lógico: La VPC de Trading solo permite conexiones salientes autenticadas hacia las IPs fijas de los brokers. Queda completamente bloqueado el tráfico hacia dominios de IA (`api.typesafe.ai`, Google Cloud, etc.).
