# JEV-P14-008 — Priorización Multicriterio de Tareas: Separación de Urgencia, Esfuerzo y Dependencias

## 1. Respuesta directa y decisión que permite tomar

El ordenamiento de una lista de tareas pendientes no debe delegarse a una sola escala ordinal simplista de 'prioridad'. La arquitectura debe evaluar dimensiones ortogonales independientes: 1) Urgencia temporal (fecha límite determinista calculada en CPU); 2) Importancia estratégica evaluada con Jev mediante `Score(1, 5)`; 3) Estimación de esfuerzo cognitivo (`Choice` entre `bajo`, `medio`, `alto`); y 4) Existencia de dependencias bloqueantes registradas en base de datos relacional. La combinación se ejecuta mediante una función de prioridad determinista en Python.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Metodología de gestión del tiempo (Matriz de Eisenhower multidimensional) y optimización de productividad.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Estándares de gestión de proyectos ágiles y principios de la matriz de Stephen Covey sobre tareas urgentes vs importantes.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Fórmula determinista de prioridad: $\text{Prioridad} = (\text{Score}_{\text{importancia}} \times 2.0) + \text{Factor}_{\text{plazo}} - \text{Factor}_{\text{esfuerzo}}$. Las tareas bloqueadas por dependencias pendientes reciben automáticamente prioridad 0.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P14_08")

def calcular_prioridad_compuesta(score_importancia: int, esfuerzo_str: str, dias_restantes: int, tiene_bloqueos: bool) -> float:
    try:
        if tiene_bloqueos:
            return 0.0  # Bloqueada
        peso_esfuerzo = {"bajo": 1.0, "medio": 2.0, "alto": 3.0}.get(esfuerzo_str, 2.0)
        factor_urgencia = max(0.0, 10.0 - dias_restantes)
        prioridad = (score_importancia * 2.0) + factor_urgencia - (peso_esfuerzo * 0.5)
        return round(prioridad, 2)
    except Exception as err:
        logger.error(f"Fallo en calculo de prioridad: {type(err).__name__} (detalles omitidos por seguridad)")
        return 0.0
```

- **Contraejemplo / Caso borde**: Permitir que el modelo asigne 'Prioridad Alta' a una tarea gigantesca cuya fecha límite es en seis meses mientras vencen trámites regulatorios urgentes de hoy.
