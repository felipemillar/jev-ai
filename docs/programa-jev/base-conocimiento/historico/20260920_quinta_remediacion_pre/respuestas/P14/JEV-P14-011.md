# JEV-P14-011 — Filtro de Alertas de Investigación: Reducción de Ruido sin Ocultar Novedades Raras

## 1. Respuesta directa y decisión que permite tomar

Un filtro eficaz de alertas de investigación (arXiv, blogs científicos, lanzamientos de software) debe resolver la tensión entre saturación por ruido y pérdida de señales raras de alto valor. Para evitar que el filtro silencie avances disruptivos que utilizan vocabulario no convencional, Jev debe configurarse para descartar únicamente el ruido obvio (publicidad, spam, noticias repetitivas), derivando cualquier artículo técnico con términos inusuales o metodología estadística a una bandeja de 'revisión exploratoria rápida'.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Vigilancia tecnológica, filtrado de información científica y retención de señales débiles (Weak Signals).
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Prácticas de inteligencia competitiva y vigilancia tecnológica en centros de investigación aplicada.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Compuerta de Descarte Conservadora: Solo se descarta un ítem si la probabilidad de que sea irrelevante es superior a 0.90 en una primitiva `Choice(instructions='Filtrar alertas preservando novedades atipicas', criteria={'relevante_directo': 'Alerta relevante directa que exige acción', 'novedad_atipica': 'Novedad atípica o patrón fuera de distribución', 'ruido_irrelevante': 'Ruido operativo o fluctuación insignificante'})`.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P14_11')

def filtrar_alerta_tecnologica(texto_alerta: str) -> str:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=texto_alerta, questions={'clasificacion': Choice(instructions='Filtrar alertas preservando novedades atipicas', criteria={'relevante_directo': 'Alerta relevante directa que exige acción', 'novedad_atipica': 'Novedad atípica o patrón fuera de distribución', 'ruido_irrelevante': 'Ruido operativo o fluctuación insignificante'})})
        return res.answers['clasificacion'].choice
    except Exception as err:
        logger.error(f'Fallo en filtro de alertas: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'novedad_atipica'
