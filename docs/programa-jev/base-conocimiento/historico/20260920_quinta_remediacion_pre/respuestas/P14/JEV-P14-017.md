# JEV-P14-017 — Diseño de Interfaz Minimalista: Decisión, Evidencia Breve y Opción de Corregir

## 1. Respuesta directa y decisión que permite tomar

La interfaz de usuario para flujos personales no debe saturar al usuario con párrafos explicativos extensos que obliguen a perder tiempo leyendo la justificación del modelo. La pantalla debe presentar exclusivamente tres elementos concisos: 1) La decisión o etiqueta propuesta (e.g. `URGENTE`); 2) La evidencia mínima directa (una frase de hasta 15 palabras extraída del texto original); y 3) Un botón de un solo clic para corregir la categoría si el modelo falló.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Diseño de interfaces de usuario (UI/UX) para herramientas de IA centradas en la velocidad cognitiva.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Principios de diseño de interacción humano-IA de Microsoft (Guideline 4: Show contextually relevant information and enable easy dismissal).
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Estructura de la tarjeta visual (UI Card): Encabezado con etiqueta + Píldora de extracto textual + Menú desplegable o botones rápidos de reasignación. El clic de corrección actualiza inmediatamente la base local de reglas.
