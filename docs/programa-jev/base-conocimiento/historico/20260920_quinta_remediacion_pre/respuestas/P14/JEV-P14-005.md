# JEV-P14-005 — Decisiones Personales que Exigen Confirmación Humana Obligatoria (Human Gate)

## 1. Respuesta directa y decisión que permite tomar

Existe un límite ético y operativo no negociable: ciertas decisiones personales jamás deben ejecutarse de forma desatendida, independientemente de que Jev emita una certeza del 99.9%. Acciones irreversibles como: eliminar correos o archivos de forma permanente, ordenar transferencias bancarias o pagos, aceptar o rechazar compromisos en el calendario, o enviar comunicaciones formales a terceros deben requerir confirmación humana explícita en pantalla (Human-in-the-Loop Gate).

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Límites de autonomía de agentes personales, control de acciones de alto impacto y seguridad de usuario.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Principios de gobernanza de agentes de IA: las acciones con consecuencias legales, financieras o interpersonales irreversibles exigen confirmación activa del usuario.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Patrón Propose-and-Confirm: El componente de Jev genera una propuesta etiquetada (`status: PROPUESTA_PENDIENTE`); la interfaz muestra dos botones claros ('Aprobar acción' y 'Rechazar'). Solo el evento de clic del usuario dispara la mutación transaccional.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P14_05")

def procesar_accion_critica(tipo_accion: str, detalles: dict, confirmacion_usuario: bool) -> dict:
    try:
        acciones_irreversibles = {"BORRAR_ARCHIVO", "ENVIAR_PAGO", "CANCELAR_REUNION"}
        if tipo_accion in acciones_irreversibles:
            if not confirmacion_usuario:
                logger.info(f"Accion critica detenida esperando aprobacion humana: {tipo_accion}")
                return {"estado": "PENDIENTE_APROBACION_HUMANA", "detalles": detalles}
            return {"estado": "EJECUTADO_CON_CONFIRMACION", "accion": tipo_accion}
        return {"estado": "EJECUTADO_AUTONOMO", "accion": tipo_accion}
    except Exception as err:
        logger.error(f"Fallo en compuerta humana: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"estado": "ERROR_SEGURIDAD"}
```

- **Contraejemplo / Caso borde**: Permitir que un script borre automáticamente 100 correos que Jev clasificó como 'spam' provocará la pérdida definitiva de un contrato importante clasificado por error.
