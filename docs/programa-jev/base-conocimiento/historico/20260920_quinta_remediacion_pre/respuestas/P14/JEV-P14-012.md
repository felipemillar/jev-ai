# JEV-P14-012 — Enrutamiento de Consultas Personales: Búsqueda, Cálculo, Generativo o Jev

## 1. Respuesta directa y decisión que permite tomar

El asistente personal no debe intentar resolver todas las dudas mediante un único modelo de lenguaje. Debe implementar un enrutador determinista que despache cada solicitud según su naturaleza ontológica: 1) Cálculos matemáticos, fechas y conversiones -> Python determinista en CPU; 2) Búsqueda factual de documentos propios -> Recuperador BM25/SQLite local; 3) Decisiones semánticas breves y triaje -> Jev 1.13; y 4) Redacción de correos largos o lluvia de ideas creativa -> LLM generativo frontier.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Arquitectura de asistentes personales modulares y optimización de herramientas por propósito.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Principios de diseño de agentes híbridos: la especialización funcional de herramientas supera ampliamente a los agentes monolíticos de texto libre.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Clasificador de intención rápido: Evaluar con expresiones regulares preliminares si hay operadores matemáticos; si requiere semántica, Jev clasifica el tipo de consulta en una llamada de 150 ms para dirigir el flujo.

import logging

logger = logging.getLogger("P14_12")

def enrutar_consulta_asistente(consulta_texto: str) -> str:
    try:
        # Deteccion rapida de calculo determinista
        if any(char in "+-*/=" for char in consulta_texto) and any(c.isdigit() for c in consulta_texto):
            return "MOTOR_CALCULO_PYTHON"
        if len(consulta_texto.split()) < 6 and "?" not in consulta_texto:
            return "BUSQUEDA_LOCAL_SQLITE"
        if "redactar" in consulta_texto.lower() or "escribir borrador" in consulta_texto.lower():
            return "LLM_GENERATIVO_FRONTIER"
        return "DECISION_SEMANTICA_JEV"
    except Exception as err:
        logger.error(f"Fallo en enrutador personal: {type(err).__name__} (detalles omitidos por seguridad)")
        return "DECISION_SEMANTICA_JEV"
