# JEV-P14-009 — Clasificación de Notas de Reuniones sin Inferencia de Falsos Acuerdos

## 1. Respuesta directa y decisión que permite tomar

Al clasificar o procesar minutas de reuniones no estructuradas, el sistema debe limitarse estrictamente a etiquetar los pasajes donde se expresaron acuerdos consensuados explícitos, prohibiendo la inferencia de consensos no formulados verbalmente. Si en el texto se lee 'se discutió la posibilidad de cambiar el proveedor', Jev debe clasificarlo como `tema_en_discusion` y jamás como `acuerdo_adoptado`. Todo acuerdo extraído debe citar el fragmento textual literal.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Procesamiento de actas corporativas, fidelidad documental y prevención de malentendidos organizacionales.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Buenas prácticas de secretaría corporativa y gobernanza de decisiones organizacionales.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Primitiva de validación estricta: `Choice(instructions='Determinar si existe un acuerdo formalmente adoptado', criteria={'acuerdo_explicito': 'Acuerdo explícito formalmente adoptado en acta', 'debate_sin_resolucion': 'Punto debatido sin adopción de resolución', 'informacion_informativa': 'Mención de carácter meramente informativo'})`. Solo los pasajes con certeza superior a 0.85 se vinculan a la lista formal de decisiones de la reunión.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
import logging
from typesafe_sdk import TypeSafeClient, Choice
logger = logging.getLogger('P14_09')

def auditar_acuerdo_reunion(extracto_dialogo: str) -> dict:
    try:
        client = TypeSafeClient(model='jev-1.13.0')
        res = client.system_one(state=extracto_dialogo, questions={'estado_acuerdo': Choice(instructions='Determinar si existe un acuerdo formalmente adoptado', criteria={'acuerdo_explicito': 'Acuerdo explícito formalmente adoptado en acta', 'debate_sin_resolucion': 'Punto debatido sin adopción de resolución', 'informacion_informativa': 'Mención de carácter meramente informativo'})})
        ans = res.answers['estado_acuerdo']
        return {'es_acuerdo_firme': ans.choice == 'acuerdo_explicito', 'confianza': ans.confidence}
    except Exception as err:
        logger.error(f'Fallo en auditoria de acuerdos: {type(err).__name__} (detalles omitidos por seguridad)')
        return {'es_acuerdo_firme': False, 'confianza': 0.0}
```
