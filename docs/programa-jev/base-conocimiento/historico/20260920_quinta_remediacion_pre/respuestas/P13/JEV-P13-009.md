# JEV-P13-009 — Escenarios Comparativos de Volumen: Bajo (1K), Medio (50K) y Alto (1M de Llamadas)

## 1. Respuesta directa y decisión que permite tomar

La viabilidad económica de Jev varía drásticamente según el nivel de actividad: 1) Escenario Bajo (1.000 llamadas/mes): Costo API < $0.10 USD/mes; el costo dominante es el desarrollo e integración inicial. Jev SaaS es la única opción razonable. 2) Escenario Medio (50.000 llamadas/mes): Costo API ~$4.20 USD/mes; excelente relación costo-beneficio. 3) Escenario Alto (1.000.000 llamadas/mes): Costo API ~$84.00 USD/mes. Aún en 1M de llamadas, Jev SaaS sigue siendo notablemente más barato que un servidor GPU propio ($400/mes).

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Dimensionamiento por escalas de uso, presupuestos comparativos y horizontes de volumen.
- **Supuesto clave**: Evaluación financiera a precios plenos documentados ($0.042/Mtok) sin subsidios temporales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia económica**: Datos empíricos de consumo de APIs del Programa Jev en entornos piloto y pre-producción.
- **Contraste de modelos**: Se comparan escenarios de SaaS gestionado frente a auto-hosting de GPU y LLMs frontier generativos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Tabla comparativa de costos directos mensuales (2.000 tokens promedio): 1K = $0.084 USD; 50K = $4.20 USD; 1M = $84.00 USD; 10M = $840.00 USD. A partir de 6M llamadas al mes se justifica formalmente evaluar hosting local.
