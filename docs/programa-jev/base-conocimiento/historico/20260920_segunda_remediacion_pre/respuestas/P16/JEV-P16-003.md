# JEV-P16-003 — Wheelwork: Operaciones de Recursos Humanos y Gobernanza Ética

## 1. Respuesta directa y decisión que permite tomar
Tres pilotos seguros para Wheelwork con datos sintéticos: (1) Verificación de cumplimiento de requisitos excluyentes formales (ej. titulación legal requerida o certificación técnica vigente), (2) Clasificación de solicitudes de empleo por área funcional (Ventas, TI, Operaciones), y (3) Detección de omisiones de información de contacto.

## 2. Alcance, términos y supuestos
- **Contexto:** Operaciones de talento y RRHH de Wheelwork.
- **Límites Normativos:** Prohibición absoluta de descarte algorítmico automatizado sin revisión humana (Human-in-the-Loop obligatorio).
- **Protección de Datos:** Anonimización local en CPU de todos los identificadores directos e indirectos antes de la llamada a la API.

## 4. Explicación técnica verificable
Estos pilotos operan con perfiles generados artificialmente, garantizando riesgo cero de vulneración de privacidad.

### Salvaguardas Éticas y Operativas en Wheelwork
1. **Anonimización Criptográfica:** Redacción en CPU local de nombres, género, colegios y domicilios antes de la inferencia.
2. **Extracción con Cita de Respaldo:** Cada competencia sugerida debe vincularse al fragmento literal del currículum.
3. **Pruebas Contrafactuales Regulares:** Verificación empírica de que la permutación de atributos demográficos produce idéntico resultado.
4. **Supervisión Humana Obligatoria:** El sistema solo emite recomendaciones; el cambio de estado en el ATS requiere acción afirmativa del reclutador.

## 5. Ejemplo trabajado y contraejemplo
- **Módulo de Verificación de Requisitos Objetivos en Python:**
```python
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("JEV-P16-003")

def verificar_requisito_tecnico(cv_anonimizado: str, tecnologia_requerida: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(
            state=f"Requisito: Experiencia práctica demostrable en {tecnologia_requerida}\n\nPerfil:\n{cv_anonimizado[:1200]}",
            questions={
                "evidencia": Choice(
                    instructions="¿El candidato acredita experiencia directa en la tecnología?",
                    criteria={"acreditada": "Menciona proyectos o roles con la tecnologia", "no_acreditada": "No la menciona o solo la lista como interés"}
                )
            }
        )
        ans = res.answers["evidencia"]
        return {"resultado": ans.choice, "confidence": ans.confidence, "estado": "exito"}
    except Exception as err:
        logger.error(f"Fallo en verificacion Wheelwork: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"resultado": "no_acreditada", "confidence": 0.0, "estado": "error_operativo"}
```
- **Contraejemplo:** Rechazar automáticamente al 50% de los postulantes con menor `confidence` sin revisión humana: constituye una práctica laboral discriminatoria e ilegal sujeta a sanciones regulatorias.
