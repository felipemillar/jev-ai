# JEV-P05-003: Evidencia Requerida para Certificar Calibración Local en Nuestros Datos

## 1. Respuesta directa y decisión que permite tomar

Las afirmaciones de calibración provistas por TypeSafe AI ($ECE \approx 0.03$) constituyen únicamente **evidencia de laboratorio en la distribución de origen del proveedor** (predominantemente benchmarks académicos en inglés como MNLI, HellaSwag y tareas de clasificación general). En estadística del aprendizaje automático, es un principio demostrado que **la calibración probabilística no se transfiere invariante bajo desplazamiento de dominio (*Covariate Shift* o *Concept Shift*)**.

Para afirmar con validez científica y prudencia empresarial que las salidas de Jev 1.13 están verdaderamente calibradas en nuestros datos (Wheelwork y QRT), se requiere un **Protocolo de Certificación Empírica Local Ciega** compuesto por cuatro requisitos de evidencia demostrable:

1. **Dataset Representativo Local Auditado ($N \ge 1,000$)**: Un conjunto de prueba extraído directamente de la distribución real de producción (contratos chilenos, documentos del SII, balances locales, transcripciones de atención telefónica), con etiquetas *ground truth* verificadas por al menos dos expertos humanos independientes con concordancia inter-anotador $\kappa$ de Cohen $\ge 0.85$.
2. **Medición Formal de Confiabilidad y Descomposición de Brier**:
   - *Expected Calibration Error (ECE)* calculado mediante cuantiles de frecuencia adaptativa (*Equal-Frequency Binning*, $M=10$) con umbral estricto: $\text{ECE} \le 0.05$.
   - *Maximum Calibration Error (MCE)* que acote el peor intervalo de probabilidad: $\text{MCE} \le 0.12$.
   - *Brier Score y su Descomposición*: Demostrar que el término de fiabilidad (*Reliability*) tiende a cero ($< 0.015$).
3. **Diagrama de Fiabilidad con Bandas de Confianza Bootstrap (95%)**: La curva de calibración observada debe intersectar la diagonal ideal ($y = x$) dentro del intervalo de confianza del 95% obtenido por remuestreo bootstrap (1,000 iteraciones).
4. **Prueba de Bondad de Ajuste Estadística (Hosmer-Lemeshow / Spiegelhalter)**: La prueba estadística formal de hipótesis no debe rechazar la hipótesis nula de calibración ($p\text{-value} > 0.05$).
5. **Auditoría de Invarianza por Subgrupos Críticos**: Demostrar que la calibración se mantiene en estratos minoritarios vulnerables o de alto impacto (e.g., conductores jóvenes en Wheelwork, empresas emergentes en QRT).

**Decisión que permite tomar**: Prohibir la adopción de las probabilidades de Jev 1.13 en entornos de producción con riesgo financiero o legal mientras no se haya ejecutado y aprobado el Protocolo de Certificación Empírica Local sobre un conjunto ciego de nuestros datos. Mientras esta evidencia no exista, el estado de la calibración debe catalogarse formalmente como `no_verificado` en nuestros sistemas.

## 2. Alcance, términos, versiones y supuestos

- **Alcance**: Requisitos metodológicos, matemáticos y operacionales para validar la calibración de Jev 1.13 en datos de negocio chilenos para Wheelwork y QRT.
- **Términos formalizados**:
  - *Domain Shift (Desplazamiento de Dominio)*: Variación entre la distribución de datos en la que el proveedor entrenó el modelo $P_{\text{train}}(X)$ y la distribución operativa real $P_{\text{prod}}(X)$.
  - *Equal-Frequency Binning (Agrupación por Frecuencia Homogénea)*: Partición del espacio de probabilidades en intervalos que contienen el mismo número de observaciones, evitando el sesgo de bins vacíos del agrupamiento uniforme.
  - *Bootstrap Confidence Bands*: Intervalos empíricos construidos mediante remuestreo con reemplazo para cuantificar la incertidumbre de la curva de fiabilidad debida al tamaño muestral finito.
  - *Spiegelhalter's Z-Test*: Prueba estadística de calibración que evalúa si la suma ponderada de errores de Brier difiere significativamente de cero.
- **Versiones de referencia**: Jev 1.13 (`typesafe-ai >= 0.1.0`), Python 3.11+, Scipy, Statsmodels.
- **Supuestos fundamentales**:
  1. El etiquetado humano local es el estándar de oro (*Ground Truth*); si los humanos discrepan entre sí, la incertidumbre es aleatoria (ruido de etiqueta) y no necesariamente descalibración del modelo.
  2. Un tamaño muestral inferior a $N = 500$ carece de potencia estadística para detectar descalibraciones en los extremos de la distribución ($p < 0.10$ o $p > 0.90$).

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1. Ejemplo sintético trabajado: Protocolo Automatizado de Certificación en Python

```python
"""
Protocolo de Certificación de Calibración Local con Bootstrap y Test de Spiegelhalter.
"""
import numpy as np
from scipy import stats
from typing import Dict, Any, Tuple

class LocalCalibrationCertificationProtocol:
    def __init__(self, ece_threshold: float = 0.05, mce_threshold: float = 0.12, p_value_threshold: float = 0.05):
        self.ece_threshold = ece_threshold
        self.mce_threshold = mce_threshold
        self.p_value_threshold = p_value_threshold

    def evaluate_dataset(self, y_true: np.ndarray, y_prob: np.ndarray, n_bootstrap: int = 1000) -> Dict[str, Any]:
        """
        Ejecuta la batería completa de certificación sobre una muestra local.
        """
        n = len(y_true)
        if n < 500:
            raise ValueError(f"Muestra insuficiente ({n} < 500) para certificación formal.")

        # 1. Brier Score
        brier = np.mean((y_prob - y_true) ** 2)

        # 2. Adaptive ECE (Quantile Bins)
        quantiles = np.linspace(0, 1, 11)
        bin_edges = np.quantile(y_prob, quantiles)
        bin_edges[0] = 0.0
        bin_edges[-1] = 1.0 + 1e-6

        bin_indices = np.digitize(y_prob, bin_edges) - 1
        ece = 0.0
        mce = 0.0

        for b in range(10):
            mask = bin_indices == b
            if np.sum(mask) > 0:
                acc = np.mean(y_true[mask])
                conf = np.mean(y_prob[mask])
                diff = np.abs(acc - conf)
                ece += (np.sum(mask) / n) * diff
                if diff > mce:
                    mce = diff

        # 3. Spiegelhalter's Z-Test para calibración probabilística
        # H0: El modelo está perfectamente calibrado
        # Estadístico z = sum((y - p) * (1 - 2p)) / sqrt(sum((1 - 2p)^2 * p * (1 - p)))
        numerator = np.sum((y_true - y_prob) * (1 - 2 * y_prob))
        variance = np.sum(((1 - 2 * y_prob) ** 2) * y_prob * (1 - y_prob))
        
        if variance > 0:
            z_stat = numerator / np.sqrt(variance)
            p_val = 2 * (1 - stats.norm.cdf(np.abs(z_stat)))
        else:
            z_stat, p_val = 0.0, 1.0

        # Dictamen final
        pasa_ece = ece <= self.ece_threshold
        pasa_mce = mce <= self.mce_threshold
        pasa_pval = p_val >= self.p_value_threshold
        certificado = pasa_ece and pasa_mce and pasa_pval

        return {
            "muestras": n,
            "brier_score": round(float(brier), 4),
            "adaptive_ece": round(float(ece), 4),
            "mce": round(float(mce), 4),
            "spiegelhalter_z": round(float(z_stat), 3),
            "spiegelhalter_p_value": round(float(p_val), 4),
            "criterios": {
                "ece_aprobado": bool(pasa_ece),
                "mce_aprobado": bool(pasa_mce),
                "test_estadistico_aprobado": bool(pasa_pval)
            },
            "dictamen_final": "CALIBRACION_LOCAL_CERTIFICADA" if certificado else "REQUIERE_RECALIBRACION"
        }

# Simulación de prueba con dos escenarios
if __name__ == "__main__":
    np.random.seed(101)
    N = 1000

    # Escenario A: Datos de proveedor en distribución (Bien calibrados)
    p_ideal = np.random.uniform(0.1, 0.9, N)
    y_ideal = np.random.binomial(1, p_ideal)

    # Escenario B: Nuestros datos locales con Desplazamiento de Dominio (Sobreconfianza OOD)
    p_ood = np.random.beta(4, 2, N)  # Sesgado a valores altos (0.75 - 0.95)
    y_ood = np.random.binomial(1, p_ood * 0.75)  # Acierto un 25% menor al predicho

    certificador = LocalCalibrationCertificationProtocol()

    print("=== AUDITORÍA ESCENARIO A (Datos en Distribución) ===")
    res_a = certificador.evaluate_dataset(y_ideal, p_ideal)
    print(f"ECE: {res_a['adaptive_ece']} | p-value: {res_a['spiegelhalter_p_value']} | Dictamen: {res_a['dictamen_final']}")

    print("\n=== AUDITORÍA ESCENARIO B (Nuestros Datos Locales OOD) ===")
    res_b = certificador.evaluate_dataset(y_ood, p_ood)
    print(f"ECE: {res_b['adaptive_ece']} | p-value: {res_b['spiegelhalter_p_value']} | Dictamen: {res_b['dictamen_final']}")
```

### 5.2. Contraejemplo y Caso Límite: Benchmark Aprobado con Datos Sintéticos que Oculta Errores en la Jerga Chilena

Un equipo de ingeniería valida Jev 1.13 traduciendo el benchmark Stanford NLI al español neutro mediante Google Translate.
- En este dataset neutro, el modelo obtiene un impecable $ECE = 0.028$ y aprueba la auditoría con honores.
- Al desplegar en Wheelwork, los clientes escriben reclamos usando modismos chilenos (*"el auto tironea caleta y quedó botado en la pana del tonto"*).
- Jev 1.13 no reconoce `"pana del tonto"` (quedarse sin bencina por negligencia) y clasifica el reclamo como `"FALLO_MECANICO_GRAVE_VEHICULO"` con confianza de $0.94$, activando el protocolo de grúa y sustitución de vehículo sin costo para el arrendatario negligente.
- **Falla de evidencia**: El benchmark sintético tradujo palabras pero no capturó la distribución semántica local. La afirmación de calibración era un artefacto del dataset traducido, no una propiedad del modelo en la realidad operacional chilena.

## 7. Fallos, límites, controles y condiciones de no uso

### 7.1. Modos de falla y mitigaciones

| Modo de Falla | Causa Raíz | Detección | Mitigación Arquitectónica |
|---|---|---|---|
| **Fuga de Evaluación (Data Leakage)** | Incluir casos del conjunto de calibración en el conjunto ciego de certificación. | ECE anormalmente bajo en validación ($0.01$) que sube drásticamente en producción. | Separación criptográfica estricta de conjuntos mediante partición determinista por SHA-256 de ID. |
| **Sesgo de Muestra Pequeña** | Intentar certificar calibración con solo 100 casos. | Bandas de confianza bootstrap excesivamente anchas ($[0.01, 0.25]$). | Prohibir certificación formal con muestras menores a $N = 1,000$. |
| **Deriva Temporal de Calibración** | El modelo estaba calibrado en marzo, pero en julio una reforma tributaria altera el léxico. | Monitoreo continuo del Brier Score en ventanas móviles de 30 días en producción. | Programar auditorías periódicas de re-certificación semestrales. |

### 7.2. Condiciones de NO uso

- **NO utilizar sellos o certificaciones del proveedor como sustituto de la validación local**: Ningún informe de TypeSafe AI es admisible como prueba de calibración ante auditores internos o comités de riesgo.
- **NO certificar calibración sobre datos sintéticos generados por el mismo modelo**: Evaluar a Jev con datos sintéticos generados por transformers genera un sesgo de auto-confirmación ilusorio.

### 8.1. Diseño experimental
- **Hipótesis falsable**: La ejecución del Protocolo de Certificación Empírica Local sobre una muestra ciega de 1,000 documentos de negocio de Wheelwork y QRT rechazará la calibración de fábrica de Jev 1.13 con un $p\text{-value} < 0.01$ en el test de Spiegelhalter, pero tras el ajuste de un parámetro único de temperatura $T^* \in [1.2, 1.8]$ en CPU, el protocolo aprobará la certificación con $\text{ECE} \le 0.045$ y $p\text{-value} > 0.10$.
- **Dataset sintético de prueba**: 1,000 casos representativos con doble validación experta.
- **Métricas y umbrales**:
  - ECE post-ajuste: $\le 0.05$.
  - MCE post-ajuste: $\le 0.12$.
  - Spiegelhalter p-value: $> 0.05$.
- **Criterio de rechazo**: Si tras ajustar Temperature Scaling el ECE permanece por encima de $0.06$, se descarta el modelo de temperatura única y se evalúa Regresión Isotónica no paramétrica.
- **Presupuesto estimado**: Ejecución puramente local en CPU = $0.00 USD.
