# JEV-P18-017 — Nuevos Productos, Modelos SaaS y Viabilidad Comercial

## 1. Respuesta directa y decisión que permite tomar
Señales de incompatibilidad de producto con Jev: Si el cliente demanda respuestas redactadas en lenguaje natural libre, resúmenes estilísticos extensos o cálculos contables de precisión, la oportunidad no es apta para Jev.

## 2. Alcance, términos y supuestos
- **Contexto:** Desarrollo de nuevos productos, módulos SaaS e iniciativas de negocio.
- **Ventaja Diferencial:** Tarifa ultra-competitiva ($0.042/Mtok de entrada, salida gratuita) y latencia estructurada en clasificación masiva.
- **Límites de Producto:** Exclusión estricta de aplicaciones que requieran generación de texto extenso o razonamiento creativo abierto.

## 4. Explicación técnica verificable
El sistema de triaje debe rechazar estos proyectos en fase de descubrimiento para evitar frustración del cliente y fallos en producción.

### Marco de Evaluación de Oportunidades de Producto
1. **Validación de Alternativa Actual:** Si un script de Python con regex o búsqueda elástica resuelve el caso, se veta el uso de IA cloud.
2. **Unit Economics Rentables:** El valor económico aportado al cliente debe superar holgadamente el TCO (Coste de inferencia + Gateway + Supervisión humana).
3. **Portabilidad de Proveedor:** Arquitectura basada en interfaces desacopladas para mitigar el riesgo de bloqueo comercial con TypeSafe.
4. **Filtro Ético y Regulatorio:** Descarte inmediato de aplicaciones de alto riesgo legal o discriminatorio.

## 5. Ejemplo trabajado y contraejemplo
- **Middleware de Enrutamiento Semántico de Consultas en Python:**
```python
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("JEV-P18-017")

def enrutar_consulta_cliente(texto_peticion: str) -> dict:
    try:
        # Triaje de intencion para optimizar costes de soporte
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(
            state=texto_peticion[:1000],
            questions={
                "destino": Choice(
                    instructions="Clasificar peticion de soporte para derivacion",
                    criteria={"facturacion": "Cobros, facturas o pagos", "soporte_tecnico": "Incidencias de software o errores", "ventas": "Contratacion de nuevos planes"}
                )
            }
        )
        ans = res.answers["destino"]
        return {"cola_destino": ans.choice, "confidence": ans.confidence, "accion": "enrutar"}
    except Exception as err:
        logger.error(f"Fallo en enrutador comercial: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"cola_destino": "triaje_manual_general", "confidence": 0.0, "accion": "fallback"}
```
