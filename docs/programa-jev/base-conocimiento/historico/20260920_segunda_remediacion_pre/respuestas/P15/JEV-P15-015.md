# JEV-P15-015 — QRT: Investigación Cuantitativa y Soberanía Operativa

## 1. Respuesta directa y decisión que permite tomar
Para prevenir fuga de información por revisiones de datos corporativos (earnings restatements), el repositorio histórico debe utilizar almacenamiento Point-in-Time estricto que devuelva únicamente la cifra conocida por el mercado en la fecha T.

## 2. Alcance, términos y supuestos
- **Contexto:** División de Quantitative Research & Trading (QRT).
- **Límite Estricto:** Prohibición absoluta de cursar órdenes de trading, gestionar posiciones o alterar algoritmos de ejecución con modelos de lenguaje.
- **Soberanía Determinista:** La infraestructura de trading (MT5, pasarelas FIX, cálculo de riesgos) opera bajo control matemático determinista en CPU local.

## 4. Explicación técnica verificable
Cualquier reporte semántico analizado por Jev debe alimentarse exclusivamente de la versión original del comunicado emitida en T.

### Principios de Arquitectura en QRT
1. **Segregación de Redes (Air-Gap Lógico):** Los servicios que consumen la API de TypeSafe están aislados en una red de análisis y carecen de conectividad con los terminales de ejecución.
2. **Control de Sesgo de Anticipación (Point-in-Time):** Todos los documentos y noticias se indexan con el timestamp de primera emisión pública verificable.
3. **Validación Falsable:** Ninguna categorización textual se considera señal de mercado sin superar un riguroso test de Purged Walk-Forward con corrección de pruebas múltiples.
4. **Respaldo Determinista:** La caída o degradación de la API de TypeSafe nunca interrumpe el motor de ejecución financiera.

## 5. Ejemplo trabajado y contraejemplo
- **Módulo de Clasificación Cualitativa en Python para QRT:**
```python
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("JEV-P15-015")

def clasificar_comunicado_macro(titular: str, cuerpo: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(
            state=f"Titular: {titular}\nCuerpo: {cuerpo[:1500]}",
            questions={
                "sesgo_politica": Choice(
                    instructions="Determinar sesgo declarado en comunicado",
                    criteria={"contractivo": "Alza de tasas / endurecimiento", "expansivo": "Baja de tasas / estimulo", "neutro": "Sin cambios"}
                )
            }
        )
        ans = res.answers["sesgo_politica"]
        return {"sesgo": ans.choice, "confidence": ans.confidence, "estado": "exito"}
    except Exception as err:
        logger.error(f"Fallo en clasificacion documental QRT: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"sesgo": "neutro", "confidence": 0.0, "estado": "error_operativo"}
```
- **Contraejemplo:** Alimentar una salida de Jev directamente a una orden `OrderSend` de MetaTrader 5: violación flagrante de los protocolos de gestión de riesgo financiero y causa de descalificación inmediata.
