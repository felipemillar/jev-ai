# JEV-P14-001 — Productividad Personal, Triaje y Asistencia

## 1. Respuesta directa y decisión que permite tomar
Un inventario de decisiones personales repetitivas debe clasificar las tareas en una matriz 2x2 de Frecuencia vs. Variabilidad Semántica. Solo justifican automatización con Jev aquellas tareas de alta frecuencia (> 15 ocurrencias/semana) y baja variabilidad de consecuencias (riesgo acotado). Automatizar tareas esporádicas o de alta ambigüedad introduce sobrecostes de supervisión y mantenimiento que anulan cualquier ahorro de tiempo.

## 2. Alcance, términos y supuestos
- **Ámbito:** Flujos de trabajo personales, triaje de correspondencia, notas, tareas y material de lectura.
- **Restricción de Privacidad:** Prohibición estricta de procesar credenciales, información financiera sensible o datos médicos a través de la API externa.
- **Gobernanza:** Soberanía del usuario; toda acción irreversible requiere autorización humana explícita.

## 4. Explicación técnica verificable
Inventario operativo de triaje: (1) Etiquetado de newsletters y lectura diferida, (2) Categorización de recibos de compra, (3) Triaje de solicitudes en mensajería personal.

### Reglas de Diseño del Flujo Personal
1. **Sanitización Previa en CPU:** Regex local elimina tokens, claves y datos identificativos personales antes de componer el payload.
2. **Inferencia Semántica Rápida:** Llamada síncrona a `POST /v1/systemone` con timeout estricto de 450 ms.
3. **Compuerta de Confianza:** Si `confidence < 0.75`, el elemento se marca como 'requiere_atencion' sin aplicar categorización presuntiva.
4. **Almacenamiento Local Seguro:** Metadatos y etiquetas se persisten en SQLite local con cifrado en reposo.

## 5. Ejemplo trabajado y contraejemplo
- **Implementación Segura en Python:**
```python
# Clasificacion de decisiones personales por umbral de retorno
def evaluar_viabilidad_automatizacion(frecuencia_semanal: int, costo_error_minutos: float) -> str:
    try:
        roi = (frecuencia_semanal * 2.0) - (costo_error_minutos * 0.1)
        return 'AUTOMATIZAR' if roi > 10.0 else 'MANTENER_MANUAL'
    except Exception as err:
        logger.error(f'Error calculando viabilidad: {type(err).__name__} (detalles omitidos por seguridad)')
        return 'ERROR'
```
- **Contraejemplo:** Configurar un script que elimine archivos del disco duro basándose únicamente en una respuesta `Choice` con `confidence = 0.85`: provocará pérdida accidental irreversible de documentos valiosos.
