# JEV-P14-008 — Productividad Personal, Triaje y Asistencia

## 1. Respuesta directa y decisión que permite tomar
La priorización de tareas debe desacoplar sus componentes: Urgencia (días restantes hasta deadline, calculado por CPU), Importancia (alineación con metas estratégicas, evaluada por Jev), Esfuerzo estimado (Fibonacci) y Dependencias deterministas (grafo acíclico DAG).

## 2. Alcance, términos y supuestos
- **Ámbito:** Flujos de trabajo personales, triaje de correspondencia, notas, tareas y material de lectura.
- **Restricción de Privacidad:** Prohibición estricta de procesar credenciales, información financiera sensible o datos médicos a través de la API externa.
- **Gobernanza:** Soberanía del usuario; toda acción irreversible requiere autorización humana explícita.

## 4. Explicación técnica verificable
Jev no calcula fechas ni ordena números; únicamente evalúa la semántica de la alineación estratégica del título y descripción de la tarea.

### Reglas de Diseño del Flujo Personal
1. **Sanitización Previa en CPU:** Regex local elimina tokens, claves y datos identificativos personales antes de componer el payload.
2. **Inferencia Semántica Rápida:** Llamada síncrona a `POST /v1/systemone` con timeout estricto de 450 ms.
3. **Compuerta de Confianza:** Si `confidence < 0.75`, el elemento se marca como 'requiere_atencion' sin aplicar categorización presuntiva.
4. **Almacenamiento Local Seguro:** Metadatos y etiquetas se persisten en SQLite local con cifrado en reposo.

## 5. Ejemplo trabajado y contraejemplo
- **Implementación Segura en Python:**
```python\n# Implementacion de referencia para JEV-P14-008\nimport logging\nfrom typesafe_sdk import TypeSafeClient, Choice\n\nlogger = logging.getLogger("JEV-P14-008")\n\ndef ejecutar_triaje_personal(texto: str) -> dict:\n    try:\n        client = TypeSafeClient(model="jev-1.13.0")\n        res = client.system_one(\n            state=texto[:1000],\n            questions={"prioridad": Choice(instructions="Priorizar", criteria={"alta": "Urgente", "baja": "Rutinario"})}\n        )\n        ans = res.answers["prioridad"]\n        return {"prioridad": ans.choice, "confidence": ans.confidence}\n    except Exception as err:\n        logger.error(f"Error en triaje personal: {type(err).__name__} (detalles omitidos por seguridad)")\n        return {"prioridad": "baja", "confidence": 0.0}\n```
