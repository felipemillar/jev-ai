# JEV-P17-015 — Investigación Rigurosa, Síntesis y Aprendizaje Acumulativo

## 1. Respuesta directa y decisión que permite tomar
Para evitar conflictos en edición concurrente y mantener una única fuente canónica, el repositorio utiliza control de versiones Git con bloqueo de ramas y verificación mediante hashes criptográficos SHA-256.

- **Anticircularidad:** Prohibición estricta de citar textos autogenerados como fuentes de respaldo primario.

## 4. Explicación técnica verificable
Cada pregunta tiene un único archivo markdown asociado; las modificaciones concurrentes deben fusionarse mediante pull requests auditables.

### Protocolos Canónicos de Investigación
1. **Identificadores Persistentes:** Asignación de IDs inmutables a preguntas (`JEV-`), afirmaciones (`CLM-`) y fuentes (`SRC-`).
2. **Validación Automática de Enlaces:** Verificación criptográfica (SHA-256) de la integridad y vigencia de las fuentes citadas.
3. **Control de Declaraciones de Auditoría:** Toda revisión realizada por modelos internos se clasifica como autorrevisión (`en_revision`), dejando la aceptación final a cargo de Codex y supervisión humana.
4. **Respaldo Portátil:** Almacenamiento desacoplado en Markdown plano para garantizar independencia de plataformas externas.

## 5. Ejemplo trabajado y contraejemplo
- **Script de Verificación de Integridad Referencial en Python:**
```python
import os
import re
import logging

logger = logging.getLogger("JEV-P17-015")

def verificar_integridad_citas(directorio_respuestas: str, catalogo_fuentes: set) -> list:
    citas_rotas = []
    try:
        for archivo in os.listdir(directorio_respuestas):
            if archivo.endswith(".md"):
                with open(os.path.join(directorio_respuestas, archivo), "r", encoding="utf-8") as f:
                    contenido = f.read()
                    fuentes_encontradas = re.findall(r"SRC-\d{4}", contenido)
                    for src in fuentes_encontradas:
                        if src not in catalogo_fuentes:
                            citas_rotas.append((archivo, src))
        return citas_rotas
    except Exception as err:
        logger.error(f"Fallo en auditoria de citas: {type(err).__name__} (detalles omitidos por seguridad)")
        return [("ERROR_SISTEMA", "SRC-0000")]
```
