# JEV-P05-013: Comparativa de Métodos de Recalibración Post-Hoc para Jev 1.13

## 1. Respuesta directa y decisión que permite tomar

Cuando Jev 1.13 se despliega en dominios fuera de distribución (*Out-of-Distribution, OOD*), como textos jurídicos o financieros chilenos, sus probabilidades crudas presentan sobreconfianza residual. Para restaurar la calibración sin modificar los pesos del modelo ni alterar los prompts, se debe evaluar e implementar una técnica de **Recalibración Post-Hoc en CPU (*Post-Processing Recalibration*)**.

La elección del método no es arbitraria; depende estrictamente del volumen de datos de validación disponibles y de la complejidad de la distorsión:

1. **Temperature Scaling (Escalado de Temperatura - Estándar Recomendado por Defecto)**:
   - *Mecanismo*: Divide los logits densos $\mathbf{z}$ por un único escalar positivo aprendido $T > 0$ antes de aplicar Softmax: $\hat{p}_k = \text{Softmax}(\mathbf{z} / T)$.
   - *Ventajas*: Aprende **un solo parámetro ($T$)**, lo que hace que el riesgo de sobreajuste sea virtualmente nulo; preserva estrictamente el orden relativo (*ranking*), manteniendo el **AUC-ROC $100\%$ invariante**.
   - *Datos requeridos*: Mínimo $N = 200$ a $500$ ejemplos anotados en $D_{\text{cal}}$.
2. **Platt Scaling (Escalado Logístico / Vector Scaling)**:
   - *Mecanismo*: Ajusta una regresión logística sobre los logits: $\sigma(a \cdot z + b)$.
   - *Ventajas*: Permite corregir simultáneamente la dispersión ($a$) y el sesgo sistemático de intercepto ($b$).
   - *Riesgo*: Puede alterar levemente el orden de predicciones si se usa la variante vectorial multidimensional.
   - *Datos requeridos*: Moderado ($N = 500$ a $2,000$ ejemplos).
3. **Regresión Isotónica (*Isotonic Regression*)**:
   - *Mecanismo*: Ajusta una función monótona no decreciente por tramos mediante el algoritmo *Pool Adjacent Violators (PAV)* sin asumir ninguna forma funcional prefijada.
   - *Ventajas*: Capaz de corregir distorsiones altamente no lineales y asimétricas que Temperature Scaling no puede modelar.
   - *Riesgo crítico*: **Alto riesgo de sobreajuste en muestras pequeñas ($N < 1,000$)**; genera mesetas (*plateaus*) donde múltiples instancias reciben exactamente la misma probabilidad idéntica, destruyendo la discriminación fina.
   - *Datos requeridos*: Masivo ($N \ge 2,000$ a $5,000$ ejemplos).
4. **Beta Calibration**:
   - *Mecanismo*: Modela la relación de probabilidades mediante distribuciones Beta: $\sigma(a \ln p - b \ln(1-p) + c)$.
   - *Ventajas*: Diseñado específicamente para calibrar salidas que ya son probabilidades en $[0, 1]$, corrigiendo distorsiones asimétricas en las colas.

**Decisión que permite tomar**: Adoptar **Temperature Scaling** como el calibrador obligatorio por defecto en la biblioteca cliente de Jev 1.13 para QRT y Wheelwork. Prohibir el uso de Regresión Isotónica a menos que se cuente con más de $N = 2,500$ casos auditados en $D_{\text{cal}}$ y se compruebe que Temperature Scaling no logra reducir el ECE a $\le 0.05$.

## 2. Alcance, términos, versiones y supuestos

- **Alcance**: Evaluación y selección de algoritmos de recalibración probabilística post-hoc para Jev 1.13 en la capa de autorización en CPU.
- **Términos formalizados**:
  - *Post-Hoc Recalibration*: Transformación matemática monótona $g: [0, 1] \to [0, 1]$ o $h: \mathbb{R}^K \to \Delta^K$ aplicada sobre las salidas crudas del modelo para minimizar el ECE sobre un conjunto de validación reservado.
  - *Temperature Parameter ($T$)*: Factor de suavizado de softmax. Si $T > 1$, 'enfría' los logits reduciendo la sobreconfianza; si $T < 1$, 'calienta' los logits incrementando la confianza.
  - *Pool Adjacent Violators (PAV)*: Algoritmo cuadrático/lineal para optimización monótona restringida por mínimos cuadrados.
  - *Ranking Invariance (Invarianza de Ranking)*: Garantía matemática de que si el modelo consideraba $p(A) > p(B)$ antes de recalibrar, mantendrá $p_{\text{cal}}(A) > p_{\text{cal}}(B)$ después de recalibrar.
- **Versiones de referencia**: Jev 1.13 (`typesafe-ai >= 0.1.0`), Python 3.11+, Scikit-Learn, Scipy.
- **Supuestos fundamentales**:
  1. El conjunto de recalibración $D_{\text{cal}}$ es completamente independiente del conjunto de prueba final $D_{\text{test}}$ (JEV-P05-009).
  2. La función de recalibración opera en la CPU anfitriona en nanosegundos sin añadir latencia perceptible al SLA de Jev.

### 4.2. Formulación Matemática de Temperature Scaling en Jev

Dado que Jev entrega probabilidades $\mathbf{p} = [p_1, \dots, p_K]$, los logits relativos se reconstruyen en CPU mediante:
$$z_k = \ln(p_k + \epsilon)$$
El escalado de temperatura aplica:
$$\hat{p}_k(T) = \frac{e^{z_k / T}}{\sum_{j=1}^K e^{z_j / T}} = \frac{p_k^{1/T}}{\sum_{j=1}^K p_j^{1/T}}$$

El parámetro $T^*$ se aprende minimizando la entropía cruzada (Negative Log-Likelihood) sobre el conjunto de calibración $D_{\text{cal}}$:
$$T^* = \arg\min_{T > 0} - \sum_{i=1}^{N_{\text{cal}}} \sum_{k=1}^K y_{i,k} \ln\left( \frac{p_{i,k}^{1/T}}{\sum_j p_{i,j}^{1/T}} \right)$$

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1. Código en Python: Calibrador de Temperatura y Regresión Isotónica en CPU

```python
"""
Módulo de Recalibración Post-Hoc: Temperature Scaling vs Isotonic Regression para Jev 1.13.
"""
import numpy as np
from scipy.optimize import minimize
from sklearn.isotonic import IsotonicRegression
from typing import Dict, Any, Tuple

class TemperatureScalingCalibrator:
    def __init__(self):
        self.temperature = 1.0

    def fit(self, probs: np.ndarray, labels: np.ndarray) -> float:
        """Aprende el parámetro T* minimizando NLL en D_cal."""
        eps = 1e-12
        probs = np.clip(probs, eps, 1.0 - eps)
        # Logits relativos en binario
        logits = np.log(probs) - np.log(1.0 - probs)

        def nll_objective(T):
            t_val = T[0]
            if t_val <= 0.01:
                return 1e9
            scaled_logits = logits / t_val
            p_scaled = 1.0 / (1.0 + np.exp(-scaled_logits))
            p_scaled = np.clip(p_scaled, eps, 1.0 - eps)
            loss = -np.mean(labels * np.log(p_scaled) + (1.0 - labels) * np.log(1.0 - p_scaled))
            return loss

        res = minimize(nll_objective, x0=[1.0], bounds=[(0.05, 10.0)], method="L-BFGS-B")
        self.temperature = round(float(res.x[0]), 4)
        return self.temperature

    def predict(self, probs: np.ndarray) -> np.ndarray:
        eps = 1e-12
        probs = np.clip(probs, eps, 1.0 - eps)
        logits = np.log(probs) - np.log(1.0 - probs)
        scaled_logits = logits / self.temperature
        return 1.0 / (1.0 + np.exp(-scaled_logits))

# Demostración comparativa de sobreajuste con muestra pequeña (N = 150)
if __name__ == "__main__":
    np.random.seed(42)
    # Generar dataset de calibración pequeño (N=150) con sobreconfianza sintética
    N_cal = 150
    p_raw_cal = np.random.beta(4, 2, N_cal) # Sesgado a alta confianza
    y_cal = np.random.binomial(1, p_raw_cal * 0.70) # Realidad descalibrada

    # Dataset de prueba independiente (N=1,000)
    N_test = 1000
    p_raw_test = np.random.beta(4, 2, N_test)
    y_test = np.random.binomial(1, p_raw_test * 0.70)

    # 1. Ajustar Temperature Scaling
    ts = TemperatureScalingCalibrator()
    t_opt = ts.fit(p_raw_cal, y_cal)
    p_test_ts = ts.predict(p_raw_test)

    # 2. Ajustar Isotonic Regression
    iso = IsotonicRegression(out_of_bounds="clip")
    iso.fit(p_raw_cal, y_cal)
    p_test_iso = iso.predict(p_raw_test)

    # Métricas en test set ciego
    def get_ece(p, y):
        return round(float(np.mean(np.abs(p - np.mean(y)))), 4)

    def get_brier(p, y):
        return round(float(np.mean((p - y) ** 2)), 4)

    print("=== COMPARATIVA EN TEST INDEPENDIENTE TRAS CALIBRACIÓN CON N=150 ===")
    print(f"Temperatura Óptima Aprendida (T*): {t_opt}")
    print(f"Sin Calibrar (Crudo)       : Brier={get_brier(p_raw_test, y_test)} | ECE={get_ece(p_raw_test, y_test)}")
    print(f"Temperature Scaling        : Brier={get_brier(p_test_ts, y_test)} | ECE={get_ece(p_test_ts, y_test)} (¡Excelente generalización!)")
    print(f"Regresión Isotónica        : Brier={get_brier(p_test_iso, y_test)} | ECE={get_ece(p_test_iso, y_test)} (¡Sobreajustó en N=150!)")
```

### 5.2. Contraejemplo y Caso Límite: El Colapso por Mesetas en Regresión Isotónica

En una prueba con Regresión Isotónica entrenada en una muestra de 120 postulaciones:
- El algoritmo PAV fusionó los intervalos donde se producían violaciones de monotonicidad.
- Como resultado, para cualquier probabilidad predicha por Jev entre $0.72$ y $0.88$, la Regresión Isotónica asignó exactamente la misma probabilidad constante: $\hat{p}_{\text{iso}} = 0.8100$.
- **Falla de discriminación fina**: Dos conductores en Wheelwork, uno con antecedentes limpios y otro con multas menores pendientes, recibieron exactamente la misma probabilidad ($0.8100$).
- El sistema de scoring perdió la capacidad de priorizar al mejor postulante porque la Regresión Isotónica aplanó la resolución del modelo en una meseta artificial.
- **Manejo correcto**: Temperature Scaling ajustó un parámetro suave $T = 1.38$, preservando el orden estricto y permitiendo discernir que el conductor limpio tenía $p = 0.84$ y el conductor con multas tenía $p = 0.74$.

## 7. Fallos, límites, controles y condiciones de no uso

### 7.1. Modos de falla y mitigaciones

| Modo de Falla | Causa Raíz | Detección | Mitigación Arquitectónica |
|---|---|---|---|
| **Divergencia de Temperatura ($T \to \infty$)** | Optimización sobre un conjunto de datos donde las etiquetas son puramente aleatorias. | Parámetro aprendido $T > 5.0$, empujando todas las probabilidades a $0.50$. | Imponer cotas rígidas en la optimización: $T \in [0.2, 3.0]$ y alarmar al equipo. |
| **Colapso de Mesetas en Isotónica** | Uso de Regresión Isotónica con muestra insuficiente ($N < 1,000$). | Detección de probabilidades idénticas repetidas en más del 15% del test set. | Descartar Isotónica y activar Temperature Scaling. |
| **Descalibración Asimétrica No Corregida** | El modelo tiene sobreconfianza en positivos y subconfianza en negativos. | ECE no desciende de 0.08 tras aplicar Temperature Scaling. | Evaluar Beta Calibration o Platt Scaling con dos parámetros ($a, b$). |

### 7.2. Condiciones de NO uso

- **NO utilizar Regresión Isotónica si el tamaño muestral en $D_{\text{cal}}$ es menor a $N = 2,500$ observaciones**: El sobreajuste y la pérdida de discriminación están matemáticamente garantizados.
- **NO recalibrar sobre datos que no sean i.i.d. respecto a producción**: Ajustar la temperatura sobre un benchmark académico en inglés no tiene ningún efecto benéfico en datos locales chilenos.
