# JEV-P14-006 — Priorización de Lecturas sin Descarte Sistemático de Ideas Novedosas

## 1. Respuesta directa y decisión que permite tomar

Un sistema de priorización de lecturas técnicas no debe optimizar únicamente para reforzar los intereses conocidos del usuario, ya que crearía una cámara de eco intelectual. Jev debe configurarse para evaluar dos dimensiones ortogonales mediante primitivas independientes: 1) Relevancia directa con proyectos activos (`Score` de 1 a 5); y 2) Grado de novedad conceptual o divergencia metodológica (`Choice` con opciones: `alineado`, `metodologia_novedosa`, `paradigma_opuesto`). Se reserva una cuota del 20% para lecturas divergentes.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Curaduría científica, mitigación de sesgos de confirmación y preservación de serendipia en investigación.
- **Supuesto clave**: Pruebas herméticas en corpus sintético previas a cualquier acceso a datos personales reales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia personal/operativa**: Metodología de investigación del Programa Jev: el avance conceptual exige confrontar literatura heterodoxa y evitar la especialización excesiva temprana.
- **Contraste de utilidad**: Se descarta la automatización de procesos de baja frecuencia o que impliquen sobrecarga de mantenimiento.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Algoritmo de Lista Balanceada: De cada 10 papers recomendados, 7 corresponden al Top de relevancia directa y 3 corresponden a artículos clasificados como `metodologia_novedosa` o `paradigma_opuesto` con alta certeza.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Choice, Score

logger = logging.getLogger("P14_06")

def evaluar_paper_dos_dimensiones(resumen_paper: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(
            state=resumen_paper,
            questions={
                "relevancia": Score(instructions="Alineacion con proyectos actuales", min_score=1, max_score=5),
                "novedad": Choice(instructions="Tipo de enfoque metodologico", options=["clasico_conocido", "novedoso", "disruptivo"])
            }
        )
        return {
            "score_relevancia": res.answers["relevancia"].score,
            "tipo_enfoque": res.answers["novedad"].choice
        }
    except Exception as err:
        logger.error(f"Fallo en clasificacion de paper: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"score_relevancia": 1, "tipo_enfoque": "clasico_conocido"}
```

- **Contraejemplo / Caso borde**: Filtrar lecturas basándose solo en palabras clave familiares descartará papers seminales que abordan el mismo problema con una terminología diferente.
