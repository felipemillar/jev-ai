# JEV-P15-007 — Deduplicación de Noticias Sindicadas y Preservación de la Fuente Original

## 1. Respuesta directa y decisión que permite tomar

En los mercados financieros, una misma noticia es republicada por docenas de medios y cables de prensa (Bloomberg, Reuters, Diario Financiero, El Mercurio) con ligeras variaciones de redacción a lo largo de varias horas. El sistema de QRT debe aplicar deduplicación semántica para agrupar todas las versiones bajo una sola entidad de suceso, pero preservando estrictamente la marca de tiempo del primer despacho y la procedencia de la fuente original para evitar señales de volumen artificiales.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Procesamiento de feeds de noticias sindicadas, deduplicación en tiempo real y preservación de procedencia.
- **Supuesto clave**: Entorno de investigación documental hermético y aislado del motor de trading algorítmico.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia cuantitativa**: Dinámicas de propagación de noticias en microestructura de mercado: tratar cables repetidos como eventos independientes genera sobreponderación indebida en modelos cuantitativos.
- **Contraste econométrico**: Se prohíbe deducir rentabilidad o predicción financiera a partir de exactitud de clasificación de texto.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Deduplicación temporal en ventana móvil de 6 horas: Si el texto comparte más del 80% de similitud semántica con una noticia registrada en las últimas 6 horas, se vincula como `noticia_derivada` sin alterar la hora del evento original.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import hashlib, logging

logger = logging.getLogger("P15_07")

class DeduplicadorNoticiasQRT:
    def __init__(self):
        self.catalogo_eventos = {}

    def registrar_cable(self, texto_cable: str, timestamp_recepcion: float, fuente: str) -> dict:
        try:
            # Hash semantico preliminar sobre entidades clave
            hash_suceso = hashlib.sha256(texto_cable[:200].encode("utf-8")).hexdigest()[:16]
            if hash_suceso in self.catalogo_eventos:
                evento_original = self.catalogo_eventos[hash_suceso]
                return {
                    "es_duplicado": True,
                    "primer_despacho_ts": evento_original["timestamp"],
                    "fuente_original": evento_original["fuente"],
                    "fuente_actual": fuente
                }
            self.catalogo_eventos[hash_suceso] = {"timestamp": timestamp_recepcion, "fuente": fuente}
            return {"es_duplicado": False, "primer_despacho_ts": timestamp_recepcion}
        except Exception as err:
            logger.error(f"Fallo en deduplicacion de cables: {type(err).__name__} (detalles omitidos por seguridad)")
            return {"es_duplicado": False}
```

- **Contraejemplo / Caso borde**: Multiplicar el tamaño de una posición financiera por cinco porque 5 periódicos distintos publicaron el mismo cable de una agencia de noticias.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Sobreponderación de noticias sindicadas | Distorsión de señales cuantitativas | Agrupación en ventana móvil de 6 horas | Conservar exclusivamente el timestamp del primer despacho |
| Look-ahead bias por fechas de reporte contable | Resultados de backtest sobreoptimizados | Filtro por publication_timestamp | Bloqueo estricto de eventos con timestamp futuro |
| Conexión accidental de módulos semánticos al broker | Ejecución errónea de órdenes de capital | Reglas de firewall de red (Air-Gap) | Prohibir APIs de FIX en servidores de inferencia |

## 8. Validación propuesta

- **Hipótesis Falsable**: La deduplicación de cables reduce el volumen de eventos redundantes en un 60% sin perder primicias.
- **Métricas**: Tasa de noticias redundantes filtradas con éxito.
- **Criterio de Rechazo**: Deduplicación >= 95% de cables repetidos.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
