# JEV-P10-008 — Medición de Calidad de Ranking con Relevancia Incompleta y Desacuerdo entre Evaluadores

## 1. Respuesta directa y decisión que permite tomar

La evaluación de la calidad del ranking producido por Jev debe medirse utilizando métricas robustas ante relevancia incompleta: Mean Reciprocal Rank (MRR), Normalized Discounted Cumulative Gain (nDCG@K) y Bpref (Binary Preference). En presencia de desacuerdo entre evaluadores humanos, debe computarse el coeficiente Kappa de Fleiss o Cohen ($\kappa$). Solo deben considerarse como ground truth los casos donde $\kappa \ge 0.70$; los documentos no juzgados deben tratarse bajo el supuesto de no-relevancia condicionada.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Metodología de benchmarking, fiabilidad inter-evaluador y métricas estadísticas de recuperación de información.
- **Supuesto clave**: Existencia de un motor de recuperación primaria de primera fase configurado y poblado.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Estándares de la conferencia TREC (Text REtrieval Conference) sobre evaluación de colecciones no exhaustivas de juicios de relevancia.
- **Contraste metodológico**: Se descartan arquitecturas que confunden búsqueda masiva no estructurada con inferencia semántica puntual.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Métrica Bpref: $Bpref = \frac{1}{R} \sum_{r \in R} \left(1 - \frac{\text{no-relevantes arriba de } r}{\min(R, N)}\right)$, donde $R$ es el conjunto de relevantes juzgados y $N$ los no relevantes juzgados. Bpref es insensible a documentos no evaluados.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P10_08")

def calcular_mrr(posiciones_primer_relevante: list) -> float:
    try:
        if not posiciones_primer_relevante:
            return 0.0
        reciprocal_ranks = [1.0 / pos for pos in posiciones_primer_relevante if pos > 0]
        return sum(reciprocal_ranks) / len(posiciones_primer_relevante)
    except Exception as err:
        logger.error(f"Fallo en calculo de MRR: {type(err).__name__} (detalles omitidos por seguridad)")
        return 0.0
```

- **Contraejemplo / Caso borde**: Evaluar un motor de búsqueda asumiendo que los documentos no leídos por los evaluadores son irrelevantes distorsiona la precisión si el corpus es de gran escala.
