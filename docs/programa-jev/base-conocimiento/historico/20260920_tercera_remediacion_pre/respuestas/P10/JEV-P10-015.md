# JEV-P10-015 — Recuperación Multilingüe y Manejo de Terminología Técnica y Sectorial Chilena

## 1. Respuesta directa y decisión que permite tomar

El pipeline de búsqueda no debe aplicar traducción automática simplista sobre términos técnicos o expresiones jurídicas y financieras chilenas (tales como 'finiquito', 'mutuo dinerario', 'sociedad por acciones', 'hecho esencial' o 'boleta de garantía'). La traducción al inglés destruye las sutilezas legales locales. Jev 1.13 debe alimentarse directamente con el texto original en español utilizando glosarios de correspondencia sectorial y embeddings entrenados en corpus multilingüe.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Procesamiento de lenguaje natural en dialectos y registros locales (NLP en español de Chile) y preservación semántica.
- **Supuesto clave**: Existencia de un motor de recuperación primaria de primera fase configurado y poblado.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Resultados del Pilar P07: Jev conserva alta capacidad semántica en español cuando los términos jurídicos y financieros se mantienen en su registro original sin perturbar la morfología.
- **Contraste metodológico**: Se descartan arquitecturas que confunden búsqueda masiva no estructurada con inferencia semántica puntual.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Glosario sectorial en CPU: Reemplazo o enriquecimiento contextual previo a la llamada: asociar el término chileno con su definición normativa precisa en el encabezado del `state` para desambiguar la evaluación.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("P10_15")

def evaluar_termino_sectorial_chileno(texto_laboral: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        prompt = f"CONTEXTO LABORAL CHILENO:\n{texto_laboral}"
        res = client.system_one(
            state=prompt,
            questions={
                "causal": Choice(
                    instructions="Identificar causal de termino de contrato segun Codigo del Trabajo",
                    options=["necesidades_de_la_empresa", "renuncia_voluntaria", "mutuo_acuerdo", "otra"]
                )
            }
        )
        return {"causal_identificada": res.answers["causal"].choice}
    except Exception as err:
        logger.error(f"Fallo en analisis sectorial: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"causal_identificada": "error"}
```

- **Contraejemplo / Caso borde**: Traducir 'finiquito ratificado ante ministro de fe' como 'cleared settlement before faith minister' induce a cualquier modelo a interpretar un contexto religioso inexistente.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Traducción destructiva de términos locales | Interpretación errónea de normativas legales | Procesamiento en español original nativo | Prohibir traducción previa de textos legales |
| Sobrecarga de pasajes en state (>32 KB) | Error 400 en runtime de API | Validación preventiva de bytes | Truncar o fragmentar pasajes a <= 400 palabras |
| Desalineación semántica en consultas OOD | Falsos positivos en clasificación | Monitoreo de entropía y certeza | Compuerta de abstención automática |

## 8. Validación propuesta

- **Hipótesis Falsable**: El procesamiento nativo en español supera a pipelines con traducción previa en más de 25 puntos de exactitud en derecho laboral.
- **Métricas**: Exactitud en clasificación de figuras jurídicas chilenas.
- **Criterio de Rechazo**: Exactitud >= 92% en español frente a < 70% con traducción.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
