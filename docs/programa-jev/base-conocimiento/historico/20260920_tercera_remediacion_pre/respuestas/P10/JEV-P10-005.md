# JEV-P10-005 — Verificación de Citas Genuinas vs Superposición Léxica Superficial

## 1. Respuesta directa y decisión que permite tomar

Una cita documental solo es válida si existe una relación formal de soporte lógico (entailment) entre la evidencia citada y la afirmación realizada. La mera coincidencia de términos, nombres propios o palabras clave no constituye soporte epistémico. Jev debe configurarse mediante primitivas `Choice` con opciones mutuamente excluyentes (`sustenta`, `contradice`, `neutral`) o primitivas `Noul` calibradas para detectar contradicciones sutiles o afirmaciones descontextualizadas.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Auditoría de trazabilidad documental, detección de citas falsas y aseguramiento de fidelidad textual.
- **Supuesto clave**: Existencia de un motor de recuperación primaria de primera fase configurado y poblado.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Auditoría externa de Codex: se detectaron afirmaciones que citaban fuentes de NotebookLM basándose en coincidencias léxicas que no respaldaban la conclusión técnica emitida.
- **Contraste metodológico**: Se descartan arquitecturas que confunden búsqueda masiva no estructurada con inferencia semántica puntual.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Prueba de entailment en lenguaje natural (NLI): La afirmación se evalúa como hipótesis ($H$) y el pasaje como premisa ($P$). El modelo determina si $P \implies H$ con probabilidad $p \ge 0.85$.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("P10_05")

def verificar_soporte_cita(premisa_pasaje: str, hipotesis_afirmacion: str) -> bool:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        prompt = f"PREMISA: {premisa_pasaje}\nHIPOTESIS: {hipotesis_afirmacion}"
        res = client.system_one(
            state=prompt,
            questions={
                "relacion": Choice(
                    instructions="Determinar si la premisa sustenta rigurosamente la hipotesis",
                    options=["sustenta_plenamente", "contradice", "falta_evidencia"]
                )
            }
        )
        ans = res.answers["relacion"]
        return ans.choice == "sustenta_plenamente" and ans.confidence >= 0.85
    except Exception as err:
        logger.error(f"Fallo en verificacion de cita: {type(err).__name__} (detalles omitidos por seguridad)")
        return False
```

- **Contraejemplo / Caso borde**: Citar una regulación que dice 'se prohíbe el uso de derivados no registrados' como justificación de que 'los derivados están autorizados' porque ambas frases contienen las mismas palabras clave.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Cita espuria por coincidencia de palabras | Invalidación en auditoría externa | NLI estricto con Choice cerrado | Exigir confianza >= 0.85 en sustenta_plenamente |
| Sobrecarga de pasajes en state (>32 KB) | Error 400 en runtime de API | Validación preventiva de bytes | Truncar o fragmentar pasajes a <= 400 palabras |
| Desalineación semántica en consultas OOD | Falsos positivos en clasificación | Monitoreo de entropía y certeza | Compuerta de abstención automática |

- **Criterio de Rechazo**: Precisión de sustento >= 98% en muestra auditada de 200 casos.
