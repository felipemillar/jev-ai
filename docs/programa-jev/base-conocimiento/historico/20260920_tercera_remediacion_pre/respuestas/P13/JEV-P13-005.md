# JEV-P13-005 — Punto de Equilibrio (Break-Even): Volumen Crítico frente a Servidores Locales y Personal

## 1. Respuesta directa y decisión que permite tomar

El punto de equilibrio económico entre consumir Jev vía SaaS y alojar un modelo local open-source (e.g. DeBERTa-v3 en AWS EC2 `g4dn.xlarge` con GPU NVIDIA T4 a ~$400 USD/mes todo incluido) se sitúa en aproximadamente 4.5 millones de llamadas mensuales (asumiendo textos promedio de 2.000 tokens). Por debajo de 4.5M llamadas al mes, Jev SaaS es indefectiblemente más económico ya que traslada el costo de hardware ocioso, mantenimiento SRE y disponibilidad al proveedor.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Análisis de punto de equilibrio, decisiones Make-or-Buy y economía de servidores dedicados.
- **Supuesto clave**: Evaluación financiera a precios plenos documentados ($0.042/Mtok) sin subsidios temporales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia económica**: Costos de instancias cloud reservadas (AWS/GCP) y comparación con precios por token de TypeSafe.
- **Contraste de modelos**: Se comparan escenarios de SaaS gestionado frente a auto-hosting de GPU y LLMs frontier generativos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Ecuación de Break-Even: $\text{Volumen}_{\text{BE}} = \frac{\text{Costo Fijo Mensual Servidor (\$400)}}{\text{Costo Marginal por Llamada Jev (\$0.000084)}} \approx 4.761.904 \text{ llamadas}$. Si el tráfico es menor, el servidor local gasta capital en tiempo ocioso.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_05")

def calcular_volumen_break_even(costo_fijo_servidor_usd: float = 400.0, costo_por_llamada_saas: float = 0.000084) -> int:
    try:
        if costo_por_llamada_saas <= 0:
            return 0
        return int(costo_fijo_servidor_usd / costo_por_llamada_saas)
    except Exception as err:
        logger.error(f"Fallo en calculo break-even: {type(err).__name__} (detalles omitidos por seguridad)")
        return 0
```
