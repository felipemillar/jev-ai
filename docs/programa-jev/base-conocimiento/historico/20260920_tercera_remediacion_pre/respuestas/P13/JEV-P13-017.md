# JEV-P13-017 — Presupuesto de Evaluación Previa y Reducción de Incertidumbre Tecnológica

## 1. Respuesta directa y decisión que permite tomar

Antes de comprometer meses de desarrollo en una integración profunda con Jev, los proyectos deben asignar un presupuesto de evaluación previa (PoC Budget) acotado a un máximo de $500 USD de consumo de API y 40 horas de ingeniería. Este presupuesto se destina exclusivamente a ejecutar benchmarks rigurosos sobre datos reales, medir la tasa de exactitud, comprobar la latencia y determinar la tasa de abstención efectiva, reduciendo la incertidumbre tecnológica antes de inversiones mayores.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Gestión de la innovación, mitigación de riesgos de I+D y economía de pruebas de concepto (PoC).
- **Supuesto clave**: Evaluación financiera a precios plenos documentados ($0.042/Mtok) sin subsidios temporales.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia económica**: Metodología Lean Startup y prácticas de ingeniería ágil para la validación temprana de hipótesis críticas.
- **Contraste de modelos**: Se comparan escenarios de SaaS gestionado frente a auto-hosting de GPU y LLMs frontier generativos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Compromiso de evaluación en 3 etapas: Etapa 1 (Benchmark sintético local, costo $0); Etapa 2 (Prueba de API con 5.000 consultas representativas, costo ~$1 USD); Etapa 3 (Análisis de resultados y decisión de avance/cancelación).

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P13_17")

def control_gasto_poc(gasto_acumulado: float, limite_poc_usd: float = 500.0) -> dict:
    try:
        presupuesto_restante = limite_poc_usd - gasto_acumulado
        alcanzo_limite = gasto_acumulado >= limite_poc_usd
        if alcanzo_limite:
            logger.critical("LIMITE DE PRESUPUESTO DE EVALUACION ALCANZADO: Congelar llamadas")
        return {
            "gasto_actual": round(gasto_acumulado, 2),
            "restante": round(max(0.0, presupuesto_restante), 2),
            "puede_continuar": not alcanzo_limite
        }
    except Exception as err:
        logger.error(f"Fallo en control de gasto PoC: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"puede_continuar": False}
```

## 8. Validación propuesta

- **Hipótesis Falsable**: La fase de evaluación acotada descarta el 80% de las iniciativas inviables con menos del 5% del presupuesto total.
- **Métricas**: Costo medio de proyectos descartados tempranamente.
- **Criterio de Rechazo**: Gasto en iniciativas descartadas < $500 USD.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
