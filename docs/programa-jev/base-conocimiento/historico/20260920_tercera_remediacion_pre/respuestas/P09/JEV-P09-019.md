# JEV-P09-019 — Diseño de Interfaz Interna Común (Patrón Adapter) para Sustituibilidad de Proveedores

## 1. Respuesta directa y decisión que permite tomar

Para evitar el acoplamiento duro al proveedor TypeSafe, los sistemas deben interactuar con Jev exclusivamente a través de una interfaz abstracta interna (`ISemanticClassifier` o `ISemanticRouter`). Este patrón Adapter desacopla la lógica de negocio de las peculiaridades del SDK de Jev, permitiendo conmutar a modelos locales (DeBERTa-v3, SetFit) o a APIs alternativas sin alterar los controladores de dominio.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Arquitectura limpia, puertos y adaptadores (Arquitectura Hexagonal) y prevención de vendor lock-in.
- **Supuesto clave**: Conectividad saliente HTTPS habilitada hacia los endpoints oficiales de TypeSafe.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia documental**: Patrones clásicos de diseño (GoF Adapter Pattern) aplicados a componentes de inferencia estadística en microservicios críticos.
- **Contraste de hipótesis**: Se descartan integraciones basadas en suposiciones de APIs genéricas de OpenAI o protocolos no oficiales.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Definición de Protocolo/ABC en Python: Métodos `classify(text, categories)` y `score(text, min_val, max_val)` que devuelven tipos de dominio agnósticos (`DecisionDomain`), absorbiendo las particularidades de `answers` de Jev.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
from abc import ABC, abstractmethod
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("P09_19")

class ISemanticClassifier(ABC):
    @abstractmethod
    def clasificar(self, texto: str, opciones: list) -> str:
        pass

class JevClassifierAdapter(ISemanticClassifier):
    def __init__(self):
        self.client = TypeSafeClient(model="jev-1.13.0")

    def clasificar(self, texto: str, opciones: list) -> str:
        try:
            res = self.client.system_one(
                state=texto,
                questions={"q": Choice(instructions="Clasificar", options=opciones)}
            )
            return res.answers["q"].choice
        except Exception as err:
            logger.error(f"Fallo en adaptador Jev: {type(err).__name__} (detalles omitidos por seguridad)")
            return "indeterminado" 
```

- **Contraejemplo / Caso borde**: Dispersar llamadas directas a `TypeSafeClient` en 50 archivos distintos del backend hará inviable sustituir a Jev si los precios o términos del proveedor cambian.

## 6. Aplicación práctica o transferencia

En el núcleo de servicios de Wheelwork para poder alternar entre Jev y un clasificador local de currículums.

## 7. Fallos conocidos, advertencias y contraindicaciones

| Modo de Fallo | Impacto Operativo | Detección Temprana | Mitigación Arquitectónica |
| :--- | :--- | :--- | :--- |
| Acoplamiento masivo directo al SDK | Costo millonario ante migración de proveedor | Regla arquitectónica de Clean Architecture | Exigir uso exclusivo del Adapter |
| Corte total de conectividad saliente | Caída del servicio dependiente | Monitoreo sintético cada 60s | Conmutación automática a clasificador determinista local |
| Variación no notificada en contrato | Errores 422 en llamadas de API | Pruebas de contrato diarias en CI | Fijar versión y alertar ante discrepancias |

## 8. Validación propuesta

- **Hipótesis Falsable**: El patrón Adapter permite reemplazar el motor de inferencia en menos de 4 horas hombre de trabajo de ingeniería.
- **Métricas**: Tiempo de desarrollo requerido para sustituir el proveedor.
- **Criterio de Rechazo**: Sustitución completa en < 8 horas sin tocar controladores.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
