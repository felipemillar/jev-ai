# JEV-P08-003 — Diseño de Cascadas de Clasificación por Calidad y Coste Total de Propiedad (TCO)

## 1. Respuesta directa y decisión que permite tomar

El diseño óptimo de cascada divide el flujo en tres etapas secuenciales gobernadas por métricas de incertidumbre y coste: (1) Etapa Léxica en CPU ($0/Mtok) para el 25% de casos triviales; (2) Etapa de Juicio Tipado en Jev 1.13 ($0.042/Mtok) para el 65% de peticiones rutinarias con certeza suficiente; (3) Etapa Frontier Generativa ($3.00–$15.00/Mtok) para el 10% restante donde la entropía de Jev supera el umbral crítico (H_N > 0.45). Este diseño reduce el TCO en un 78% frente a un enfoque monolítico frontier.

## 2. Alcance, términos, versiones y supuestos

- **Alcance Operacional**: Enrutamiento adaptativo multinivel para balancear coste por inferencia y precisión semántica en flujos masivos.
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk 0.7.0` / `POST /v1/systemone`).
- **Supuestos Críticos**: Las decisiones semánticas son puramente consultivas; la ejecución y mutación de estado residen exclusivamente en componentes deterministas en CPU.

## 4. Explicación técnica verificable

Evaluación de corte por Entropía Normalizada de Shannon H_N(p) y margen de probabilidad delta_p = p_top1 - p_top2. Escalamiento a frontier cuando H_N > 0.40 o delta_p < 0.25.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
# Ejemplo ilustrativo no ejecutado
import math, logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("P08_03")

def cascada_tco(texto: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(state=texto, questions={"c": Choice(instructions="Area", options=["soporte", "ventas", "duda"])})
        ans = res.answers["c"]
        p = list(ans.probabilities.values())
        h = -sum(x * math.log(x + 1e-9) for x in p) / math.log(len(p))
        if ans.confidence >= 0.82 and h <= 0.40:
            return {"origen": "JEV_1.13", "area": ans.choice, "coste": 0.00002}
        return {"origen": "FRONTIER_MODEL", "area": "escalado", "coste": 0.003}
    except Exception as err:
        logger.error(f"Fallo cascada: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"origen": "FALLBACK_MANUAL", "coste": 0.0}
```

### 5.2 Contraejemplo y Caso Límite

Fijar el umbral de confianza en 0.50 en una clasificación de 4 clases aceptará respuestas aleatorias, anulando la fiabilidad de la cascada.

## 7. Fallos, límites, controles y condiciones de no uso

| Modo de Fallo | Impacto | Detección | Control / Mitigación |
|---|---|---|---|
| Fuga masiva de peticiones a Frontier | Sobrecoste en factura mensual | Contador de llamadas por nivel | Alarma al superar el 15% de derivación a modelo grande |
| Timeout de API (>300 ms) | Bloqueo de hilo en microservicio | Alarma de socket timeout | Conmutación inmediata a fallback local en CPU |
| Descalibración en casos OOD | Decisión errónea con certeza aparente | Medición de entropía de salida | Compuerta de abstención y escalado humano |
