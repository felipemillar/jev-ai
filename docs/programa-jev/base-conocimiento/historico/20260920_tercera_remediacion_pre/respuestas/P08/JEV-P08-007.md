# JEV-P08-007 — Resolución de Contradicciones entre Jev, Verificadores y Reglas de Negocio

## 1. Respuesta directa y decisión que permite tomar

Ante una discrepancia entre la inferencia de Jev y un verificador o regla de negocio, está estrictamente prohibido arbitrar eligiendo la salida con mayor confianza numérica. La resolución canónica aplica una jerarquía ontológica: (1) Las reglas de negocio deterministas tienen veto absoluto sobre transacciones prohibidas; (2) Los verificadores formales (regex, checksums, bases de datos) prevalecen sobre juicios de lenguaje natural; (3) Si Jev contradice una regla suave pero aporta alta certeza, el caso se etiqueta como anomalía y se enruta a arbitraje humano.

## 2. Alcance, términos, versiones y supuestos

- **Alcance Operacional**: Políticas de arbitraje no estocásticas ante colisión de veredictos entre componentes de software.
- **Versión de Referencia**: Jev 1.13 (`typesafe_sdk 0.7.0` / `POST /v1/systemone`).
- **Supuestos Críticos**: Las decisiones semánticas son puramente consultivas; la ejecución y mutación de estado residen exclusivamente en componentes deterministas en CPU.

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1 Implementación en Python (SDK 0.7.0)

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Noul

logger = logging.getLogger("P08_07")

def arbitrar_conflicto(texto: str, pasa_regla_dura: bool) -> str:
    try:
        if not pasa_regla_dura:
            return "RECHAZO_POR_VETO_DETERMINISTA"
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(state=texto, questions={"v": Noul(statement="¿Cumple politica de calidad?")})
        p = res.answers["v"].noul
        if p >= 0.85:
            return "APROBADO_CONSENSO"
        return "ESCALADO_A_HUMANO"
    except Exception as err:
        logger.error(f"Fallo arbitraje: {type(err).__name__} (detalles omitidos por seguridad)")
        return "ERROR_ABSTENCION" 
```

### 5.2 Contraejemplo y Caso Límite

Un clasificador otorga 0.99 de confianza a que un documento es válido, pero el archivo carece de firma electrónica avanzada. Aceptar el documento vulneraría la ley de firma electrónica.
