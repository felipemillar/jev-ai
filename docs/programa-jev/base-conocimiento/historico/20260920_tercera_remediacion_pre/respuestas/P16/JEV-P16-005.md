# JEV-P16-005 — Auditoría de Equidad Algorítmica y Cumplimiento de la Ley 19.628 y el AI Act

## 1. Respuesta directa y decisión que permite tomar

El uso de Jev en selección de talento debe cumplir estrictamente con el principio de no discriminación consagrado en el Art. 2 del Código del Trabajo chileno, la Ley 19.628 de Protección de Datos Personales y las directrices de alto riesgo del AI Act europeo. Se prohíbe de forma absoluta evaluar o procesar variables protegidas: género, edad, estado civil, orientación sexual, religión, afiliación sindical, etnia o comuna de residencia de los candidatos.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Compliance laboral chileno, ética algorítmica y prevención de discriminación laboral.
- **Supuesto clave**: Pruebas sobre perfiles sintéticos y cumplimiento estricto del Código del Trabajo chileno y Ley 19.628.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia laboral/B2B**: Dictámenes de la Dirección del Trabajo (Ord. N° 3704/134 sobre discriminación en procesos de selección) y directrices de IA de alto riesgo en empleo (AI Act Annex III).
- **Contraste ético-jurídico**: Se prohíben descartes automáticos no supervisados y el tratamiento de atributos sensibles protegidos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Sanitización determinista de variables protegidas: Antes de enviar el perfil a Jev, un script en CPU elimina nombres, fotografías, fechas de nacimiento, direcciones residenciales y nombres de instituciones educativas que actúan como variables proxy socioeconómicas.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import re, logging

logger = logging.getLogger("P16_05")

def anonimizar_perfil_laboral(cv_texto_crudo: str) -> str:
    try:
        # Eliminar edad, fechas de nacimiento y genero
        texto_limpio = re.sub(r"\b\d{1,2}\s*(?:años|anos)\b", "[EDAD_OMITIDA]", cv_texto_crudo, flags=re.IGNORECASE)
        texto_limpio = re.sub(r"\b(?:femenino|masculino|soltero|casado|divorciado)\b", "[ESTADO_OMITIDO]", texto_limpio, flags=re.IGNORECASE)
        texto_limpio = re.sub(r"\b(?:comuna|domicilio|residencia)\s*:\s*[^\n]+", "[DIRECCION_OMITIDA]", texto_limpio, flags=re.IGNORECASE)
        return texto_limpio
    except Exception as err:
        logger.error(f"Fallo en anonimizacion laboral: {type(err).__name__} (detalles omitidos por seguridad)")
        return "" 
```
