# JEV-P16-019 — Métricas Integrales de Evaluación de Pilotos: Tiempo, Calidad, Equidad y Retrabajo

## 1. Respuesta directa y decisión que permite tomar

El éxito de los pilotos WW-01 y WW-02 debe medirse mediante un cuadro de mando integral balanceado (Balanced Scorecard) que evite premiar únicamente la velocidad o el volumen de procesamiento. Las cuatro dimensiones obligatorias son: 1) Eficiencia temporal (reducción neta de horas de triaje manual); 2) Calidad de selección (tasa de candidatos propuestos que superan la entrevista técnica); 3) Equidad algorítmica (paridad de impacto adverso AIR >= 0.85); y 4) Tasa de retrabajo (porcentaje de correcciones manuales requeridas).

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Balanced Scorecard en talento humano, evaluación multidimensional de IA y control de retrabajo.
- **Supuesto clave**: Pruebas sobre perfiles sintéticos y cumplimiento estricto del Código del Trabajo chileno y Ley 19.628.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia laboral/B2B**: Marco de evaluación del Programa Jev para la certificación de pilotos corporativos en `pilotos.md`.
- **Contraste ético-jurídico**: Se prohíben descartes automáticos no supervisados y el tratamiento de atributos sensibles protegidos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Dashboard balanceado en Grafana: Fórmulas consolidadas en tiempo real. Si la tasa de retrabajo supera el 15% o si el AIR cae bajo 0.80, el dashboard emite una alerta roja y congela el avance del piloto.

# Ejemplo ilustrativo no ejecutado
import logging

logger = logging.getLogger("P16_19")

def auditar_cuadro_mando_piloto_ww(ahorro_horas: float, tasa_aprobacion_entrevista: float, air_equidad: float, tasa_retrabajo_pct: float) -> dict:
    try:
        es_exitoso = (
            ahorro_horas >= 20.0 and 
            tasa_aprobacion_entrevista >= 0.70 and 
            air_equidad >= 0.85 and 
            tasa_retrabajo_pct <= 15.0
        )
        return {
            "piloto_aprobado": es_exitoso,
            "dimensiones": {
                "ahorro_horas": ahorro_horas,
                "calidad_entrevista": tasa_aprobacion_entrevista,
                "equidad_air": air_equidad,
                "retrabajo": tasa_retrabajo_pct
            }
        }
    except Exception as err:
        logger.error(f"Fallo en cuadro de mando: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"piloto_aprobado": False}
