# JEV-P16-014 — Clasificación de Feedback Cualitativo: Hechos Relatados vs Opiniones Subjetivas

## 1. Respuesta directa y decisión que permite tomar

En auditorías de clima organizacional y reportes de la Ley Karin (prevención del acoso laboral y sexual en Chile), Jev debe clasificar el texto de encuestas y denuncias cualitativas diferenciando con rigor epistemológico entre: 1) Hechos concretos relatados (con fecha, lugar o acciones observables); 2) Opiniones o juicios de valor subjetivos ('el jefe me cae mal'); y 3) Reclamaciones sin sustento fáctico. Esta segregación protege la debida diligencia de los comités de investigación.

## 2. Alcance, términos y supuestos

- **Ámbito analizado**: Compliance con la Ley Karin (Ley 21.643 de Chile), investigación de acoso laboral y análisis de clima.
- **Supuesto clave**: Pruebas sobre perfiles sintéticos y cumplimiento estricto del Código del Trabajo chileno y Ley 19.628.
- **Términos**: La versión de referencia es `typesafe_sdk 0.7.0` y el modelo `jev-1.13.0`.

## 3. Evidencia y contraste

- **Evidencia laboral/B2B**: Directrices de la Dirección del Trabajo y Superintendencia de Seguridad Social (SUSESO) para la aplicación de la Ley Karin.
- **Contraste ético-jurídico**: Se prohíben descartes automáticos no supervisados y el tratamiento de atributos sensibles protegidos.
- **Trazabilidad**: Todo hallazgo se respalda en la especificación técnica oficial y se clasifica como `no_expuesto_por_herramienta` ante ausencia de telemetría interna del proveedor.

## 4. Explicación técnica

Clasificador formal de feedback: Evaluar mediante `Choice(options=['hecho_concreto_verificable', 'percepcion_subjetiva', 'lenguaje_ofensivo_descalificatorio'])`. Los hechos concretos se derivan a la secretaría del comité de investigación de acoso.

## 5. Ejemplo ilustrativo, verificación o contraejemplo

```python
# Ejemplo ilustrativo no ejecutado
import logging
from typesafe_sdk import TypeSafeClient, Choice

logger = logging.getLogger("P16_14")

def clasificar_denuncia_ley_karin(texto_denuncia: str) -> dict:
    try:
        client = TypeSafeClient(model="jev-1.13.0")
        res = client.system_one(
            state=texto_denuncia,
            questions={
                "naturaleza_declaracion": Choice(
                    instructions="Diferenciar hechos con circunstancias de opiniones subjetivas",
                    options=["hecho_concreto_circunstanciado", "opinion_subjetiva_general", "conflicto_interpersonal_menor"]
                )
            }
        )
        return {"clasificacion": res.answers["naturaleza_declaracion"].choice}
    except Exception as err:
        logger.error(f"Fallo en clasificador de feedback: {type(err).__name__} (detalles omitidos por seguridad)")
        return {"clasificacion": "hecho_concreto_circunstanciado"}
```

- **Contraejemplo / Caso borde**: Desestimar una denuncia grave de acoso laboral porque el trabajador usó palabras coloquiales en lugar de términos jurídicos formales.

## 8. Validación propuesta

- **Hipótesis Falsable**: La segregación entre hechos y opiniones acelera la admisibilidad de denuncias en un 60%.
- **Métricas**: Tiempo de respuesta en triaje de denuncias conforme a Ley Karin.
- **Criterio de Rechazo**: Triaje preliminar en < 24 horas hábiles tras la recepción.
- **Estado**: Protocolo de validación propuesto para banco de pruebas local.
