# JEV-P07-004: Fenómenos del Español Chileno que Alteran Clasificaciones Semánticas

## 1. Respuesta directa y decisión que permite tomar

El español de Chile presenta peculiaridades morfopragmáticas y léxicas que colapsan sistemáticamente las clasificaciones semánticas automáticas cuando se procesan mediante traducciones literales o modelos lingüísticos que carecen de sintonización dialectal. Fenómenos como locuciones adverbiales de urgencia (*"al tiro"*), metáforas de liquidez financiera (*"estar pato"*, *"lucas"*), eufemismos atenuantes (*"un temita"*, *"dar la lata"*), indicadores de conflicto operacional (*"tener atados"*, *"irse a las pailas"*) e ironía sarcástica con léxico invertido (*"una joyita"*) alteran radicalmente la polaridad, la severidad y la intención de los mensajes.

Una traducción literal convierte estas expresiones en secuencias absurdas o desprovistas de significado transaccional (ej. *"estar pato"* traducido como *"to be a duck"* o *"irse a las pailas"* como *"to go to the pans"*), induciendo a clasificadores como Jev a emitir falsos positivos de satisfacción o falsos negativos de alerta crítica. Para Wheelwork y QRT, la mitigación obligatoria consiste en implementar una **capa de canonización dialectal determinista** en el preprocesamiento que mapee estas expresiones a conceptos unívocos antes de la evaluación de Sistema 1.

## 4. Explicación técnica verificable

### 2.1 Ruptura Semántico-Pragmática en la Transferencia Literal

En lingüística computacional, un modismo o modismo regional constituye una **unidad fraseológica no composicional**: el significado global de la expresión no equivale a la suma de los significados de sus palabras constituyentes:
$$\text{Semántica}\left(\bigcup_{i=1}^n w_i\right) \neq \sum_{i=1}^n \text{Semántica}(w_i)$$

Cuando un motor de traducción automática (NMT) o un tokenizador anglocéntrico procesa estas unidades sin contar con pares dialectales alineados (fenómeno ampliamente documentado en *FLORES-200* y *Belebele*), ocurre una **ruptura pragmática**:
1. **Pérdida de Polaridad:** Expresiones de queja severa con palabras positivas superficiales se clasifican como elogios.
2. **Colapso de Urgencia:** Marcadores temporales inmediatos se diluyen o se omiten en la traducción.
3. **Invisibilización de Fricción Financiera:** El vocabulario monetario y de solvencia informal queda clasificado como ruido o contenido zoológico/gastronómico.

```
Mecanismo de Error por Traducción Literal de Chilenismos
─────────────────────────────────────────────────────────────────────────────
Texto Fuente:       "El bot de trading se fue a las pailas al tiro."
Traducción Literal: "The trading bot went to the frying pans at the shot."
                               │
                               ▼
Jev Inference:      Pregunta: "Did the system crash?"
                    Resultado: False (Confianza 0.89)  <── ¡Fallo Crítico Silencioso!
```

## 5. Ejemplo sintético trabajado y contraejemplo o caso límite

### 5.1. Implementación de Referencia en Python

El siguiente módulo implementa el transformador determinista de expresiones dialectales chilenas (*Chilean Dialect Canonicalizer*), que sanitiza el texto antes de generar el estado para Jev.

```python
# Ejemplo ilustrativo no ejecutado
"""
Módulo de Canonización Dialectal Chilena para Jev AI.
Normaliza modismos y locuciones no composicionales preservando el sentido semántico.
"""

from dataclasses import dataclass
from typing import Dict, Any, Tuple, Pattern
import re
import logging

logger = logging.getLogger("ChileanDialectNormalizer")


@dataclass(frozen=True)
class CanonicalizationResult:
    original_text: str
    canonical_text: str
    detected_idioms: Dict[str, str]
    urgency_boost: bool
    risk_boost: bool


class ChileanDialectNormalizer:
    """
    Normalizador determinista de expresiones idiomáticas chilenas críticas para decisiones de negocio.
    """

    def __init__(self):
        # Mapeo de modismos a descriptores semánticos formales
        self.idiom_patterns = [
            (re.compile(r"\bal tiro\b", re.IGNORECASE), "inmediatamente de forma urgente", "urgency"),
            (re.compile(r"\b(andar|estar)\s+pato\b", re.IGNORECASE), "sin liquidez financiera ni fondos", "risk"),
            (re.compile(r"\b(irse|se fue)\s+a las pailas\b", re.IGNORECASE), "sufrió una caída catastrófica total", "risk"),
            (re.compile(r"\bcaleta de atados\b", re.IGNORECASE), "múltiples problemas técnicos graves", "risk"),
            (re.compile(r"\btener atados\b", re.IGNORECASE), "tener conflictos y dificultades", "risk"),
            (re.compile(r"\buna joyita\b", re.IGNORECASE), "un servicio sumamente deficiente y deficiente", "risk"),
            (re.compile(r"\bdar la lata\b", re.IGNORECASE), "insistir por falta de solución oportuna", "neutral"),
            (re.compile(r"\bno me pescan\b", re.IGNORECASE), "no atienden mis instrucciones requeridas", "risk"),
            (re.compile(r"\b(\d+)\s*lucas\b", re.IGNORECASE), r"\1 mil pesos chilenos", "currency"),
            (re.compile(r"\bun temita\b", re.IGNORECASE), "un asunto delicado de alto impacto", "risk"),
        ]

    def normalize(self, text: str) -> CanonicalizationResult:
        try:
            canonical = text
            detected = {}
            urgency = False
            risk = False

            for pattern, replacement, category in self.idiom_patterns:
                match = pattern.search(canonical)
                if match:
                    matched_str = match.group(0)
                    detected[matched_str] = replacement
                    canonical = pattern.sub(replacement, canonical)

                    if category == "urgency":
                        urgency = True
                    elif category == "risk":
                        risk = True

            return CanonicalizationResult(
                original_text=text,
                canonical_text=canonical,
                detected_idioms=detected,
                urgency_boost=urgency,
                risk_boost=risk
            )

        except Exception as err:
            logger.error(f"Error canonizando texto chileno: {type(err).__name__} (detalles omitidos por seguridad)")
            # En caso de excepción, retornar el texto original sin alterar para no abortar el flujo
            return CanonicalizationResult(
                original_text=text,
                canonical_text=text,
                detected_idioms={},
                urgency_boost=False,
                risk_boost=False
            )
```

### 4.2 QRT: Alerta Temprana en Canales de Traders Locales

## 7. Fallos, límites, controles y condiciones de no uso

### 7.1. Modos de Falla y Controles de Mitigación
1. **Descalibración por modismos chilenos no composicionales**: Activación de umbrales dinámicos y compuerta de abstención ante entropía alta.
2. **Fragmentación sub-léxica en tokenización**: Preprocesamiento determinista de acrónimos territoriales y siglas institucionales (CMF, SII, DTE, UF) en memoria en CPU.
3. **Falsos positivos por sarcasmo o ironía**: Desacoplamiento de juicios de satisfacción mediante preguntas fácticas concurrentes en primitivas `Noul`.

### 7.2. Gobernanza, Privacidad y Condiciones de No Uso
1. **Determinismo y Explicabilidad Regulatoria:**
   - La sustitución de modismos mediante reglas deterministas documentadas asegura que la transformación del texto sea 100% auditable ante peritajes judiciales o requerimientos de la CMF. A diferencia de una reescritura mediante LLMs opacos, la canonización regex no introduce sesgos generativos ni alucinaciones.
2. **Preservación del Texto Original en Bitácora:**
   - El registro de auditoría (`audit_log`) debe almacenar siempre dos campos: `raw_input` (con el texto auténtico del usuario, necesario para pruebas legales) y `canonical_state` (el payload consumido por Jev).

---

### 7.3. Condiciones Taxativas de NO Uso
- **NO delegar la normalización de identificadores legales (RUT, patentes) al espacio latente de Jev**; debe validarse con Módulo 11 en CPU.
- **NO canalizar datos confidenciales o bancarios a servicios de traducción externa (NMT no autorizados)** para intentar "traducir" antes de Jev.
- **NO ejecutar acciones operativas irreversibles sin verificación de umbral calibrado localmente**.

### 7.1 Hipótesis Falsable
$$H_0: \text{Classification\_Accuracy}_{\text{Raw\_Chileno}} = \text{Classification\_Accuracy}_{\text{Canonicalized}}$$
*La hipótesis nula postula que la canonización previa de modismos chilenos no produce una mejora estadísticamente significativa en la precisión de clasificación de Jev sobre entradas coloquiales.*

### 7.2 Protocolo Experimental
1. **Muestra:** 100 mensajes reales y sintéticos curados que contienen chilenismos críticos de urgencia, insolvencia, fallas técnicas e ironía.
2. **Condiciones Pareadas:**
   - Brazo 1: Inferencia directa de Jev sobre el texto crudo original.
   - Brazo 2: Inferencia de Jev sobre el texto procesado con `ChileanDialectNormalizer`.
3. **Métrica y Criterio de Falsación:**
   - Se mide la tasa de acierto frente al *Ground Truth* validado por lingüistas chilenos.
   - Si $\text{Accuracy}_{\text{Canonicalized}} - \text{Accuracy}_{\text{Raw}} \ge 0.15$ con $p < 0.001$ mediante la prueba de McNemar, se **rechaza $H_0$** y se declara obligatoria la canonización dialectal en producción.
